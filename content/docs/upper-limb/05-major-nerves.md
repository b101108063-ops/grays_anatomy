::: {#本章重點}
- **正中神經（Median Nerve, C6-T1）**：魚際3.5指感覺，損傷後形成「猿手」
- **尺神經（Ulnar Nerve, C8-T1）**：小魚際1.5指感覺，損傷後形成「爪形手」
- **橈神經（Radial Nerve, C5-T1）**：所有伸肌支配，損傷後形成「垂腕」
- 三大神經均起源於臂叢，走行各具特徵
- 神經損傷症狀包括運動障礙與感覺障礙
:::

## 1. 正中神經（Median Nerve, C6-T1）

### 1.1 解剖走行

| 區段 | 走行描述 |
|------|----------|
| 臂部 | 起於內側束與外側束會合→沿臂內側下行→位於肱动脉內側 |
| 前臂 | 穿過**旋前圓肌**兩頭之間→走在前臂前側深層→與指淺屈肌、指深屈肌之間 |
| 腕部 | 通過**腕管**（屈肌支持帶下方）→進入手掌 |
| 手部 | 分為外側支與內側支 |

### 1.2 運動支配（Motor Innervation）

| 肌肉 | 位置 | 功能 |
|------|------|------|
| **旋前圓肌** | 前臂前側 | 前臂旋前 |
| **橈側腕屈肌** | 前臂前側 | 屈腕（橈偏） |
| **掌長肌** | 前臂前側 | 屈腕 |
| **指淺屈肌**（外側半） | 前臂前側 | 屈近端指間關節 |
| **指深屈肌**（外側半） | 前臂前側 | 屈遠端指間關節（食指、中指） |
| **拇長屈肌** | 前臂前側 | 屈拇指遠端 |
| **旋前方肌** | 前臂前側 | 前臂旋前 |
| **拇指對掌肌** | 手部魚際 | 拇指對掌 |
| **拇短展肌** | 手部魚際 | 拇指外展 |
| **拇短屈肌**（淺頭） | 手部魚際 | 屈拇指 |
| **蚓狀肌（1-2）** | 手掌 | 屈掌指關節、伸指間關節 |

### 1.3 感覺支配（Sensory Innervation）

| 區域 | 具體分布 |
|------|----------|
| **手掌外側** | 拇指、食指、中指、無名指**橈側**（魚際隆起） |
| **手指掌側** | 拇指遠端、食指、中指、無名指**橈側3.5指** |
| **手指背側** | 食指、中指遠端（**部分**指背） |

### 1.4 臨床損傷表現

#### 腕部損傷（最常見）

| 表現 | 說明 |
|------|------|
| **魚際肌萎縮** | 拇指對掌、外展、屈曲障礙 |
| **猿手（Ape Hand）** | 魚際平坦，拇指與食指平行，無法對掌 |
| **感觉障碍** | 魚際及外側3.5指麻木 |

#### 肘部或更高位置損傷

| 表現 | 說明 |
|------|------|
| 前臂症狀 | 旋前障礙（旋前圓肌無力） |
| 手部症狀 | 魚際萎縮 + 蚓狀肌（1-2）無力 |
| **「祝福手（Hand of Benediction）」** | 屈指障礙，尤其食指與中指 |

> **臨床應用**：**腕隧道症候群（Carpal Tunnel Syndrome）**是正中神經在腕管內受壓的疾病，是最常見的上肢神經卡壓病變。主要表現為夜間手指麻木、刺痛，嚴重時出現魚際肌萎縮。Tinel's sign（輕叩腕管區）和Phalen's test（手腕屈曲30-60秒誘發症狀）是常用檢查。

## 2. 尺神經（Ulnar Nerve, C8-T1）

### 2.1 解剖走行

| 區段 | 走行描述 |
|------|----------|
| 臂部 | 起於內側束→沿臂內側下行→位於**肱骨內上髁後方**（尺神經溝） |
| 前臂 | 穿過尺側腕屈肌兩個頭之間→走在前臂前側尺側 |
| 腕部 | 走在尺動、靜脈外側→通過**腕管的尺側**（Guyon's管） |
| 手部 | 分為淺支（感覺）與深支（運動） |

### 2.2 運動支配（Motor Innervation）

| 肌肉 | 位置 | 功能 |
|------|------|------|
| **尺側腕屈肌** | 前臂前側尺側 | 屈腕（尺偏） |
| **指深屈肌**（內側半） | 前臂前側 | 屈遠端指間關節（無名指、小指） |
| **小魚際肌** | 手部小魚際 | 小指對掌、外展、屈曲 |
| **背側骨間肌**（4條） | 掌骨間 | **外展**手指（II, III, IV） |
| **掌側骨間肌**（3條） | 掌骨間 | **內收**手指（II, III, IV） |
| **蚓狀肌**（3-4） | 手掌尺側 | 屈掌指關節、伸指間關節 |
| **內收肌** | 手部拇指 | 拇指內收 |

### 2.3 感覺支配（Sensory Innervation）

| 區域 | 具體分布 |
|------|----------|
| **手掌內側** | 小指、無名指**尺側**（小魚際） |
| **手指掌側** | 小指、無名指**尺側1.5指** |
| **手背內側** | 小指、無名指**尺側1.5指**（部分） |

### 2.4 臨床損傷表現

#### 肘部損傷（尺神經溝）

| 表現 | 說明 |
|------|------|
| **爪形手（Claw Hand）** | 掌指關節過伸、指間關節屈曲（小指、無名指最明顯） |
| **骨間肌萎縮** | 掌骨間凹陷 |
| **手指外展/內收障礙** | 無法分開手指（背側骨間肌）、無法併攏（掌側骨間肌） |
| ** Froment's sign** | 拇指內收障礙，屈曲代替內收（Froment's sign阳性） |

#### 腕部損傷（Guyon's管）

| 表現 | 說明 |
|------|------|
| 運動障礙 | 僅手內在肌受累，尺側腕屈肌及指深屈肌正常（由前臂支配） |
| 感覺障礙 | 手掌及手指尺側 |

> **臨床應用**：**Froment's sign**用於評估尺神經運動功能：囑患者用拇指和食指夾持紙張，若拇指遠端指間關節屈曲（拇長屈肌代償）而無法內收，則為陽性。**爪形手**的特點是掌指關節過伸（骨間肌無力無法屈曲掌指關節）及指間關節屈曲（蚓狀肌無力無法伸直指間關節）。

## 3. 橈神經（Radial Nerve, C5-T1）

### 3.1 解剖走行

| 區段 | 走行描述 |
|------|----------|
| 臂部 | 起於後束→繞過**橈神經溝**（與肱深动脉伴行）→穿過**肱三頭肌**與**肱橈肌**之間 |
| 前臂 | 穿過**旋後肌**（骨間後神經）→走在前臂後側淺層與深層之間 |
| 終末支 | 終於**淺支**（感覺）與**深支**（運動） |

### 3.2 運動支配（Motor Innervation）

| 肌肉 | 位置 | 功能 |
|------|------|------|
| **三角肌後份** | 肩部 | 肩關節後伸 |
| **肱三頭肌** | 臂後側 | 伸肘 |
| **肘肌** | 肘關節後方 | 伸肘（輔助） |
| **肱橈肌** | 前臂外側 | 屈肘（中立位最有效） |
| **旋後肌** | 前臂後側 | 前臂旋後 |
| **橈側腕長伸肌** | 前臂後側 | 伸腕（橈偏） |
| **橈側腕短伸肌** | 前臂後側 | 伸腕（橈偏） |
| **指伸肌** | 前臂後側 | 伸手指（掌指關節為主） |
| **尺側腕伸肌** | 前臂後側 | 伸腕（尺偏） |
| **拇指伸肌**（長、短） | 前臂後側 | 伸拇指 |
| **食指伸肌** | 前臂後側 | 伸食指 |

### 3.3 感覺支配（Sensory Innervation）

| 區域 | 具體分布 |
|------|----------|
| **上臂後側** | 臂後側皮神經 |
| **前臂後側** | 前臂後側皮神經 |
| **手背** | 橈側**3.5指**背面（拇指、食指、中指、無名指橈側）——由淺支分布 |

### 3.4 臨床損傷表現

#### 高位損傷（橈神經溝）

| 表現 | 說明 |
|------|------|
| **垂腕（Wrist Drop）** | 腕伸肌全部無力，無法伸腕 |
| **伸指障礙** | 指伸肌無力 |
| **伸拇指障礙** | 拇指伸肌無力 |
| **感覺障礙** | 手背橈側3.5指麻木 |

#### 橈神經深支損傷（骨間後神經）

| 表現 | 說明 |
|------|------|
| 伸腕正常 | 橈側腕長/短伸肌由淺支支配，仍正常 |
| 垂指 | 指伸肌、拇指伸肌障礙 |

> **臨床應用**：橈神經損傷最典型的臨床表現是**「垂腕」**，因為腕伸肌失去神經支配，患者無法主動伸腕。**「Saturday night palsy」**是指在睡眠或醉酒時，橈神經在臂部受壓（特別是橈神經溝處）而導致的損傷，常見於手臂靠在椅背或床緣時。

## 4. 三大神經損傷比較

| 特徵 | 正中神經 | 尺神經 | 橈神經 |
|------|----------|--------|--------|
| **來源** | C6-T1 | C8-T1 | C5-T1 |
| **起源束** | 內側束+外側束 | 內側束 | 後束 |
| **感覺分布** | 外側3.5指（掌側） | 內側1.5指 | 手背橈側3.5指 |
| **運動障礙** | 魚際萎縮、無法對掌 | 爪形手、骨間肌萎縮 | 垂腕、垂指 |
| **典型畸形** | **猿手（Ape Hand）** | **爪形手（Claw Hand）** | **垂腕（Wrist Drop）** |
| **主要損傷部位** | 腕管 | 尺神經溝/Guyon's管 | 橈神經溝 |
| **重要症狀** | 夜間麻木、Tinel's sign | Froment's sign | 感覺減退（手背） |

## 5. 臨床檢查法

### 正中神經檢查

| 檢查 | 方法 | 正常反應 |
|------|------|----------|
| 對掌 | 拇指觸碰小指指尖 | 拇指能對掌 |
| 魚際感覺 | 輕觸食指、中指掌側 | 正常感覺 |
| Tinel's sign | 輕叩腕管 | 無刺痛/放電感 |

### 尺神經檢查

| 檢查 | 方法 | 正常反應 |
|------|------|----------|
| Froment's sign | 夾持紙張 | 拇指能內收，關節不屈曲 |
| 分指/併指 | 分開/併攏手指 | 正常活動 |
| 小魚際感覺 | 輕觸小指掌側 | 正常感覺 |

### 橈神經檢查

| 檢查 | 方法 | 正常反應 |
|------|------|----------|
| 伸腕 | 手臂平放桌面，手背向上伸腕 | 正常伸腕 |
| 伸指 | 前臂旋前，伸直手指 | 正常伸指 |
| 拇指伸直 | 拇指豎起 | 正常伸拇指 |

> **臨床應用**：在創傷評估中，神經功能檢查是必備項目。三大神經的功能障礙都有獨特的臨床表現，正確識別有助於定位損傷水平和制定治療策略。

## 6. 總結

| 神經 | 感覺區 | 運動（主要） | 典型畸形 |
|------|--------|--------------|----------|
| **正中神經** | 外側3.5指（掌側） | 魚際肌、拇指對掌 | 猿手（Ape Hand） |
| **尺神經** | 內側1.5指 | 小魚際肌、骨間肌 | 爪形手（Claw Hand） |
| **橈神經** | 手背橈側3.5指 | 所有伸肌 | 垂腕（Wrist Drop） |
