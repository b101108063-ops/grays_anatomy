## 1. 肩關節（Glenohumeral Joint）

肩關節是典型的**球窩關節（ball-and-socket joint）**，由肱骨頭與肩胛骨的關節盂組成，是**全身活動度最大**的關節，但相對地**穩定性也最差**，容易發生脫位。

### 關節結構

| 結構 | 說明 |
|------|------|
| 關節盂（Glenoid Cavity） | 肩胛骨外側的淺窩，略微凹陷 |
| 肱骨頭（Humeral Head） | 球形，指向內側上方 |
| 關節囊（Joint Capsule） | 薄而鬆弛，允許大範圍活動 |
| 盂唇（Glenoid Labrum） | 纖維軟骨環，增加關節盂深度 |
| 韌帶 | 囊韌帶加強穩定性 |

### 關節穩定結構——肩袖（Rotator Cuff）

**肩袖**由四塊肌肉的腱性部分組成，環繞肩關節，對維持穩定性至關重要：

| 肌肉 | 英文 | 主要功能 | 神經支配 |
|------|------|----------|----------|
| 棘上肌 | Supraspinatus | **外展起始**（前15°） | 肩胛上神經 |
| 棘下肌 | Infraspinatus | **外旋** | 肩胛上神經 |
| 小圓肌 | Teres Minor | **外旋** | 腋神經 |
| 肩胛下肌 | Subscapularis | **內旋** | 肩胛下神經 |

> **臨床應用**：肩袖損傷（Rotator Cuff Injury）是常見的肩部疾病，尤其常見於需要反覆抬手過頭的運動（如游泳、棒球）或工作者。**棘上肌**是最常受損的肩袖肌肉，病理切片可見肌腱退行性變化。肩袖完整時才能維持肱骨頭在關節盂內的正常位置。

## 2. 肩部肌肉（Shoulder Muscles）

### 主要肩部肌肉

| 肌肉 | 英文 | 起點 | 止點 | 功能 | 神經支配 |
|------|------|------|------|------|----------|
| 三角肌 | Deltoid | 鎖骨外側、肩峰、肩胛岡 | 肱骨三角肌粗隆 | **外展**（前中後部各有功能） | **腋神經（Axillary Nerve）** |
| 胸大肌 | Pectoralis Major | 鎖骨、胸骨、肋軟骨 | 肱骨大結節嵴 | **內收、內旋** | 胸前內側/外側神經 |
| 胸小肌 | Pectoralis Minor | 第3-5肋 | 肩胛喙突 | 拉肩胛向前下 | 胸前內側神經 |
| 鎖骨下肌 | Subclavius | 第1肋軟骨 | 鎖骨下面 | 固定/下壓鎖骨 | 鎖骨下神經 |
| 僧帽肌 | Trapezius | 上項線、枕外粗隆、C7-T12棘突 | 鎖骨、肩峰、肩胛岡 | 提肩、降肩、固定肩胛 | 副神經（Accessory Nerve） |

### 三角肌（Deltoid）功能分區

- **前部纖維**：屈曲、內旋
- **中部纖維**：**外展**（主要功能）
- **後部纖維**：伸展、外旋

> **臨床應用**：三角肌萎縮可由**腋神經損傷**引起，常見於肩關節脫位或肱骨外科頸骨折後。臨床上可觀察到肩部輪廓變平、「方肩」畸形。

## 3. 臂部血管（Brachial Vessel）

### 肱动脉（Brachial Artery）

**肱动脉**是上肢最主要的动脉，於臂部內側下行：

| 項目 | 說明 |
|------|------|
| 起點 | 腋动脉在肩胛下肌下緣延續 |
| 走行 | 臂內側，介於正中神經（外側）與尺神經（內側）之間 |
| 主要分支 | 肱深动脉、高位尺側副动脉、尺側下副动脉 |
| 終點 | 肘窩中部分為尺动脉與橈动脉 |

### 主要側支循環

當肱动脉在臂部中段阻塞時，可通過以下側支循環維持遠端血流：
- **肱深动脉**與**尺側上副动脉**吻合
- **尺側下副动脉**與**尺侧返动脉**吻合

> **臨床應用**：測量**臂部血壓**時使用的血壓計囊帶即包繞於上臂中段，聽診位置在肱动脉遠端。臨床上可觸摸肱动脉搏動來評估近端血流，位置在臂內側、肱二頭肌與肱三頭肌之間溝內。

## 4. 臂部神經（Nerves of Arm）

臂部主要神經包括**肌皮神經**與**腋神經**，均源自**臂叢外側束與後束**：

### 肌皮神經（Musculocutaneous Nerve, C5-C6）

| 項目 | 說明 |
|------|------|
|起源 | 臂叢外側束 |
| 走行 | 穿過**肱二頭肌**與**喙肱肌**之間 |
| 運動支配 | 屈肘（肱二頭肌、肱肌）、前臂旋後（旋後肌） |
| 感覺支配 | 前臂外側皮質（前臂外側皮神經） |

### 腋神經（Axillary Nerve, C5-C6）

| 項目 | 說明 |
|------|------|
| 起源 | 臂叢後束 |
| 走行 | 穿過**四角空間**，繞肱骨頸 |
| 運動支配 | 三角肌（外展）、小圓肌（外旋） |
| 感覺支配 | 肩部外側（三角肌止點以上区域）——**臂外側皮神經** |

> **臨床應用**：腋神經損傷常見於**肩關節脫位**或**肱骨頸骨折**。主要表現為：
> - **三角肌萎縮**→肩部輪廓變平（方肩）
> - **外展無力**（三角肌為主要外展肌）
> - **感覺減退**區域：肩部外側

## 5. 腋窩（Axilla）

腋窩是位於肩關節下方、胸壁與臂之間的錐體形間隙，是神經血管進出上肢的重要通道。

### 腋窩境界

| 境界 | 組成 |
|------|------|
| 前壁 | 胸大肌、胸小肌、鎖胸筋膜 |
| 後壁 | 肩胛下肌、背闊肌、大圓肌 |
| 內側壁 | 第1-4肋間隙、胸壁 |
| 外側壁 | 肱骨、喙肱肌、肱二頭肌短頭 |
| 底 | 腋筋膜（篩狀筋膜） |

### 腋窝內容物

- **腋动脉**及其分支
- **腋靜脈**
- **臂叢**主要結構
- **腋淋巴結**
- **脂肪組織**

> **臨床應用**：**腋淋巴結**引流乳房外側象限及上肢淺層的淋巴。乳癌手術時需評估腋淋巴結狀態，但需注意避免損傷重要神經如**胸長神經**（導致前鋸肌麻痺，出現翼狀肩胛）。

| **重要間隙** | 腋窩（Axilla）——神經血管樞紐 |
