::: {#本章重點}
- **上肢动脉**：鎖骨下动脉→腋动脉→肱动脉→尺/橈动脉
- **腋动脉**主要分支包括胸肩峰动脉、胸外側动脉、肩胛上动脉、旋肱後/前动脉
- **淺靜脈**：頭靜脈（外側）與貴要靜脈（內側）
- **腋窩淋巴結**分為5群，主要引流乳房及上肢淋巴
- 乳房淋巴主要引流至**腋窩淋巴結**，是乳癌轉移的重要路徑
:::

## 1. 上肢动脉（Arteries of Upper Limb）

上肢动脉呈連續性分布，由主幹动脉及其分支組成。

### 1.1 动脉主幹連續性

| 區段 | 动脉 | 英文 | 延續關係 |
|------|------|------|----------|
| 近端 | **鎖骨下动脉** | Subclavian Artery | 主幹上行至第一肋外側緣 |
| ↓ | → | → | 延續為 |
| 中段 | **腋动脉** | Axillary Artery | 第一肋外側緣至大圓肌下緣 |
| ↓ | → | → | 延續為 |
| 臂部 | **肱动脉** | Brachial Artery | 大圓肌下緣至肘窩中點 |
| ↓ | → | → | 分為 |
| 遠端 | **尺动脉** | Ulnar Artery | 前臂尺側 |
| | **橈动脉** | Radial Artery | 前臂橈側 |

### 1.2 鎖骨下动脉（Subclavian Artery）

| 項目 | 說明 |
|------|------|
| 起點 | 主动脉弓的無名动脉（左側）或頭臂干（右側） |
| 走行 | 在前斜角肌後方橫過第一肋上方 |
| 分支 | 椎动脉、甲狀頸干、肋頸干、胸廓內动脉 |
| 終點 | 第一肋外側緣移行為腋动脉 |

### 1.3 腋动脉（Axillary Artery）

腋动脉是上肢动脉中最重要的分支段，與**臂叢**關係密切。

| 項目 | 說明 |
|------|------|
| 起點 | 第一肋外側緣（鎖骨下动脉延續） |
| 終點 | 大圓肌下緣（移行為肱动脉） |
| 走行 | 經腋窩，與臂叢束支關係密切 |

#### 腋动脉主要分支

| 分支 | 英文 | 分布 | 臨床意義 |
|------|------|------|----------|
| **胸上动脉** | Supreme Thoracic Artery | 第1-2肋間隙 | 較細小 |
| **胸肩峰动脉** | Thoracoacromial Artery | 胸肌、三角肌、肩峰 | 臨床上可用作游離皮瓣血管 |
| **胸外側动脉** | Lateral Thoracic Artery | 胸大肌、胸小肌、乳房 | **乳房主要血液供應** |
| **肩胛上动脉** | Suprascapular Artery | 肩胛上肌、肩胛下肌 | 與旋肱动脉吻合 |
| **旋肱前动脉** | Anterior Circumflex Humeral Artery | 肱骨頭、肩關節 | 較細小 |
| **旋肱後动脉** | Posterior Circumflex Humeral Artery | 三角肌、肩關節 | 與肩胛上动脉吻合；**腋神經伴行** |

> **臨床應用**：腋动脉損傷常見於嚴重創傷，可導致威脅生命的出血。腋动脉瘤則可能壓迫臂叢，導致神經功能障礙。**胸外側动脉**是乳房的主要血液供應來源之一，在乳癌根治術中需妥善處理。

### 1.4 肱动脉（Brachial Artery）

| 項目 | 說明 |
|------|------|
| 起點 | 腋动脉在大圓肌下緣延續 |
| 走行 | 臂內側溝（介於正中神經與尺神經之間） |
| 分支 | 肱深动脉、尺側上副动脉、尺側下副动脉、滋养动脉 |
| 終點 | 肘窩中點分為尺动脉與橈动脉 |
| 臨床 | 測量血壓部位；可觸摸脈搏（臂內側） |

#### 主要側支循環

當肱动脉阻塞時，以下側支路徑可維持遠端血流：

| 側支路徑 | 吻合處 |
|----------|--------|
| 旋肱後动脉 ↔ 旋肱前动脉 | 肩部 |
| 肩胛上动脉 ↔ 旋肱後动脉 | 肩部 |
| 尺側上副动脉 ↔ 尺側下副动脉 ↔ 尺側返动脉 | 臂-肘 |

### 1.5 尺动脉與橈动脉（Ulnar & Radial Arteries）

| 动脉 | 位置 | 臨床意義 |
|------|------|----------|
| **尺动脉** | 前臂尺側，與尺神經伴行 | 位置較深 |
| **橈动脉** | 前臂橈側，**位置表淺** | 臨床上觸摸脈搏的首選位置 |

> **臨床應用**：**Allen試驗**用於評估掌弓的完整性：先同時壓迫尺动脉和橈动脉，囑患者握拳放鬆後，放開尺动脉，觀察手部顏色恢復情況。若手部顏色迅速恢復，提示尺动脉-掌弓系統通暢；若恢復延遲，則提示尺动脉或掌弓可能阻塞。

## 2. 上肢靜脈（Veins of Upper Limb）

上肢靜脈分為**淺靜脈**與**深靜脈**兩系統，兩者有廣泛交通。

### 2.1 淺靜脈（Superficial Veins）

| 靜脈 | 英文 | 位置 | 流向 | 臨床意義 |
|------|------|------|------|----------|
| **頭靜脈** | Cephalic Vein | 前臂**橈側**外緣→上臂外側→三角肌胸大肌間溝 | 鎖骨下静脉或腋静脉 | 靜脈穿刺首選；可用於心導管插入 |
| **貴要靜脈** | Basilic Vein | 前臂**尺側**內緣→上臂內側 | 腋静脉（深部） | 靜脈穿刺常用；也是血液透析通路 |
| **肘正中靜脈** | Median Cubital Vein | 肘窩前方，連接頭靜脈與貴要靜脈 | 交通支 | 抽血、靜脈注射最常用部位 |

> **臨床應用**：頭靜脈與貴要靜脈是臨床上最重要的淺靜脈。頭靜脈在心臟起搏器植入、中心靜脈導管插入中常被選用。貴要靜脈則是血液透析患者建立動靜脈瘻管的常用部位。

### 2.2 深靜脈（Deep Veins）

| 靜脈 | 英文 | 伴行關係 |
|------|------|----------|
| 尺側伴行靜脈 | Venae Comitantes of Ulnar Artery | 伴行尺动脉 |
| 橈側伴行靜脈 | Venae Comitantes of Radial Artery | 伴行橈动脉 |
| 肱靜脈 | Brachial Vein | 伴行肱动脉（通常為雙支） |
| 腋靜脈 | Axillary Vein | 伴行腋动脉 |

> **臨床應用**：上肢深靜脈血栓（Deep Vein Thrombosis, DVT）可能導致**Paget-Schroetter症候群**（ effort thrombosis），常見於年輕人激烈運動後。若出現上肢腫脹、疼痛，需警惕此診斷。

## 3. 淋巴系統（Lymphatic System）

### 3.1 上肢淋巴引流

| 層次 | 走行 | 引流範圍 |
|------|------|----------|
| **淺層淋巴** | 沿淺靜脈（頭靜脈、貴要靜脈） | 皮膚、皮下組織的淋巴 |
| **深層淋巴** | 沿神經血管（深靜脈、动脉） | 肌肉、骨骼、關節的淋巴 |

### 3.2 腋窩淋巴結（Axillary Lymph Nodes）

腋窩淋巴結是上肢及乳房淋巴的主要引流站，共約**20-30個**，分為五群：

| 淋巴結群 | 英文 | 位置 | 引流範圍 |
|----------|------|------|----------|
| **外側群** | Lateral Nodes | 腋靜脈後外側 | **上肢全部**（主要引流） |
| **胸肌群** | Pectoral Nodes | 胸外側动脉旁 | **乳房外側象限** |
| **肩胛下群** | Subscapular Nodes | 肩胛下动脉旁 | 背部、肩胛區 |
| **中央群** | Central Nodes | 腋窩中央脂肪組織 | 接收前三群淋巴 |
| **鎖骨下群**（三角胸肌群） | Apical/Infraclavicular Nodes | 鎖骨下方，三角肌胸大肌間溝 | **接收所有腋窩淋巴結**；**乳房上部** |

> **臨床應用**：**乳房淋巴引流**的主要路徑是：
> - **外側象限**→胸肌群淋巴結→中央群→鎖骨下群
> - **內側象限**→內乳淋巴結（沿胸廓內动脉）
> - **上部**→鎖骨下群
>
> 腋窩淋巴結狀態是**乳癌分期**的重要指標，也是手術中需評估的關鍵結構。

### 3.3 乳房淋巴引流（Breast Lymphatic Drainage）

| 區域 | 主要引流方向 |
|------|--------------|
| 乳房外側 | **腋窩淋巴結**（胸肌群→中央群→鎖骨下群） |
| 乳房內側 | 內乳淋巴結（沿胸廓內动脉） |
| 乳房上部 | 鎖骨下群淋巴結 |
| 乳房深部 | 胸肌間淋巴結（Rotter's nodes） |

> **臨床應用**：乳癌細胞主要通過**腋窩淋巴結**轉移。臨床上可通過**前哨淋巴結活檢**（Sentinel Lymph Node Biopsy）評估淋巴結狀態，避免不必要的腋窩淋巴結清除，減少術後淋巴水腫的發生。

## 4. 臨床相關——血管與淋巴疾病

### 4.1 乳房手術與淋巴水腫

| 併發症 | 說明 |
|--------|------|
| **腋窩淋巴結清除後淋巴水腫** | 上肢淋巴回流受阻，導致上肢腫脹 |
| 預防 | 前哨淋巴結活檢取代常規淋巴結清除 |
| 治療 | 彈性袖套、淋巴引流按摩、複雜消腫治療 |

### 4.2 胸出口症候群（Thoracic Outlet Syndrome）

| 項目 | 說明 |
|------|------|
| 病因 | 臂叢與鎖骨下血管在胸出口處受壓 |
| 症狀 | 上肢疼痛、麻木、感覺異常；嚴重時手指缺血 |
| 檢查 | Adson's test、Roos test |
| 治療 | 物理治療、手術減壓 |

> **臨床應用**：鎖骨下动脉與靜脈在穿過第一肋與鎖骨之間時可受到壓迫，導致**胸出口症候群**。**Adson's test**（頭轉向患側並深吸氣）可誘發鎖骨下动脉受壓症狀。

## 5. 總結表格

### 血管系統

| 區段 | 动脉 | 靜脈 |
|------|------|------|
| 近端 | 鎖骨下动脉 | 鎖骨下靜脈 |
| 中段 | 腋动脉（分支：胸肩峰动脉、胸外側动脉、肩胛上动脉、旋肱後/前动脉） | 腋靜脈 |
| 臂部 | 肱动脉 | 肱靜脈（伴行） |
| 前臂 | 尺动脉、橈动脉 | 尺側/橈側伴行靜脈 |
| 淺層 | — | 頭靜脈（外側）、貴要靜脈（內側） |

### 淋巴系統

| 結構 | 說明 |
|------|------|
| 淺層淋巴 | 沿頭靜脈、貴要靜脈 |
| 深層淋巴 | 沿神經血管 |
| 腋窩淋巴結 | 5群：外側群、胸肌群、肩胛下群、中央群、鎖骨下群 |
| 乳房引流 | 主要至腋窩淋巴結（外側），另至內乳淋巴結（內側） |
