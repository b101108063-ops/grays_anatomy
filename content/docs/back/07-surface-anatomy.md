## 本章重點

- ✅ C7 棘突是頸椎最突出的突起，低頭時更明顯
- ✅ T3 平肩胛岡內側端，T7 平肩胛骨下角
- ✅ L3-L4 平對髂嵴最高點（約臍的水準）
- ✅ S2 平對臀溝，骶角是骶管裂孔的定位標誌
- ✅ 表面標誌是臨床定位脊椎層次、進行腰椎穿刺的實用工具

---

## 表面解剖概論

表面解剖（Surface Anatomy）是利用體表可觸及的結構來定位深層解剖構造的學問。在脊椎評估和操作中，正確的表面標誌定位非常重要。

### 常用定位方法

| 方法 | 說明 |
|------|------|
| 視診 | 觀察姿態、畸形、腫脹 |
| 觸診 | 觸摸骨性標誌 |
| 活動度測試 | 評估脊椎各方向活動 |

---

## 頸椎表面標誌

### C7 棘突（隆椎）

| 項目 | 內容 |
|------|------|
| **位置** | 頸椎中最突出的棘突 |
| **辨識方法** | 低頭時更明顯；從上方計數第 7 個頸椎棘突 |
| **臨床應用** | 頸椎計數起點、針灸定位 |

### 其他頸椎棘突

| 棘突 | 定位方法 |
|------|----------|
| C2 | 枕下凹（頭後凹陷）下方第一個突起 |
| C3-C6 | 觸診不明顯（項韌帶覆蓋） |
| C7 | 最突出的頸椎棘突 |

### 項韌帶（Nuchal Ligament）

- 從枕外粗隆延伸至 C7 棘突
- 是頸椎後方重要的定位結構
- 触诊呈繃緊的韌帶狀

## 胸椎表面標誌

| 棘突 | 表面標誌 | 定位方法 |
|------|----------|----------|
| **T1** | 胸骨切跡（T2 水準）下方 | 兩肩胛骨之間 |
| **T3** | 平肩胛岡內側端 | 肩胛岡向內延伸的末端 |
| **T4** | 平乳頭線 | 男性乳頭連線 |
| **T7** | 平肩胛骨下角 | 肩胛骨下端 |
| **T12** | 平肩胛骨下角與髂嵴中點 | 约为第12肋骨位置 |

> 📌 **實用記憶法：** 「3 娘（岡）4 乳 7 下角」

## 腰椎表面標誌

| 棘突 | 表面標誌 | 定位方法 |
|------|----------|----------|
| **L1** | 第 12 肋骨下方 |  |
| **L2** | 季肋區 |  |
| **L3** | 平臍 | 約肚臍的水準 |
| **L4** | 平髂嵴最高點 | 兩側髂嵴最高點連線 |
| **L5** | 髂嵴下方、骶骨上方 |  |

> 📌 **為何 L4-L5 常作為腰椎穿刺部位？** 因為成人脊髓終於 L1-L2，此處穿刺不會損傷脊髓，安全性高。

### 髂嵴（Iliac Crest）

| 項目 | 內容 |
|------|------|
| **位置** | 骨盆上緣，觸診為腰部兩側最寬的骨性突起 |
| **對應脊椎** | 兩側髂嵴最高點連線 = **L4 棘突** |
| **對應臍** | 約 L3 水準 |
| **臨床應用** | 定位 L4-L5 穿刺點 |

---

## 骶骨與尾骨表面標誌

### 骶角（Sacral Cornu）

| 項目 | 內容 |
|------|------|
| **位置** | 骶管裂孔兩側的骨性突起 |
| **定位** | 臀溝上端，尾骨上方約 5 cm |
| **臨床應用** | 骶管阻滞麻醉（S2 水準）的定位標誌 |

### 骶管裂孔（Sacral Hiatus）

| 項目 | 內容 |
|------|------|
| **位置** | 骶骨背面，骶角之間 |
| **深度** | 皮下約 1-2 cm |
| **臨床應用** | 骶管麻醉入口 |

### 其他骶椎標誌

| 標誌 | 對應結構 |
|------|----------|
| 骶正中嵴 | 骶椎融合的棘突 |
| 骶後孔 | S1-S4 位置，可作為針灸治療點 |

### 尾骨（Coccyx）

| 項目 | 內容 |
|------|------|
| **位置** | 骶骨下方，臀溝深處 |
| **觸診** | 肛門上方約 2-3 cm |
| **臨床應用** | 尾骨骨折評估 |

## 下肢與骨盆表面標誌

| 表面標誌 | 對應脊椎層次 |
|----------|--------------|
| **臀溝（Gluteal Fold）** | 平 S2 |
| **髂前上棘（ASIS）** | 約 L5-S1 水準 |
| **股骨大轉子** | 約 S1 水準 |
| **坐骨結節** | 約 S3 水準 |

> 📌 **骶神經評估的皮節對照：**
> - S1：足跟外側
> - S2：臀裂兩側
> - S3：鞍區

## 臨床應用

### 腰椎穿刺定位

| 間隙 | 定位方法 | 適用情況 |
|------|----------|----------|
| **L3-L4** | 兩側髂嵴最高點連線（Tuffier's line）= L4 棘突，上一個棘突就是 L3 | 標準穿刺部位 |
| **L4-L5** | L4 棘突下方 | L3-L4 穿刺失敗時 |
| **L5-S1** | L5 棘突下方，骶骨上方 | 骶管麻醉 |

> ⚠️ **定位錯誤的風險：** 若在 L2 以上穿刺，可能損傷脊髓（終於 L1-L2）。

### 脊椎層次臨床定位總結

| 臨床情況 | 定位方法 |
|----------|----------|
| 腹部器官與脊椎關係 | T12：腎臟下極；L3：胰臟；L4：臍 |
| 腹部血管與脊椎關係 | L2：腸繫膜上血管；L3：腸繫膜下血管 |
| 腎臟定位 | T12-L3，右腎比左腎稍低 |

### 觸診順序

| 步驟 | 操作 |
|------|------|
| 1 | 確認 C7 棘突（低頭最突出） |
| 2 | 沿 C7 向下確認 T1 |
| 3 | 沿胸椎向下計數（肩胛岡 = T3、肩胛骨下角 = T7） |
| 4 | 確認 L4（髂嵴連線） |
| 5 | 確認 L5（髂嵴下方）、骶骨 |

### 姿勢評估

| 姿勢異常 | 可能原因 |
|----------|----------|
| 頸椎前凸減少 | 頸椎退化、肌肉緊張 |
| 胸椎後凸增加（駝背） | 骨質疏鬆、姿勢不良 |
| 腰椎前凸增加 | 腰椎滑脫、姿勢不良 |
| 脊椎側彎 | 特發性、先天性、退行性 |
