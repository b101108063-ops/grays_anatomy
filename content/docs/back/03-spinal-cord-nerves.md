## 本章重點

- ✅ 脊髓範圍：C1 到 L1-L2（成人），兒童可達 L3
- ✅ 脊髓被膜三層：硬膜（dura mater）、蛛網膜（arachnoid mater）、軟膜（pia mater）
- ✅ 31 對脊神經：8 頸、12 胸、5 腰、5 骶、1 尾
- ✅ 馬尾（Cauda Equina）由 L2 以下的腰骶神經根組成
- ✅ 皮節（Dermatome）地圖用於評估神經根功能

---

## 脊髓概述

脊髓（Spinal Cord）是中樞神經系統的一部分，呈圓柱狀，位於椎管內。

### 解剖範圍

| 時期 | 上端 | 下端 | 長度 |
|------|------|------|------|
| **胎兒/新生兒** | C1 | L3 | 約 16-20 cm |
| **成人** | C1 | **L1-L2**（通常 L1 下緣） | 約 42-45 cm |
| **終絲（Filum Terminale）** | L2 | 尾骨 | 硬膜囊內的軟膜延伸 |

> 📌 **為何成人脊髓終於 L1-L2？** 胎兒時期脊髓與脊椎等長，隨著脊椎生長速度快於脊髓，脊髓相對上移，出生後約 3 歲達成人位置。

### 脊髓形態

- 呈圓柱狀，位於椎管內
- 兩個膨大：
  - **頸膨大（Cervical Enlargement）**：C4-T1，支配上肢
  - **腰膨大（Lumbosacral Enlargement）**：L2-S3，支配下肢
- 表面有縱行的**前正中裂**和**後正中溝**

### 脊髓横切面結構

| 區域 | 內容 |
|------|------|
| **灰質（Gray Matter）** | H 形蝴蝶狀，含神經細胞體；分前角、後角、側角 |
| **白質（White Matter）** | 環繞灰質，含上行/下行傳導束 |
| **中央管（Central Canal）** | 貫穿脊髓，含腦脊液 |

## 脊髓被膜

脊髓被膜（Spinal Meninges）包覆脊髓及神經根，由外向內分三層：

| 被膜 | 結構特點 | 腔隙 |
|------|----------|------|
| **硬膜（Duramater）** | 最外層，厚而堅韌的緻密結締組織 | 硬膜外腔（Epidural Space） |
| **蛛網膜（Arachnoid Mater）** | 薄膜狀，與軟膜之間有絲狀結構 | 蛛網膜下腔（Subarachnoid Space）含 CSF |
| **軟膜（Piamater）** | 緊貼脊髓表面，富含血管 | 軟膜下腔 |

### 腔隙結構

| 腔隙 | 內容 |
|------|------|
| **硬膜外腔** | 脂肪組織、硬膜外靜脈叢（Batson's plexus）、淋巴管 |
| **蛛網膜下腔** | 腦脊液（CSF）、神經根 |
| **軟膜下腔** | 緊密貼合，無明顯腔隙 |

> 📌 **硬膜外麻醉的原理：** 將麻醉藥注入硬膜外腔，阻斷神經根的傳導，達到區域麻醉效果。

## 馬尾（Cauda Equina）

### 定義

脊髓下端（L1-L2）以下的腰、骶、尾神經根在椎管內下行，這些神經根集合外觀如馬尾，稱為**馬尾（Cauda Equina）**。

### 組成

| 結構 | 說明 |
|------|------|
| 腰神經根 | L2-L5（3 對） |
| 骶神經根 | S1-S5（5 對） |
| 尾神經根 | Co1（1 對） |
| **終絲（Filum Terminale）** | 軟膜延伸，附著於尾骨 |

### 臨床意義

- 馬尾內含感覺、運動及自主神經纖維
- 馬尾症候群（Cauda Equina Syndrome）為急症，需緊急手術減壓

## 脊神經

### 總論

人體有 **31 對脊神經（Spinal Nerves）**：

| 類別 | 數量 | 符號 |
|------|------|------|
| 頸神經 | **8 對** | C1-C8 |
| 胸神經 | **12 對** | T1-T12 |
| 腰神經 | **5 對** | L1-L5 |
| 骶神經 | **5 對** | S1-S5 |
| 尾神經 | **1 對** | Co1 |

> ⚠️ **頸神經為何是 8 對？** 因為 C1-C7 之間各有神經，但第 8 頸椎沒有對應椎骨，C8 神經從 C7 下方發出。

### 神經組成

每對脊神經由：
- **背根（感覺根）**：含神經節內感覺神經元細胞體
- **腹根（運動根）**：含脊髓前角運動神經元細胞體

兩者在椎間孔附近匯合，形成混合性脊神經。

### 神經叢（ Plexus）

| 神經叢 | 組成 | 主要分支 |
|--------|------|----------|
| **臂叢（Brachial Plexus）** | C5-T1 | 正中神經、尺神經、橈神經、腋神經、肌皮神經 |
| **腰叢（Lumbosacral Plexus）** | L1-S4 | 股神經、閉孔神經、坐骨神經、脛神經、腓總神經 |

#### 臂叢（Brachial Plexus）

```
根（C5-C8, T1）→ 幹部（上下干）→ 股（前股後股）→ 束（外側後側內側）→ 終支
```

| 終支 | 支配肌肉 | 感覺區 |
|------|----------|--------|
| 正中神經 | 前臂屈肌（部分）、手肌（魚際） | 掌側 1-3 指半 |
| 尺神經 | 小魚際、手內在肌 | 掌側 1-2 指半 |
| 橈神經 | 三角肌、肱三頭肌、前臂伸肌 | 手背橈側 2-3 指 |
| 腋神經 | 三角肌、小圓肌 | 肩外側 |

#### 腰叢（Lumbosacral Plexus）

| 主要分支 | 組成 | 支配 |
|----------|------|------|
| 股神經 | L2-L4 | 髂腰肌、股四頭肌 |
| 閉孔神經 | L2-L4 | 內收肌群 |
| 坐骨神經 | L4-S3 | 大腿後側肌群、小腿、足部（分為脛神經、腓總神經） |

## 皮節（Dermatome）

### 定義

皮節（Dermatome）是單一脊神經背根所支配的皮膚區域。

### 皮節分布圖

| 皮節 | 位置 |
|------|------|
| **C2** | 枕部、頸後 |
| **C3** | 頸側、鎖骨上區 |
| **C4** | 肩部、三角肌區 |
| **C5** | 上臂外側 |
| **C6** | 前臂外側、拇指 |
| **C7** | 手掌中央、中指 |
| **C8** | 前臂內側、環指、小指 |
| **T1** | 腋窩、上臂內側 |
| **T4** | 乳頭線 |
| **T10** | 臍線 |
| **T12** | 恥骨聯合上方 |
| **L1** | 腹股溝、臀部上方 |
| **L2** | 大腿前上方 |
| **L3** | 大腿中段、膝蓋上方 |
| **L4** | 小腿內側、踝內側 |
| **L5** | 小腿外側、足背、拇指 |
| **S1** | 足外側、足跟、小腿後側 |
| **S2** | 臀裂兩側、大腿後側 |
| **S3** | 臀溝、骶區 |
| **S4-S5** | 肛門周圍（鞍區） |

> 📌 **皮節檢查的臨床應用：** 通過測試皮節感覺，可判斷脊髓或神經根損傷的節段水準。

## 臨床應用

### 腰椎穿刺

- 常選 **L3-L4** 或 **L4-L5** 間隙
- 此處脊髓已終止（成人 L1-L2），避免損傷脊髓
- 穿刺針依次經過：皮膚 → 皮下 → 棘上韌帶 → 棘間韌帶 → 黃韌帶 → 硬膜 → 蛛網膜下腔

### 脊髓損傷定位

| 損傷層次 | 表現 |
|----------|------|
| 頸髓（C1-C4） | 四肢癱瘓、呼吸衰竭 |
| 頸膨大（C5-T1） | 上肢癱瘓、下肢癱瘓 |
| 胸髓（T1以下） | 截癱（雙下肢癱瘓） |
| 腰膨大（L2-S3） | 下肢癱瘓，感覺保留 |

### 馬尾症候群

| 症狀/徵象 | 說明 |
|-----------|------|
| 鞍區麻木 | S3-S5 支配區 |
| 大小便障礙 | 尿瀦留、便祕 |
| 會陰感覺喪失 | 馬鞍型感覺缺失 |
| 下肢疼痛、無力 | 單側或雙側 |

> ⚠️ **馬尾症候群是急症：** 出現上述症狀需緊急 MRI 確認並手術減壓，否則可能造成永久性大小便功能障礙。
