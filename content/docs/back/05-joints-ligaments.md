## 本章重點

- ✅ 椎間關節（Facet Joints）是滑膜關節，關節面方向決定活動度
- ✅ 頸椎關節面開放（自由度大）、胸椎關節面接近冠狀位（穩定但活動受限）、腰椎關節面矢狀位（允許前屈後伸）
- ✅ 主要韌帶：**棘上韌帶**、**棘間韌帶**、**黃韌帶**、**前縱韌帶**、**後縱韌帶**
- ✅ 韌帶損傷可導致脊椎不穩定，是評估創傷的重要依據

## 椎間關節（Zygapophyseal Joints / Facet Joints）

### 結構

| 項目 | 內容 |
|------|------|
| **別名** | 椎骨關節突關節、Facet Joints |
| **類型** | 滑膜關節（Synovial Joint） |
| **位置** | 每節脊椎的上下關節突之間 |
| **數量** | 每節脊椎有左右兩側，共 2 個 |

### 關節面方向與功能

| 脊椎區域 | 關節面方向 | 穩定性 | 活動度 |
|----------|------------|--------|--------|
| **頸椎** | 開放（水平或稍傾斜） | 中等 | 高（前屈、後伸、側彎、旋轉） |
| **胸椎** | 接近冠狀位（近垂直） | 高 | 低（主要是旋轉） |
| **腰椎** | 矢狀位（稍傾斜） | 中等 | 中（前屈、後伸、側彎，限制旋轉） |

> 📌 **為何腰椎旋轉受限？** 因為腰椎關節面呈矢狀位，旋轉時關節突會撞擊，限制旋轉運動。這是胸椎活動度以旋轉為主、腰椎活動度以前屈後伸為主的解剖學基礎。

### 關節囊

- 關節突關節有關節囊包覆
- 關節囊外有韌帶加強
- 富含本體感覺受器，與姿勢控制相關

### 臨床意義

| 臨床情況 | 說明 |
|----------|------|
| **小關節症候群（Facet Syndrome）** | 關節退變、發炎，導致局部疼痛 |
| **關節積液** | MRI 可見，提示炎性疾病 |
| **阻斷/麻醉** | 可做為疼痛診斷與治療的手段 |

## 脊椎韌帶

脊椎韌帶分為椎間韌帶與椎體周圍韌帶，共同維持脊椎穩定性。

### 椎間韌帶

| 韌帶 | 位置 | 結構特點 | 功能 |
|------|------|----------|------|
| **棘上韌帶（Supraspinous Ligament）** | 棘突尖端至末端 | 強韌的縱行纖維 | 限制脊椎前屈 |
| **棘間韌帶（Interspinous Ligament）** | 相鄰棘突之間 | 較薄弱的斜行纖維 | 限制前屈、限制脊椎分離 |
| **黃韌帶（Ligamentum Flavum）** | 相鄰椎板之間 | 彈性纖維（黃色） | 維持脊椎後伸、限制前屈 |

> 📌 **黃韌帶的特點：** 含大量彈性纖維，顏色呈黃色。是脊椎最富彈性的韌帶，後屈時會拉長，前屈時會縮短。黃韌帶肥厚是椎管狹窄的原因之一。

### 椎體周圍韌帶

| 韌帶 | 位置 | 特點 | 功能 |
|------|------|------|------|
| **前縱韌帶（Anterior Longitudinal Ligament, ALL）** | 椎體前方 | 最堅強的脊椎韌帶，寬帶狀 | 限制後伸、防止脊椎過度後凸 |
| **後縱韌帶（Posterior Longitudinal Ligament, PLL）** | 椎體後方、椎管前壁 | 較薄弱，覆蓋不完整（後外側最薄） | 限制前屈、防止椎間盤向後突出 |

> 📌 **為何椎間盤向後外側突出？** 前縱韌帶較厚且覆蓋完整，而後縱韌帶在椎間盤後外側區域覆蓋不完整，無法有效阻止髓核突出。

### 韌帶結構圖

```
椎管
 ↑
 [黃韌帶] ← 位於椎板之間
 [PLL] ← 位於椎體後方
 [椎間盤]
 [ALL] ← 位於椎體前方
 ↓
 椎體
```

## 各區脊椎關節與韌帶特點

### 頸椎

| 結構 | 特點 |
|------|------|
| **關節面方向** | 開放（近水平），活動度大 |
| **特有韌帶** | 項韌帶（Nuchal Ligament）— 連接 C1 與顱底 |
| **寰樞關節** | C1-C2 齒突關節、寰樞外側關節 |
| **横突孔** | 容納椎血管 |

### 胸椎

| 結構 | 特點 |
|------|------|
| **關節面方向** | 接近冠狀位，與肋骨形成關節 |
| **肋横突關節** | 肋骨結節與胸椎橫突相關節 |
| **肋椎關節** | 肋骨頭與椎體肋凹相關節 |
| **穩定性** | 與肋骨、胸骨構成胸廓，穩定性高 |

### 腰椎

| 結構 | 特點 |
|------|------|
| **關節面方向** | 矢狀位為主，限制旋轉 |
| **腰骶關節** | L5 與骶骨之間的特化關節 |
| **韌帶加強** | 髂腰韌帶、腰骶韌帶加強 |
| **活動度** | 前屈後伸為主，旋轉受限 |

## 臨床應用

### 韌帶損傷與脊椎不穩定

| 損傷類型 | 涉及韌帶 | 臨床意義 |
|----------|----------|----------|
| **屈曲損傷** | 棘間韌帶、棘上韌帶、ALL | 過度前屈導致撕裂 |
| **後伸損傷** | 前縱韌帶（ALL）、黃韌帶 | 過度後伸導致撕裂 |
| **脫位/骨折脫位** | 多個韌帶複合損傷 | 脊椎不穩定，需手術固定 |

> ⚠️ **創傷評估原則：** 脊椎韌帶損傷可能導致脊椎不穩定。臨床上若懷疑韌帶損傷，需評估脊椎穩定性，必要時手術固定。

### 脊椎穩定性評估（Denis 三柱理論）

| 柱 | 結構 |
|----|------|
| **前柱** | 前縱韌帶、椎體前半、椎間盤前半 |
| **中柱** | 椎體後半、後縱韌帶、椎間盤後半 |
| **後柱** | 關節突關節、棘突、椎板、橫突、韌帶（棘間/棘上/黃韌帶） |

> 📌 **穩定性判斷：** 中柱破壞是脊椎不穩定的重要指標。兩柱或以上損傷通常需要手術治療。

### 腰骶關節（L5-S1）

| 特點 | 說明 |
|------|------|
| **腰骶角** | L5 與骶骨夾角（約 30-40°），使 L5 有前滑傾向 |
| **傳遞重量** | 上半身重量經此關節傳至骨盆 |
| **滑脫風險** | 峡部裂或退化可導致脊椎滑脫（Spondylolisthesis） |

### 退化性改變

| 改變 | 說明 |
|------|------|
| 關節突關節磨損 | 軟骨變薄、骨刺形成 |
| 韌帶肥厚 | 黃韌帶肥厚可致椎管狹窄 |
| 骨質增生 | 關節突關節增生 |
| 脊椎不穩定 | 韌帶鬆弛導致異常活動 |

### 疼痛來源

| 結構 | 疼痛特點 |
|------|----------|
| 椎間關節 | 局部疼痛、活動時加重 |
| 黃韌帶 | 深層背痛 |
| 棘間韌帶 | 棘突間壓痛 |
| 前/後縱韌帶 | 椎體前方/後方深痛 |
