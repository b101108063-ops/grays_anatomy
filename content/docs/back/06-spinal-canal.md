## 本章重點

- ✅ 椎管由各椎孔連續形成，容納並保護脊髓及神經根
- ✅ 硬膜外腔（Epidural Space）含脂肪組織及 Batson's 靜脈叢
- ✅ 蛛網膜下腔含腦脊液（CSF），向下延伸至 S2
- ✅ 椎間孔（Intervertebral Foramen）是神經根離開椎管的神經通道
- ✅ **椎管狹窄（Spinal Stenosis）** 和 **椎間孔狹窄** 是常見臨床問題

---

## 椎管解剖

### 椎管構成

| 結構 | 形成方式 |
|------|----------|
| **椎孔（Vertebral Foramen）** | 單節椎骨的孔洞 |
| **椎管（Vertebral Canal）** | 所有椎孔上下連續形成的管道 |

椎管分為：
- **頸椎管**：容納頸髓（C1-C7）
- **胸椎管**：容納胸髓（T1-T12）
- **腰椎管**：容納馬尾（Cauda Equina）及腰骶神經根

### 椎管壁

| 方向 | 結構 |
|------|------|
| **前方** | 椎體後緣、後縱韌帶（PLL）、椎間盤 |
| **後方** | 椎板、棘突、黃韌帶、棘間韌帶 |
| **外側** | 椎弓根、關節突關節 |
| **前方兩側** | 椎弓根內側緣 |

## 硬膜外腔（Epidural Space）

### 位置

介於 **硬膜（Dura Mater）** 與 **椎管壁** 之間的腔隙。

### 內容物

| 內容 | 說明 |
|------|------|
| **脂肪組織** | 軟性填充，保護神經結構；腰椎处最丰富 |
| **硬膜外靜脈叢（Batson's Plexus）** | 無瓣膜靜脈網，連接骨盆/腹腔與顱內靜脈竇 |
| **淋巴管** | 引流腦膜淋巴 |
| **神經根** | 穿越硬膜外腔 |

### Batson's 靜脈叢

| 特點 | 臨床意義 |
|------|----------|
| 無瓣膜 | 靜脈血流可雙向流動 |
| 連接顱內與盆腔 | 感染/腫瘤可經此途徑轉移 |
| 硬膜外麻醉路徑 | 麻醉藥物注入此腔 |

> 📌 **為何孕產婦不宜行硬膜外麻醉？** 硬膜外靜脈叢在懷孕時充血，充血時穿刺風險增加，可能導致硬膜外出血或麻醉藥物進入靜脈。

### 臨床意義

| 情況 | 說明 |
|------|------|
| 硬膜外麻醉 | 常用於分娩止痛、下肢手術 |
| 硬膜外類固醇注射 | 治療椎間盤突出、神經根刺激 |
| 硬膜外血腫 | 外傷或凝血異常導致 |

## 硬膜內結構

### 脊髓被膜（由外向內）

| 被膜 | 腔隙 | 內容物 |
|------|------|--------|
| 硬膜（Dura Mater） | 硬膜外腔 | 脂肪、靜脈叢 |
| 蛛網膜（Arachnoid Mater） | 蛛網膜下腔 | CSF、神經根 |
| 軟膜（Pia Mater） | 緊貼脊髓 | 血管 |

### 蛛網膜下腔（Subarachnoid Space）

| 項目 | 內容 |
|------|------|
| **位置** | 蛛網膜與軟膜之間 |
| **內容物** | 腦脊液（CSF） |
| **延伸範圍** | 顱腔 → 椎管（向下至 S2 水準） |
| **功能** | 緩衝保護、營養運輸、廢物清除 |

### 腦脊液（CSF）

| 特性 | 說明 |
|------|------|
| 性狀 | 清亮、無色透明液體 |
| 壓力 | 側臥位：70-180 mmH₂O |
| 成分 | 水、蛋白質、葡萄糖、電解質、少量細胞 |
| 功能 | 浮力保護、營養運輸、維持顱內壓 |

### 軟膜結構

| 結構 | 說明 |
|------|------|
| **齒狀韌帶（Denticulate Ligament）** | 軟膜向側方延伸的鋸齒狀結構，固定脊髓於蛛網膜 |
| **終絲（Filum Terminale）** | 軟膜延伸至尾骨 |

## 椎間孔（Intervertebral Foramen）

### 位置與構成

椎間孔是神經根離開椎管的神經通道，由以下結構圍成：

| 方向 | 結構 |
|------|------|
| **上方** | 上方椎骨的椎弓根下緣 |
| **下方** | 下方椎骨的椎弓根上緣 |
| **前方** | 椎體後緣、椎間盤、後縱韌帶 |
| **後方** | 關節突關節、黃韌帶 |

### 內容物

| 內容 | 說明 |
|------|------|
| **背根神經節** | 感覺神經元細胞體所在 |
| **神經根** | 背根 + 腹根 |
| **脊神經** | 混合性神經 |
| **血管** | 椎間血管 |
| **脂肪組織 | 保護性填充 |

> 📌 **椎間孔大小變化：** 前屈時椎間孔增大，後伸時縮小。臨床上利用此原理緩解神經根壓迫。

## 臨床應用

### 椎管狹窄（Spinal Stenosis）

#### 定義
椎管任何部位管腔狹窄，導致神經結構受壓。

#### 分類

| 類型 | 狹窄部位 | 臨床表現 |
|------|----------|----------|
| **中央管狹窄** | 椎管中央 | 馬尾壓迫、雙下肢症狀、行走時加重（神經性跛行） |
| **椎間孔狹窄** | 椎間孔 | 單側神經根症狀 |
| **側隱窩狹窄** | 關節突關節內側 | 神經根壓迫 |

#### 病因

| 病因 | 說明 |
|------|------|
| 退化性 | 椎間盤退化、關節突關節增生、黃韌帶肥厚（最常見） |
| 先天性 | 先天性椎管狹窄 |
| 創傷性 | 椎體骨折、脱位 |
| 腫瘤性 | 椎管內腫瘤 |

#### 典型症狀

| 症狀 | 特點 |
|------|------|
| **神經性跛行** | 行走時雙下肢疼痛、麻木，休息後緩解（前屈姿勢可緩解） |
| 下肢放射痛 | 坐骨神經痛樣表現 |
| 馬尾症狀 | 鞍區麻木、大小便功能障礙 |

> 📌 **神經性跛行 vs 血管性跛行：** 
> - 神經性跛行：前屈/蹲下可緩解（椎管容積增大）
> - 血管性跛行：站立不動可緩解，行走又出現

#### 治療原則

| 治療方式 | 適應症 |
|----------|--------|
| 保守治療 | 輕度症狀：物理治療、藥物 |
| 微創手術 | 椎間孔鏡、內視鏡減壓 |
| 開放手術 | 嚴重狹窄、多節段病變：椎板切除、減壓融合 |

### 椎間孔狹窄

| 病因 | 說明 |
|------|------|
| 椎間盤突出 | 最常見原因 |
| 骨刺 | 關節突關節或椎體邊緣骨質增生 |
| 黃韌帶肥厚 | 向外側延伸 |
| 椎體滑脫 | 椎體相對移位 |

### 影像學檢查

| 檢查 | 用途 |
|------|------|
| **X 光** | 評估椎體結構、骨質變化 |
| **CT** | 清楚顯示骨質結構、椎管大小 |
| **MRI** | 顯示軟組織、脊髓、神經根、椎間盤（首選） |

### 腰椎穿刺與椎管

| 要點 | 說明 |
|------|------|
| 穿刺位置 | L3-L4 或 L4-L5 |
| 穿刺層次 | 皮膚 → 皮下 → 棘上韌帶 → 棘間韌帶 → 黃韌帶 → 硬膜 → 蛛網膜下腔 |
| 成功標誌 | 腦脊液流出（若未流出可能進入硬膜外腔或位置不對） |
