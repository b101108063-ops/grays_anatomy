## 本章重點

- ✅ 椎間盤由**纖維環（Annulus Fibrosus）**和**髓核（Nucleus Pulposus）**組成
- ✅ 椎間盤佔脊椎總長約 1/4，年輕時水分含量可達 90%
- ✅ 主要功能：吸收震動、分散壓力、維持活動度
- ✅ 椎間盤突出好發於 L4-L5、L5-S1，压迫神经根引起坐骨神經痛

---

## 椎間盤結構

椎間盤（Intervertebral Disc）是位於相鄰椎體之間的纖維軟骨結構，每節脊椎間都有一個（共 23 個：頸椎 6、胸椎 12、腰椎 5）。

### 整體結構

| 組成 | 位置 | 結構特點 |
|------|------|----------|
| **纖維環（Annulus Fibrosus）** | 周邊部分 | 分層排列的膠原纖維，向心性包繞 |
| **髓核（Nucleus Pulposus）** | 中央部分 | 膠狀物質，含水量高，具彈性 |
| **軟骨終板（Cartilaginous Endplate）** | 上下界面 | 薄層透明軟骨，介於椎體與椎間盤之間 |

### 纖維環結構

- 由 **15-25 層** 纖維軟骨構成
- 每層纖維走向不同，相鄰層呈約 30° 夾角
- 最外層與椎體邊緣及縱韌帶連續
- 抗扭轉能力強

### 髓核結構

| 特性 | 說明 |
|------|------|
| 組成 | 膠原纖維、蛋白多醣（Proteoglycans）、水 |
| 性狀 | 膠狀、黏稠、富彈性 |
| 位置 | 稍微偏後（椎間盤後 1/3） |
| 功能 | 吸收壓力、分散至纖維環 |

## 椎間盤的水分變化

| 年齡 | 水分含量 | 說明 |
|------|----------|------|
| 嬰幼兒 | 80-90% | 椎間盤柔軟、彈性佳 |
| 青少年 | 75-80% | 仍維持高水分 |
| 成人 | 70-75% | 開始退化 |
| 老年人 | <70% | 明顯脫水、彈性降低 |

> 📌 **水分變化的臨床意義：** 椎間盤脫水是導致身高縮短、椎間隙變窄的原因之一，也是椎間盤突出的前期病變。

---

## 椎間盤的功能

### 力學功能

| 功能 | 機制 |
|------|------|
| **吸收震動** | 髓核受壓時將壓力向四周分散 |
| **分散壓力** | 纖維環多層結構均勻傳遞應力 |
| **維持活動度** | 允許相鄰椎體間的微動 |
| **均勻負重** | 使椎體表面受力均勻 |

### 椎間盤與相鄰韌帶的關係

| 韌帶 | 位置 | 與椎間盤關係 |
|------|------|--------------|
| **前縱韌帶（ALL）** | 椎體前方 | 覆蓋椎間盤前壁，限制過度後伸 |
| **後縱韌帶（PLL）** | 椎體後方 | 位於椎間盤後壁，但覆蓋不完整（後外側較薄） |

> 📌 **為何椎間盤突出多向後或後外側？** 因為前縱韌帶較厚且堅固，而後縱韌帶在後外側較薄，無法有效阻擋髓核突出。

## 臨床應用

### 椎間盤突出（Disc Herniation）

**病理過程：**

```
正常椎間盤 → 脫水退化 → 纖維環裂隙 → 髓核突出 → 压迫神經根
```

**分型：**

| 分型 | 突出方向 | 臨床意義 |
|------|----------|----------|
| **中央型（Central）** | 正後方 | 可能压迫馬尾，引起膀胱/腸道功能障礙 |
| **後外側型（Posterolateral）** | 後外側 | 最常見，压迫下一節神經根（如 L4-L5 突出压迫 L5 神經根） |
| **椎間孔型（Foraminal）** | 椎間孔方向 | 压迫椎間孔內神經根 |
| **游離型（Sequestered）** | 髓核游離 | 碎片可移動至椎管內其他位置 |

**好發部位：**

| 位置 | 原因 |
|------|------|
| **L4-L5** | 承受最大機械壓力、腰椎活動度大 |
| **L5-S1** | 腰骶角使壓力集中在後側 |

### 頸椎間盤問題

| 間盤 | 影響神經根 | 症狀 |
|------|------------|------|
| C3-C4 | C4 | 頸部、肩胛區麻木 |
| C4-C5 | C5 | 三角肌無力、肩膀麻木 |
| C5-C6 | C6 | 上臂外側、拇指麻木 |
| C6-C7 | C7 | 上臂後側、中指麻木 |
| C7-T1 | C8 | 前臂內側、環指、小指麻木 |

### 腰椎間盤突出

| 間盤 | 影響神經根 | 典型症狀 |
|------|------------|----------|
| L2-L3 | L3 | 大腿前內側麻木、膝蓋反射減弱 |
| L3-L4 | L4 | 小腿內側麻木、膝蓋反射減弱 |
| **L4-L5** | **L5** | **小腿外側、拇指背側麻木、拇指背屈無力（最常見）** |
| **L5-S1** | **S1** | **小腿後側、足外側麻木、踝反射減弱、足蹠屈無力** |

> ⚠️ **警告徵象（Red Flags）：** 椎間盤突出若出現以下情況需緊急處理：
> - 馬尾症候群（大小便功能障礙、鞍區麻木）
> - 進行性神經功能缺損
> - 保守治療無效的嚴重症狀

### 椎間盤退變

- **椎間盤脫水** → MRI T2 訊號降低
- **纖維環破裂** → 疼痛原因
- **Modic 改變** → 椎體終板水腫/硬化

### 椎間盤的營養

- 椎間盤無血管支配
- 營養來自滲透作用（椎體 → 軟骨終板 → 纖維環/髓核）
- 運動與負重有助於營養擴散
