## 本章重點

- ✅ 椎間盤突出分型：中央型、後外側型、椎間孔型
- ✅ 脊椎滑脫（Spondylolisthesis）分為峡部裂性、退化性、創傷性
- ✅ 椎管狹窄分中央管狹窄與椎間孔狹窄
- ✅ 脊髓損傷分級常用 **ASIA 分級**
- ✅ 坐骨神經痛（Sciatica）與神經根病變（Radiculopathy）為常見臨床問題

---

## 椎間盤突出（Disc Herniation）

### 病理過程

```
椎間盤退化 → 水分減少 → 纖維環裂隙 → 髓核突出 → 神經根/脊髓壓迫
```

### 分型

| 分型 | 突出方向 | 受壓結構 | 臨床表現 |
|------|----------|----------|----------|
| **中央型（Central）** | 正後方 | 馬尾、脊髓 | 馬尾症候群、雙側症狀、膀胱功能障礙 |
| **後外側型（Posterolateral）** | 後外側 | 下節神經根 | 單側坐骨神經痛（最常見） |
| **椎間孔型（Foraminal）** | 椎間孔方向 | 椎間孔內神經根 | 劇烈根性疼痛 |
| **游離型（Sequestered）** | 碎片游離 | 可達椎管任意位置 | 症狀多變 |

### 好發部位與症狀

| 間盤 | 受壓神經根 | 典型症狀 |
|------|------------|----------|
| **L4-L5** | L5 | 小腿外側麻木、拇指背側無力（最常見） |
| **L5-S1** | S1 | 足外側麻木、足蹠屈無力、踝反射減弱 |
| **L3-L4** | L4 | 大腿內側麻木、膝蓋反射減弱 |

### 診斷

| 方法 | 內容 |
|------|------|
| **理學檢查** | 直腿抬高測試（SLR）、交叉直腿抬高測試、神經學檢查 |
| **影像學** | MRI（首選）、CT |
| **電生理檢查** | EMG/NCV（排除其他神經病變） |

### 治療

| 方式 | 適應症 |
|------|--------|
| 保守治療 | 初次發作、無明顯神經功能缺損：臥床、藥物、物理治療 |
| 微創手術 | 椎間孔鏡、內視鏡、顯微椎間盤切除 |
| 開放手術 | 椎間盤切除 + 融合手術 |

## 脊椎滑脫（Spondylolisthesis）

### 定義

一個椎體相對於相鄰椎體向前或向後移位。

### 分型

| 分型 | 病因 | 特點 |
|------|------|------|
| **峡部裂性（Spondylolytic）** | 椎弓峡部疲勞骨折 | 最常見，年輕人 |
| **退化性（Degenerative）** | 關節突關節退化、不穩定 | 老年人，L4-L5 |
| **創傷性（Traumatic）** | 急性外傷導致椎弓骨折 | 任何年齡 |
| **病理性（Pathological）** | 腫瘤、感染破壞骨質 | 基礎疾病 |
| **發育性（Dyplastic）** | 先天性椎弓發育不良 | 罕見 |

### Meyerding 分級

| 分級 | 滑脫程度 |
|------|----------|
| I 度 | < 25% |
| II 度 | 25-50% |
| III 度 | 50-75% |
| IV 度 | 75-100% |
| V 度 | > 100%（脊椎脫位） |

### 臨床表現

| 症狀 | 說明 |
|------|------|
| 下背痛 | 最常見，久站/行走加重 |
| 放射痛 | 神經根壓迫時 |
| 馬尾症狀 | 嚴重滑脫時 |
| 姿態異常 | 腰部前凸增加 |

## 椎管狹窄（Spinal Stenosis）

### 定義

椎管、神經根管或椎間孔的病理性狹窄，導致神經結構受壓。

### 分類

| 類型 | 狹窄部位 | 臨床表現 |
|------|----------|----------|
| **中央管狹窄** | 椎管中央 | 馬尾壓迫、雙側症狀、間歇性跛行 |
| **側隱窩狹窄** | 關節突關節內側 | 單側神經根症狀 |
| **椎間孔狹窄** | 椎間孔 | 劇烈根性疼痛 |

### 病因

| 病因 | 說明 |
|------|------|
| 退化性 | 椎間盤退化、關節突關節增生、黃韌帶肥厚（最常見） |
| 先天性 | 先天性椎管狹窄 |
| 創傷性 | 椎體骨折、脱位後 |
| 腫瘤性 | 椎管內腫瘤 |

### 神經性跛行特點

| 特點 | 說明 |
|------|------|
| 誘發因素 | 行走、站立（腰椎後伸時加重） |
| 緩解因素 | 休息、坐位、前屈姿勢 |
| 症狀 | 雙下肢疼痛、麻木、無力 |
| 與血管性跛行鑑別 | 前屈可緩解神經性跛行 |

### 治療

| 治療 | 適應症 |
|------|--------|
| 保守治療 | 輕度：物理治療、藥物、腰椎屈曲訓練 |
| 微創減壓 | 單節段或兩節段狹窄 |
| 減壓融合 | 合併脊椎不穩定或多節段病變 |

## 脊椎骨折（Vertebral Fractures）

### 分類

| 類型 | 機制 | 穩定性 |
|------|------|--------|
| **壓迫骨折（Compression）** | 軸向負荷 + 前屈 | 穩定（不侵犯後柱） |
| **爆裂骨折（Burst）** | 軸向負荷，椎體爆裂 | 不穩定（侵犯後柱） |
| **Chance 骨折** | 屈曲-牽張損傷 | 不穩定（水平骨折） |
| **骨折脱位（FX-dislocation）** | 屈曲-旋轉或剪切 | 高度不穩定 |
| **樞椎骨折（C2）** | 齒突骨折、Hangman's骨折 | 變異大 |

### 骨質疏鬆壓迫骨折

| 特點 | 說明 |
|------|------|
| 好發部位 | 胸腰交界（T12-L2） |
| 誘發因素 | 輕微外傷或無明顯外傷 |
| 表現 | 急性背痛、活動受限 |
| 治療 | 保守治療、椎體成形術、脊椎後凸成形術 |

## 脊髓損傷（Spinal Cord Injury）

### 分類

| 分類 | 說明 |
|------|------|
| **完全性損傷** | 損傷平面以下感覺、運動功能完全喪失 |
| **不完全性損傷** | 損傷平面以下仍保留部分功能 |

### ASIA 分級（美國脊椎損傷協會）

| 等級 | 定義 |
|------|------|
| **A** | 完全性損傷：鞍區（S3-S4）無任何感覺或運動功能 |
| **B** | 不完全性損傷：鞍區有感覺但無運動功能 |
| **C** | 不完全性損傷：鞍區有運動功能，但下肢肌力 < 3 級 |
| **D** | 不完全性損傷：下肢肌力 ≥ 3 級 |
| **E** | 正常：感覺和運動功能正常 |

### 常見脊髓損傷綜合徵

| 綜合徵 | 損傷部位 | 表現 |
|--------|----------|------|
| **布朗-塞卡症候群（Brown-Séquard）** | 半側脊髓 | 同側運動喪失 + 對側痛溫覺喪失 |
| **前脊髓症候群** | 脊髓前 2/3 | 運動及痛溫覺喪失，保留本體感覺 |
| **後脊髓症候群** | 脊髓後柱 | 本體感覺喪失，運動及痛溫覺保留 |
| **馬尾症候群** | 馬尾神經根 | 下肢放射性疼痛、鞍區麻木、大小便障礙 |

## 坐骨神經痛（Sciatica）

### 定義

沿坐骨神經分布區域（臀部、大腿後側、小腿、足部）的疼痛。

### 病因

| 病因 | 說明 |
|------|------|
| 椎間盤突出 | 最常見（L4-L5, L5-S1） |
| 椎管狹窄 | 腰椎管狹窄症 |
| 脊椎滑脫 | 峡部裂性或退化性 |
| 梨狀肌症候群 | 梨狀肌壓迫坐骨神經 |
| 腫瘤 | 椎管內或盆腔腫瘤 |

### 坐骨神經路徑

```
腰叢（L4-S3）→ 坐骨大切跡出骨盆 → 臀部 → 坐骨神經 →
大腿後側 → 腘窩上方分為：
  ├─ 脛神經（L4-S3）：小腿後側、足底
  └─ 腓總神經（L4-S2）：小腿前側、外側、足背
```

### 放射痛分布

| 受壓部位 | 疼痛分布 |
|----------|----------|
| L4 神經根 | 大腿前內側、膝蓋內側 |
| L5 神經根 | 小腿外側、足背拇指 |
| S1 神經根 | 小腿後側、足外側 |

## 神經根病變（Radiculopathy）

### 定義

單一或多個脊神經根受壓或損傷，導致感覺、運動及反射異常。

### 頸椎神經根病變

| 間盤 | 神經根 | 症狀分布 |
|------|--------|----------|
| C3-C4 | C4 | 頸部、肩胛區 |
| C4-C5 | C5 | 肩膀、上臂外側、三角肌 |
| C5-C6 | C6 | 上臂外側、前臂外側、拇指 |
| C6-C7 | C7 | 上臂後側、前臂背側、中指 |
| C7-T1 | C8 | 前臂內側、環指、小指 |

### 腰椎神經根病變

| 間盤 | 神經根 | 主要症狀 |
|------|--------|----------|
| L2-L3 | L3 | 大腿前內側麻木、膝蓋反射減弱 |
| L3-L4 | L4 | 小腿內側麻木、膝蓋反射減弱 |
| **L4-L5** | **L5** | **小腿外側麻木、拇指背屈無力（最常見）** |
| **L5-S1** | **S1** | **足外側麻木、踝反射減弱、足蹠屈無力** |

### 診斷要點

| 檢查 | 內容 |
|------|------|
| 理學檢查 | 神經學檢查（感覺、運動、反射） |
| 影像學 | MRI（首選） |
| 電生理檢查 | EMG/NCV（確認診斷、排除其他） |

### 治療原則

| 病情 | 治療方式 |
|------|----------|
| 輕度 | 保守治療：休息、藥物、物理治療 |
| 中度 | 離神明經根注射、椎間孔鏡減壓 |
| 重度/保守無效 | 手術減壓（椎間盤切除、椎板切除等） |

> ⚠️ **紅旗徵象（Red Flags）：** 出現以下情況需緊急處理：
> - 進行性神經功能缺損
> - 馬尾症候群（大小便障礙、鞍區麻木）
> - 保守治療無效的嚴重疼痛
