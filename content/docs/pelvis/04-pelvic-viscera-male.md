## 本章重點

- **膀胱（Bladder）**位於骨盆腔前部，逼尿肌（detrusor muscle）收縮時可排尿
- **輸尿管（Ureter）**骨盆段在膀胱後外側斜行進入，形成**輸尿管口（ureteric orifice）**
- **攝護腺（Prostate）**位於膀胱下方，**正中葉**肥大可壓迫尿道導致尿路阻塞
- **肛門指診（DRE）**可在距肛門約 **4 cm** 處觸及攝護腺
- **儲精囊（Seminal Vesicles）**位於膀胱底與直腸之間，分泌精液
- **睪丸（Testis）**血液供應來自**睪丸动脉（testicular artery）**，靜脈回流經**蔓狀靜脈叢（pampiniform plexus）**

## 膀胱（Bladder）

### 位置與形態

| 項目 | 說明 |
|------|------|
| **位置** | 骨盆腔前部，恥骨聯合後方 |
| **前方鄰近** | 恥骨聯合、恥骨上支 |
| **後方鄰近** |男性的：攝護腺、儲精囊、直腸（腹膜直腸膀胱陷凹介於膀胱與直腸之間） |
| **上方鄰近** | 乙狀結腸（小腸） |
| **下方鄰近** | 攝護腺（男性）/ 子宮頸（女性） |

### 膀胱分部

| 部分 | 英文 | 說明 |
|------|------|------|
| **頂（Apex）** | Apex | 膀胱前上端，朝向前上方 |
| **底（Fundus）** | Fundus | 膀胱後下底部 |
| **體（Body）** | Body | 膀胱的主要部分 |
| **脖（ Neck）** | Neck | 膀胱最下端，與攝護腺相連處，內有**內尿道括約肌（internal urethral sphincter）** |

### 逼尿肌（Detrusor Muscle）

- **類型**：平滑肌（不隨意肌）
- **排列**：三層交錯排列（內縱層、中環層、外縱層）
- **神經支配**：
  - **副交感神經（S2-S4）**：促使逼尿肌收縮 → **排尿（micturition）**
  - **交感神經（T11-L2）**：促使逼尿肌舒張、內尿道括約肌收縮 → **儲尿**

### 膀胱的血液供應

| 血管 | 來源 |
|------|------|
| **膀胱上动脉（Superior Vesical Artery）** | 臍动脉（umbilical artery）→ 髂內动脉 |
| **膀胱下动脉（Inferior Vesical Artery）** | 髂內动脉（internal iliac artery） |
| **閉孔动脉（Obturator Artery）** | 髂內动脉（通常） |

### 膀胱的神經支配

| 神經 | 來源 | 功能 |
|------|------|------|
| **副交感神經** | S2-S4（盆神經 pelvic splanchnic nerves） | 逼尿肌收縮 |
| **交感神經** | T11-L2（上腹下叢 hypogastric plexus） | 逼尿肌舒張、內括約肌收縮 |
| **軀體神經** | **陰部神經（Pudendal Nerve, S2-S4）** | 外尿道括約肌收縮（隨意控制） |

## 輸尿管（Ureter）— 骨盆段

### 骨盆內走行

| 區段 | 說明 |
|------|------|
| **腰段** | 從腎盂向下，跨過**髂總动脉（common iliac artery）**分叉處 |
| **骨盆段** | 沿盆腔側壁向前內側走行，介於**卵巢窝**（女）與**閉孔內肌**（男）表面 |
| **膀胱壁段** | 斜行穿過膀胱壁，形成**輸尿管口（ureteric orifice）** |

### 输尿管口（Ureteric Orifice）

- 两侧输尿管口與**膀胱頸（bladder neck）**呈**三角形**排列，構成**膀胱三角（trigone）**
- 输尿管斜行穿過膀胱壁的機制：**防止尿液逆流（vesicoureteral reflux）**

> ⚠️ **解剖關係**：男性輸尿管骨盆段在**攝護腺**外上方，與**儲精囊**相鄰；女性輸尿管在**卵巢懸韌帶**與**子宫动脉**下方走行，與子宫血管關係密切。

### 输尿管的血液供應

| 區段 | 主要供血 |
|------|----------|
| **上段（腎盂至髂總动脉）** | 腎动脉、卵巢/睪丸动脉 |
| **中段（髂總动脉至膀胱）** | 髂總/髂外动脉、卵巢/睪丸动脉 |
| **下段（膀胱壁段）** | 膀胱上/下动脉、子宮动脉（女性） |

## 攝護腺（Prostate）

### 位置與形態

| 項目 | 說明 |
|------|------|
| **位置** | 膀胱下方，恥骨聯合後方，直腸前方 |
| **形狀** | 栗子狀，大小約 **4 × 3 × 2 cm** |
| **重量** | 約 20-25 g（正常） |
| **尿道穿行** | **尿道（urethra）**穿過攝護腺中央，稱為**前列腺部尿道（prostatic urethra）** |

### 攝護腺分葉（臨床實用分法）

| 分葉 | 英文 | 位置 | 臨床意義 |
|------|------|------|----------|
| **正中葉（Middle Lobe）** | Middle Lobe | 尿道內口與射精管之間 | **肥大**可壓迫尿道内口 → 排尿困難、尿潴留 |
| **左/右葉（Left/Right Lobe）** | Left/Right Lobe | 尿道兩側 | 前列腺增生主要發生部位 |
| **後葉（Posterior Lobe）** | Posterior Lobe | 直腸可觸及處 | **癌症**好發部位，肛門指診（DRE）可觸及 |

> **肛門指診（DRE）**：攝護腺距離肛門約 **4 cm**，正常攝護腺質地光滑、柔軟。攝護腺癌時可觸及硬結節。

### 攝護腺的血液供應

| 血管 | 來源 |
|------|------|
| **攝護腺動骻（Prostatic Artery）** | 髂內动脉（internal iliac artery）→ 膀胱下动脉分支 |
| **直腸中动脉（Middle Rectal Artery）** | 髂內动脉 |
| **閉孔动脉（Obturator Artery）** | 髂內动脉（變異分支） |

### 攝護腺的神經支配

| 來源 | 功能 |
|------|------|
| **交感神經（T10-L2）** | 攝護腺收縮協助射精 |
| **副交感神經（S2-S4）** | 促進攝護腺分泌 |

## 儲精囊（Seminal Vesicles）

### 位置與形態

| 項目 | 說明 |
|------|------|
| **位置** | 膀胱底與直腸之間，攝護腺上方 |
| **形狀** | 成對的囊狀結構，長約 5 cm |
| **功能** | **分泌精液（seminal fluid）**，占射出精液量的 **60-70%** |
| **分泌物** | 果糖（提供精子能量）、前列腺素、蛋白質 |

### 與攝護腺的關係

- 儲精囊位於攝護腺上方，射精管（ejaculatory duct）穿過攝護腺
- **射精管（Ejaculatory Duct）**：由儲精囊管與輸精管壺腹會合形成，開口於**尿道前列腺部**

## 睪丸（Testis）

### 位置與形態

| 項目 | 說明 |
|------|------|
| **位置** | **陰囊（Scrotum）**內，左睪丸通常低於右側 |
| **形狀** | 扁橢圓形 |
| **大小** | 長約 4-5 cm，厚約 2-3 cm |
| **被膜** | 由外向內：陰囊皮膚 → 肉膜（dartos fascia）→ 提睪肌（cremasteric muscle）→ 睪丸鞘膜（tunica vaginalis）→ 白膜（tunica albuginea） |

### 血液供應

| 血管 | 來源 | 說明 |
|------|------|------|
| **睪丸动脉（Testicular Artery）** | 主動骻（Abdominal Aorta，腎动脉下方） | 直接來自主動骻，血氧含量高 |
| **提睪肌动脉（Cremasteric Artery）** | 腹壁下动脉（inferior epigastric artery） | 营养提睪肌 |
| **輸精管动脉（Deferential Artery）** | 膀胱上动脉 | 营养输精管 |

### 靜脈回流

| 靜脈 | 回流途徑 | 臨床意義 |
|------|----------|----------|
| **蔓狀靜脈叢（ Pampiniform Plexus）** | → **睪丸靜脈（Testicular Vein）** | 左側 → 左腎靜脈；右側 → 下腔靜脈（IVC） |
| **蔓狀靜脈叢** | 睪丸动脉周圍靜脈網 | **精子生成**需要低溫環境（約 35°C，低於體溫） |

> **靜脈曲張**：**左側**睪丸靜脈曲張常因左腎靜脈高壓所致，可影響精子品質導致**男性不孕症**。

## 副睪（Epididymis）

### 位置與形態

| 項目 | 說明 |
|------|------|
| **位置** | 睪丸後外側 |
| **形狀** | C 形，呈帽狀覆蓋睪丸上端 |
| **分部** | **頭（Caput）**、**體（Corpus）**、**尾（Cauda）** |

### 功能

| 功能 | 說明 |
|------|------|
| **精子成熟** | 頭部與體部：精子獲得運動能力與受精能力 |
| **精子儲存** | 尾部：儲存成熟精子，達數週 |
| **分泌物** | 重新吸收睾丸液體、分泌糖蛋白（支援精子） |

## 臨床應用（Clinical Correlation）

### 🚨 攝護腺增生（Benign Prostatic Hyperplasia, BPH）

- **發生率**：50 歲以上男性約 **50%**，80 歲以上達 **80%**
- **影響**：**正中葉**與**過渡帶（transition zone）**增生
- **症狀**：
  - **阻塞性症狀**：排尿踌躇、尿流細弱、排尿中斷、殘餘尿感
  - **刺激性症狀**：頻尿、急尿、夜尿
- **診斷**：DRE、超音波、PSA（攝護腺特異抗原）
- **治療**：藥物（α-阻斷劑、5α-還原酶抑制劑）、經尿道攝護腺切除術（TURP）

### 🚨 攝護腺癌（Prostate Cancer）

- **好發部位**：**後葉**（肛門指診可及）
- **特徵**：多為**腺癌（adenocarcinoma）**
- **轉移途徑**：**骨轉移**（脊椎、盆腔骨，常見骨痛）
- **篩檢**：DRE + **PSA（攝護腺特異抗原）**
- **確診**：超聲波引導切片（TRUS biopsy）

### 🚨 隱睪症（Cryptorchidism）

- **定義**：睪丸未下降至陰囊停留於腹腔或腹股溝管
- **影響**：
  - 精子品質受損（高溫環境）
  - **睪丸癌**風險增加 30-50 倍
- **治療**：**睪丸固定術（orchiopexy）**，建議 1-2 歲前行

### 🚨 輸精管結紮術（Vasectomy）

- **原理**：切斷並結紮**輸精管（ductus deferens）**，阻止精子通過
- **效果**：術後需 15-20 次射精才能完全清除殘餘精子
- **不可逆性**：應被視為不可逆的手術
- **併發症**：術後疼痛綜合徵（post-vasectomy pain syndrome）
