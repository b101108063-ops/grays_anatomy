## 本章重點

- 會陰以**恥骨聯合下支、坐骨支、坐骨結節、骶結節韌帶**為界
- 會陰分為**尿生殖三角（Urogenital Triangle）**與**肛門三角（Anal Triangle）**
- **肛門三角**含肛門口、肛門外括約肌、**坐骨直腸窩（ischiorectal fossa）**
- **尿生殖三角**分為**會陰淺隙（Superficial Perineal Pouch）**與**會陰深隙（Deep Perineal Pouch）**
- **會陰淺隙**含**球海綿體肌（bulbospongiosus）**、**坐骨海綿體肌（ischiocavernosus）**、**會陰淺橫肌**
- **會陰深隙**含**泌尿生殖膈（urogenital diaphragm）**與**外尿道括約肌（urethral sphincter）**
- **陰部內动脉（internal pudendal artery）**與**陰部神經（pudendal nerve, S2-S4）**支配會陰

---

## 會陰的境界與分界

### 會陰界線（Boundaries of the Perineum）

會陰是骨盆下口的軟組織封閉區域，其界限為：

| 方向 | 界限結構 |
|------|----------|
| **前方** | 恥骨聯合下支（inferior pubic ramus） |
| **側方** | 恥骨下支、坐骨支、**坐骨結節（ischial tuberosity）** |
| **後方** | **骶結節韌帶（sacrotuberous ligament）** |

### 會陰的兩區划分

會陰被一條想像的**經結節連線（intertubercular line）**分為兩個三角：

| 區域 | 範圍 | 包含結構 |
|------|------|----------|
| **尿生殖三角（Urogenital Triangle）** | 前 2/3 | 尿道（外口）、外生殖器、會陰淺隙/深隙 |
| **肛門三角（Anal Triangle）** | 後 1/3 | 肛門口、肛門括約肌、坐骨直腸窩 |

---

## 肛門三角（Anal Triangle）

### 肛門口（Anus）

- **位置**：肛門三角中央
- **結構**：肛管（anal canal）末端開口於體表
- **肛門自制**：肛門內括約肌（不隨意）+ **肛門外括約肌（external anal sphincter）**（隨意）

### 肛門外括約肌（External Anal Sphincter）

| 項目 | 說明 |
|------|------|
| **類型** | 橫紋肌（隨意肌） |
| **位置** | 環繞肛門管下段 |
| **神經支配** | **陰部神經（pudendal nerve, S2-S4）**的**肛門下神經（inferior anal nerve）** |
| **功能** | 隨意控制肛門关闭 |

### 坐骨直腸窩（Ischiorectal Fossa）

| 項目 | 說明 |
|------|------|
| **位置** | 肛門口兩側，介於**提肛肌（levator ani）**與**臀大肌**之間 |
| **形狀** | 楔形，尖向上，底向下 |
| **內容物** | 脂肪組織（潤滑與緩衝）、**陰部內动脉/靜脈**、**陰部神經**（Alcock's 管內） |
| **臨床意義** | 感染可擴散至對側（馬蹄形膿腫 horseshoe abscess） |

> **Alcock's 管（Alcock's Canal / Pudendal Canal）**：**陰部內动脉**與**陰部神經**通過的筋膜管，位於**閉孔內肌（obturator internus）**筋膜上。

---

## 尿生殖三角（Urogenital Triangle）

尿生殖三角的解剖結構可分為**會陰淺隙**與**會陰深隙**，兩者以**泌尿生殖膈（urogenital diaphragm）**分隔。

### 會陰淺隙（Superficial Perineal Pouch）

| 項目 | 說明 |
|------|------|
| **位置** | 介於**泌尿生殖膈（下層）**與**會陰淺筋膜（Colles' fascia）**之間 |
| **底/下界** | **會陰淺筋膜（Colles' fascia）**（ Scarpa's fascia 的延續） |
| **側壁** | 恥骨下支、坐骨支內面 |
| **完整性** | 為一封閉空間（男性：兩側相連；女性：尿道/陰道通過其中） |

#### 會陰淺隙內容物

| 肌肉 | 英文 | 功能 |
|------|------|------|
| **球海綿體肌（坐海綿體肌）** | Bulbospongiosus | 男性：壓迫尿道海綿體協助排尿/射精；女性：壓迫陰道前庭 |
| **坐骨海綿體肌** | Ischiocavernosus | 壓迫**陰莖/陰蒂海綿體**，協助維持勃起 |
| **會陰淺橫肌** | Superficial Transverse Perineal Muscle | 固定會陰體中心，加強盆底 |

> **會陰體（Perineal Body）**：會陰淺隙中線上的纤维肌肉組織，是多塊肌肉的共同附著點，對於維持肛門與尿道的正常位置至關重要。

#### 會陰淺筋膜（Colles' Fascia）

- **上層（深層）**：**會陰膜（perineal membrane）** = **泌尿生殖膈下層**
- **下層（淺層）**：**Colles' fascia**（ Scarpa's fascia 的延續）

### 會陰深隙（Deep Perineal Pouch）

| 項目 | 說明 |
|------|------|
| **位置** | 介於**泌尿生殖膈（上層）**與**泌尿生殖膈（下層/會陰膜）**之間 |
| **上界** | **尿生殖膈上層（superior fascia of urogenital diaphragm）** |
| **下界** | **會陰膜（perineal membrane）** = 尿生殖膈下層 |

#### 會陰深隙內容物

| 結構 | 英文 | 說明 |
|------|------|------|
| **外尿道括約肌（尿道外括約肌）** | External Urethral Sphincter / Sphincter Urethrae | 環繞尿道（男性：膜部尿道；女性：尿道通過尿生殖膈處） |
| **泌尿生殖膈（ urogenital diaphragm）** | Urogenital Diaphragm | 由**尿道外括約肌** + **上/下層筋膜**構成 |
| **尿道球腺（男性的）** | Bulbourethral Glands (Cowper's Glands) | 分泌鹼性液體，潤滑尿道 |

> **泌尿生殖膈（Urogenital Diaphragm）**：過去稱為「**三角韌帶（triangular ligament）**」，由**尿道外括約肌**及覆蓋其上下兩層的筋膜構成，封閉骨盆下口前方。

---

## 女性尿生殖三角的特點

| 結構 | 說明 |
|------|------|
| **尿道（Urethra）** | 長約 **3-4 cm**，向外向前開口於**陰道前庭（vestibule）** |
| **陰道（Vagina）** | 穿過泌尿生殖膈與會陰淺隙 |
| **陰蒂（Clitoris）** | 相當於男性的**陰莖（penis）**，由**陰蒂海綿體**構成 |
| **前庭球（Vestibular Bulbs）** | 相當於男性的**尿道海綿體**，位於陰道兩側 |
| **前庭腺（Bartholin's Glands）** | 位於陰道口兩側，分泌潤滑液 |

## 會陰的血管與神經

### 會陰的血液供應

| 血管 | 來源 | 支配區域 |
|------|------|----------|
| **陰部內动脉（Internal Pudendal Artery）** | 髂內动脉（Internal Iliac Artery） | 會陰主要供血 |
| **會陰动脉（Perineal Artery）** | 陰部內动脉 | 會陰淺層 |
| **肛門动脉（Inferior Rectal Artery）** | 陰部內动脉 | 肛門區域 |
| **陰莖/陰蒂背动脉（Dorsal Artery of Penis/Clitoris）** | 陰部內动脉 | 陰莖/陰蒂 |

### 會陰的神經支配

| 神經 | 來源 | 支配 |
|------|------|------|
| **陰部神經（Pudendal Nerve）** | **S2-S4**（骶叢） | 會陰主要感覺與運動神經 |
| **肛門下神經（Inferior Anal Nerve）** | 陰部神經分支 | 肛門外括約肌、肛門周圍皮膚 |
| **會陰神經（Perineal Nerve）** | 陰部神經分支 | 會陰淺層肌肉與皮膚 |
| **陰莖背神經（Dorsal Nerve of Penis）** | 陰部神經 | 陰莖/陰蒂感覺 |

> ⚠️ **陰部神經卡壓（Pudendal Nerve Entrapment）**：常因長期騎乘（cycling）或分娩造成，導致**陰部神經痛（pudendal neuralgia）**，表現為會陰部疼痛、感覺異常。

## 會陰的淋巴引流

| 區域 | 淋巴引流方向 |
|------|-------------|
| **肛門皮膚** | **腹股溝淺淋巴結（superficial inguinal nodes）** |
| **會陰皮膚** | 腹股溝淺淋巴結 |
| **陰道下 1/3** | 腹股溝淺淋巴結 |
| **陰道上 2/3** | 髂內淋巴結（internal iliac nodes） |
| **攝護腺** | 髂內/骶淋巴結（sacral nodes） |

## 臨床應用（Clinical Correlation）

### 🚨 會陰撕裂傷（Perineal Laceration）

分娩過程中最常見的損傷，按程度分為：

| 等級 | 說明 |
|------|------|
| **I 度** | 僅皮膚與陰道黏膜撕裂 |
| **II 度** | 涉及會陰體（但不達肛門括約肌） |
| **III 度** | 肛門括約肌**部分**撕裂（< 50% 厚度） |
| **IV 度** | 肛門括約肌**完全**撕裂 + 直腸黏膜 |
| **OASIS** | Obstetric Anal Sphincter Injuries = III 度 + IV 度 |

> **預防**：**會陰切開術（episiotomy）**可選擇性擴大出口，但常規使用仍有爭議。

### 🚨 肛門括約肌修復術（Anal Sphincter Repair）

- **適應症**：外傷性肛門括約肌撕裂（尤其是**OASIS**後修復失敗者）
- **方法**：重疊修復（overlapping repair）或端對端修復（end-to-end repair）
- **成功率**：約 50-80% 可恢復自制功能

### 🚨 前庭大囊腫（Bartholin's Cyst）

- **病因**：**前庭大腺（Bartholin's gland）**出口阻塞
- **位置**：陰道口兩側（後方）
- **處理**：囊腫引流、造口術（marsupialization）；必要時切除腺體

### 🚨 會陰疼痛綜合徵（Perineal Pain Syndrome）

- **病因**：慢性會陰損傷、神經卡壓、感染後
- **診斷**：排除其他疾病（痔瘡、肛裂、感染）
- **治療**：藥物（神經調節劑）、物理治療、神經阻斷
