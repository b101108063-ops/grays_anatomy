## 本章重點

- **髂總动脉（Common Iliac Artery）**分為**髂外动脉（External Iliac Artery）**（→下肢）與**髂內动脉（Internal Iliac Artery）**（→盆腔臟器）
- **髂內动脉（Internal Iliac Artery）**分支分為**壁支**（臀上/臀下动脉、閉孔动脉等）與**臟支**（膀胱上/下动脉、子宫动脉、直腸中动脉、陰部內动脉）
- **骨盆靜脈**與同行動脉同名，回流至**髂內靜脈**
- **腰骶叢（Lumbosacral Plexus, L4-S3）**分為**閉孔神經（obturator nerve）**、**股神經（femoral nerve）**、**坐骨神經（sciatic nerve）**、**臀上/臀下神經**
- **交感神經（T10-L2）**經**上腹下叢（hypogastric plexus）**支配盆腔；**副交感神經（S2-S4）**經**下腹下叢（inferior hypogastric plexus）**支配盆腔

---

## 髂總动脉（Common Iliac Artery）

### 起點與走行

| 項目 | 說明 |
|------|------|
| **起點** | **主動骻（Aorta）**在 **L4 椎體**水平分叉 |
| **終點** | 在**骶髂關節（sacroiliac joint）**前方分為髂外动脉與髂內动脉 |
| **長度** | 約 4-5 cm |
| **分支** | **髂腰动脉（iliolumbar artery）**（常見） |

### 髂總动脉分叉處的臨床意義

- **分叉角度**：左髂總动脉較右側更向前傾斜
- **臨床**：腹主动脉瘤、髂總动脉瘤的手術評估需注意此處解剖關係

---

## 髂外动脉（External Iliac Artery）

| 項目 | 說明 |
|------|------|
| **主要功能** | 為**下肢**供血 |
| **終點** | 在**腹股溝韌帶（inguinal ligament）**下方穿出改稱為**股动脉（femoral artery）** |
| **重要分支** | **腹壁下动脉（inferior epigastric artery）**、**旋髂深动脉（deep circumflex iliac artery）** |

> **腹壁下动脉（Inferior Epigastric Artery）**：與**睪丸/卵巢动脉**在胎兒期的吻合退化有關，是**腹股溝直疝（direct inguinal hernia）**與**腹股溝斜疝（indirect inguinal hernia）**鑑別的重要參考標誌。

---

## 髂內动脉（Internal Iliac Artery）

### 概述

| 項目 | 說明 |
|------|------|
| **主要功能** | 為**盆腔臟器**、**骨盆壁**、**臀部**供血 |
| **起點** | 髂總动脉分叉，約在**骶髂關節**前方 |
| **長度** | 約 3-4 cm |
| **走行** | 向後下方走行，進入盆腔 |

### 髂內动脉分支

髂內动脉分為**壁支（parietal branches）**與**臟支（visceral branches）**：

#### 壁支（Parietal Branches）

| 分支 | 英文 | 說明 |
|------|------|------|
| **髂腰动脉** | Iliolumbar Artery | 供血髂肌、腰大肌、腰方肌 |
| **骶外側动脉** | Lateral Sacral Arteries | 通常有上下兩支，供血骶骨、硬膜、馬尾 |
| **臀上动脉** | Superior Gluteal Artery | 穿過**梨狀肌上孔（suprapiriform foramen）**→臀部 |
| **臀下动脉** | Inferior Gluteal Artery | 穿過**梨狀肌下孔（infrapiriform foramen）**→臀部 |
| **閉孔动脉** | Obturator Artery | 穿過**閉孔**→大腿內側 |

> ⚠️ **臀上动脉**與**臀下动脉**均穿過**坐骨大切跡**，是臀區域最粗大的血管，手術時需特別注意。

#### 臟支（Visceral Branches）

| 分支 | 英文 | 供血區域 |
|------|------|----------|
| **膀胱上动脉** | Superior Vesical Artery | 膀胱上半部（來自**臍动脉 umbilical artery**未閉部分） |
| **膀胱下动脉** | Inferior Vesical Artery | 膀胱下半部、攝護腺（男性） |
| **子宫动脉** | Uterine Artery | 子宮（女性） |
| **直腸中动脉** | Middle Rectal Artery | 直腸中段、攝護腺（男性） |
| **陰部內动脉** | Internal Pudendal Artery | 會陰、外生殖器 |

> **臍动脉（Umbilical Artery）**：胎兒期為主要供血通道，出生後遠側段退化為**膀胱上动脉（近側段）**與**膀胱臍韌帶（medial umbilical ligament）**（遠側段）。

## 骨盆靜脈（Pelvic Veins）

### 靜脈回流原則

| 原則 | 說明 |
|------|------|
| **同名回流** | 骨盆靜脈與同行動脉同名（膀胱上靜脈 superior vesical vein 等） |
| **髂內靜脈** | 所有盆腔臟器靜脈回流至**髂內靜脈（internal iliac vein）** |
| **髂總靜脈** | 左、右髂內靜脈 + 髂外靜脈 → **髂總靜脈（common iliac vein）** |
| **下腔靜脈** | 左右髂總靜脈 → **下腔靜脈（IVC）** |

### 重要靜脈吻合

| 吻合 | 說明 |
|------|------|
| **椎靜脈叢（Batson's Plexus）** | 盆腔與脊椎靜脈之間的吻合，**攝護腺癌**可經此轉移至脊椎 |
| **直腸靜脈叢** | 上直腸靜脈（腸系膜下靜脈→肝門靜脈）↔ 中/下直腸靜脈（髂內靜脈）→**門-腔靜脈吻合** |
| **卵巢/睪丸靜脈** | 右側 → 下腔靜脈；左側 → 左腎靜脈 |

> **椎靜脈叢（Batson's Plexus）**：位於椎管內外，無靜脈瓣，靜脈血可雙向流動。是攝護腺癌、乳癌、肺癌等實體瘤轉移至脊椎或顱內的重要途徑。

## 腰骶叢（Lumbosacral Plexus, L4-S3）

腰骶叢是**腰叢（Lumbosacral Plexus）**的延續，由**L4、L5、S1、S2、S3** 脊神經前支組成。

### 腰骶叢的主要分支

| 神經 | 英文 | 主要來源 | 終點/支配 |
|------|------|----------|------------|
| **閉孔神經** | Obturator Nerve | L2-L4 | 內收肌群（大腿內側）；皮支→大腿內側皮膚 |
| **股神經** | Femoral Nerve | L2-L4 | 髂腰肌、縫匠肌、股四頭肌；皮支→小腿內側（隱神經） |
| **坐骨神經** | Sciatic Nerve | **L4-S3**（最粗大神經） | 分為**脛神經（Tibial N., L4-S3）**與**總腓神經（Common Peroneal N., L4-S2）**；支配大腿後側與全部小腿/足部肌肉 |
| **臀上神經** | Superior Gluteal Nerve | L4-S1 | 臀中肌、臀小肌、闊筋膜張肌 |
| **臀下神經** | Inferior Gluteal Nerve | L5-S2 | 臀大肌 |

### 坐骨神經（Sciatic Nerve）

| 項目 | 說明 |
|------|------|
| **組成** | **L4-S3** 前支匯聚而成，是體內最粗大的神經 |
| **走行** | 穿過**坐骨大孔（greater sciatic foramen）**→**梨狀肌下孔（infrapiriform foramen）**→大腿後側 |
| **分叉** | 通常在**腘窩（popliteal fossa）**上方分為**脛神經**與**總腓神經**（約 30% 在盆腔內即分叉） |
| **臨床意義** | 腰椎間盤突出（尤其是 **L4/L5**、**L5/S1**）可壓迫坐骨神經，導致**坐骨神經痛（sciatica）** |

### 閉孔神經（Obturator Nerve）

| 項目 | 說明 |
|------|------|
| **組成** | **L2-L4** |
| **走行** | 沿腰大肌內側緣下行 → 穿**閉膜管（obturator canal）**→大腿 |
| **運動支配** | **閉孔外肌（obturator externus）**、**內收肌群（adductors）**：長收肌、短收肌、大收肌、股薄肌 |
| **感覺支配** | 大腿內側皮膚（偶有變異） |
| **臨床意義** | 閉孔疝（obturator hernia）可壓迫此神經，引起大腿內側疼痛 |

## 自主神經系統（Autonomic Nervous System）— 盆腔支配

盆腔的自主神經支配分為**交感神經**與**副交感神經**兩部分：

### 交感神經（Sympathetic Innervation）

| 項目 | 說明 |
|------|------|
| **節前神經元胞體** | **T10-L2**（脊髓側角） |
| **投射途徑** | 交感神經節 → 內臟神經 → **上腹下叢（Superior Hypogastric Plexus）** |
| **功能** | 抑制排尿（內尿道括約肌收縮）、促進射精、血管收縮 |
| **路徑** | 節前纖維在**椎旁交感神經節（paravertebral ganglia）**或**椎前交感神經節（prevertebral ganglia）**更換神經元 |

### 副交感神經（Parasympathetic Innervation）

| 項目 | 說明 |
|------|------|
| **節前神經元胞體** | **S2-S4**（脊髓灰質側角） |
| **投射途徑** | 節前纖維經**盆神經（Pelvic Splanchnic Nerves, S2-S4）**→**下腹下叢（Inferior Hypogastric Plexus）** |
| **功能** | 促进排尿（逼尿肌收縮）、促进勃起、促進分泌 |
| **更換神經元** | 在盆腔器官壁內的神經節更換神經元（不經椎旁/椎前節） |

### 腹下叢（Hypogastric Plexuses）

| 叢 | 位置 | 功能 |
|------|------|------|
| **上腹下叢（Superior Hypogastric Plexus）** | **L5/S1** 椎體前方，的主動脈分叉下方 | 接收交感神經（T10-L2）；分配至左、右下腹下叢 |
| **左/右下腹下叢** | 直腸/膀胱兩側，子宮闊韌帶內 | 混合交感、副交感與感覺神經；直接支配盆腔臟器 |

> **臨床意義**：**上腹下叢阻斷（superior hypogastric plexus block）**可用於治療慢性盆腔疼痛或緩解重度痛經。

## 骨盆神經的臨床相關性

### 髂內动脉結紮（Internal Iliac Artery Ligation）

- **適應症**：盆腔出血、子宮陰道出血、無法控制的產後出血
- **效果**：減少約 85% 的盆腔血流量（因側支循環豐富）
- **側支路徑**：對側髂內动脉、卵巢动脉、直腸中动脉等

### 閉孔神經損傷（Obturator Nerve Injury）

| 病因 | 說明 |
|------|------|
| **骨盆腔手術** | 子宮切除術、直腸手術時直接損傷 |
| **股骨頭骨折** | 骨碎片壓迫 |
| **生產** | 胎頭壓迫（短暫性） |

**症狀**：大腿內側感覺異常 + 內收無力（行走障礙）

### 骨盆帶神經痛（Pelvic girdle nerve pain）

- **病因**：懷孕期間激素導致韌帶鬆弛，壓迫神經
- **好發神經**：**閉孔神經**、**股神經**
- **治療**：物理治療、局部注射、藥物

---

## 臨床應用（Clinical Correlation）

### 🚨 子宮动脉栓塞術（Uterine Artery Embolization, UAE）

- **適應症**：**子宫肌瘤（uterine leiomyoma）**、產後出血
- **方法**：經股动脉穿刺，置管至子宫动脉，注入栓塞物質
- **原理**：阻斷肌瘤血供使其萎縮；正常子宫肌層可通過側支循環存活
- **優點**：微創、保留子宫
- **併發症**：栓塞後綜合徵（腹痛、發燒、噁心）、卵巢功能減退

### 🚨 攝護腺癌的神經保留手術（Nerve-Sparing Radical Prostatectomy）

- **解剖基礎**：**前列腺周圍神經血管叢（prostatic neurovascular bundle）**位於攝護腺後外側，包含**副交感神經（S2-S4）**（勃起功能）與**交感神經**（射精功能）
- **目的**：在切除攝護腺的同時保留神經，維持術後勃起功能
- **挑戰**：癌症切除完整性與功能保留之間的平衡

### 🚨 陰部神經卡壓症候群（Pudendal Nerve Entrapment Syndrome）

| 項目 | 說明 |
|------|------|
| **病因** | 長期騎乘（自行車、摩托車）、分娩、慢性便秘 |
| **卡壓部位** | **Alcock's 管（pudendal canal）** |
| **症狀** | **會陰部疼痛（慢性）**、感覺異常、肛門/尿道功能障礙 |
| **診斷** | 排除性診斷；陰部神經傳導檢查 |
| **治療** | 保守治療（物理治療、藥物）、神經阻斷、微創減壓手術 |
