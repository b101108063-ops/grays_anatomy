## 本章重點

- **子宫（Uterus）**位於骨盆腔中央，呈前傾前屈位，主要韌帶為**主韌帶（cardinal ligament）**與**圓韌帶（broad ligament）**
- **卵巢（Ovary）**血液供應來自**卵巢动脉（ovarian artery）**（主動骻）和**子宫动脉**卵巢支
- **輸卵管（Uterine Tube）**分為間質部、峽部、壺腹部、漏斗部，**壺腹部**是宮外孕最常見部位
- **陰道（Vagina）**前壁約 4 cm、後壁約 7 cm，子宮頸周圍形成**陰道穹（fornix）**
- 子宫动脉是**髂內动脉（internal iliac artery）**的分支，在輸尿管下方跨過

## 子宮（Uterus）

### 位置與姿勢

| 特徵 | 說明 |
|------|------|
| **位置** | 骨盆腔中央，膀胱與直腸之間 |
| **姿勢** | **前傾（anteverted）**：子宫長軸與陰道長軸呈向前 90°<br>**前屈（anteflexed）**：子宫體與子宫頸之間向前彎曲 |
| **正常傾角** | 子宮底向前向下，宮頸向下向後 |

### 子宮分部

| 部分 | 英文 | 說明 |
|------|------|------|
| **子宫底** | Fundus | 子宮最上方，輸卵管附著處以上 |
| **子宫體** | Body | 子宮的主要部分，受精卵著床處 |
| **子宫峽部** | Isthmus | 體與頸之間的狹窄部，懷孕時可擴張 |
| **子宫頸** | Cervix | 子宮下端，突入陰道上部（陰道部 cervical portio） |

### 子宮韌帶

| 韌帶 | 英文 | 起始 | 終止 | 功能 |
|------|------|------|------|------|
| **闊韌帶** | Broad Ligament | 子宮兩側 | 盆腔側壁 | 包覆輸卵管、子宮血管、神經 |
| **圓韌帶** | Round Ligament | 子宮底前外側 | 腹股溝管深環 → 大陰唇 | 維持子宫前傾 |
| **卵巢韌帶** | Ovarian Ligament | 子宮後外側 | 卵巢內側 | 固定卵巢 |
| **卵巢懸韌帶**（骨盆漏斗韌帶） | Suspensory Ligament of Ovary / Infundibulopelvic Ligament | 卵巢上端 | 骨盆側壁 | 含卵巢血管 |
| **恥骨宮頸韌帶** | Pubocervical Ligament | 恥骨內面 | 子宮頸前外側 | 支撐膀胱底 |
| **主韌帶**（Mackenrodt's ligament） | Cardinal Ligament / Transverse Cervical Ligament | 子宮頸 / 陰道上部外側 | 盆腔側壁（肛門提肌腱弓） | **最重要的支撐韌帶**，防止子宫脫垂 |
| **骶子官韌帶** | Uterosacral Ligament | 子宮頸後外側 | 骶骨前面 | 維持子宫後傾 |

> **臨床重點**：**主韌帶（Cardinal Ligament）**是防止子宫脫垂的最重要結構，包含子宫动脉、靜脈與神經。

### 子宮的血液供應

| 血管 | 來源 | 說明 |
|------|------|------|
| **子宫动脉（Uterine Artery）** | 髂內动脉（Internal Iliac Artery） | 在**輸尿管（ureter）**下方橫向跨過，於子宫頸旁形成**輸尿管隧道（ureteric tunnel）** |
| **卵巢动脉（Ovarian Artery）** | 主動脈（Abdominal Aorta） | 經卵巢懸韌帶進入卵巢，與子宫动脉吻合 |

> ⚠️ **解剖危險區**：子宫动脉與輸尿管在**輸尿管口（ureteric orifice）**附近關係密切，子宮切除術時需小心避免損傷輸尿管。

### 子宮的淋巴引流

| 區域 | 淋巴引流方向 |
|------|-------------|
| 子宮底 / 子宮體 | 沿卵巢血管 → **腰淋巴結（lumbar lymph nodes）** |
| 子宮頸 | 沿子宫动脉 → **髂內 / 髂外淋巴結（internal/external iliac nodes）**；經閉孔神經血管 → **閉孔淋巴結（obturator nodes）** |

## 卵巢（Ovary）

### 形態與位置

| 項目 | 說明 |
|------|------|
| **形狀** | 扁橢圓形，似杏仁 |
| **大小** | 約 4 × 3 × 1 cm |
| **位置** | **卵巢窩（Ovarian Fossa）**：位於盆腔側壁，介於髂內动脉與子宫动脉之間 |
| **固定結構** | 卵巢懸韌帶、卵巢韌帶、卵巢系膜（mesovarium，闊韌帶後層） |

### 血液供應

| 血管 | 來源 | 靜脈回流 |
|------|------|----------|
| **卵巢动脉（Ovarian Artery）** | 主動脈（腎动脉下方） | 右側 → **下腔靜脈（IVC）** |
| | | 左側 → **左腎靜脈（Left Renal Vein）** |

> **臨床意義**：左側卵巢靜脈回流至左腎靜脈，因此**左側卵巢靜脈曲張（left ovarian varicocele）**較少見，但若發生則可能與左腎靜脈受壓有關。

### 功能

- **排卵（Ovulation）**：每月釋放成熟卵子
- **內分泌**：分泌**雌激素（estrogen）**與**黃體素（progesterone）**

## 輸卵管（Uterine Tube / Fallopian Tube）

### 分部（由內至外）

| 部分 | 英文 | 位置 | 說明 |
|------|------|------|------|
| **間質部** | Interstitial / Intramural | 子宮壁內 | 最窄部，長約 1 cm |
| **峽部** | Isthmus | 子宮與卵巢之間 | 壁厚腔窄，結紮部位 |
| **壺腹部** | Ampulla | 卵巢附近 | 管腔最大，**宮外孕最常見部位** |
| **漏斗部** | Infundibulum | 最外側 | 呈漏斗狀，末端為**輸卵管腹腔口（abdominal ostium）** |

### 結構特徵

- 全長約 **10-12 cm**
- 漏斗部邊緣有多個**傘狀突起（fimbriae）**，可捕捉排卵後的卵子
- 管壁由**黏膜層**（纖毛上皮）、**肌肉層**、**漿膜層**組成

## 陰道（Vagina）

### 形態學

| 項目 | 說明 |
|------|------|
| **長度** | 前壁：約 **4 cm**<br>後壁：約 **7 cm**（因、子宮頸突入） |
| **走向** | 向上向後，與水平面呈約 **60-65°** |
| **口徑** | 未擴張時前後壁相接，呈 H 形橫切面 |

### 陰道穹（Fornix）

陰道围绕子宫頸形成四個隱窩：

| 部位 | 英文 | 臨床意義 |
|------|------|----------|
| **前穹** | Anterior Fornix | 較淺 |
| **後穹** | Posterior Fornix | **最深**，可经此進行盆腔穿刺（culdocentesis） |
| **左/右穹** | Lateral Fornices | 臨床上較少单独提及 |

> **後穹（Posterior Fornix）**是盆腔最低點之一，腹腔積液（如血液）首先積聚於此，是陰道檢查或穿刺的重要途徑。

### 陰道的血液供應

| 血管 | 來源 |
|------|------|
| **子宫动脉陰道支** | 髂內动脉 → uterine artery |
| **陰部內动脉（Internal Pudendal Artery）** | 髂內动脉 → internal pudendal artery |
| **直腸中动脉（Middle Rectal Artery）** | 髂內动脉 → middle rectal artery |

## 臨床應用（Clinical Correlation）

### 🚨 宮外孕（Ectopic Pregnancy）

最常見的宮外孕部位為**輸卵管的壺腹部（ampulla）**：

| 項目 | 說明 |
|------|------|
| **發生率** | 約 1-2% 的妊娠 |
| **最常見部位** | **壺腹部（~70%）**、峽部、間質部 |
| **危險因素** | 輸卵管炎（PID）、手術史、子宮內膜異位症 |
| **症狀** | 腹痛、子宮出血、暈厥（破裂性宮外孕） |
| **診斷** | 超音波（TVUS）+ β-hCG |
| **緊急處理** | 破裂性宮外孕 → 手術；未破裂 → Methotrexate 或手術 |

### 🚨 子宮脫垂（Uterine Prolapse）

子宫沿陰道向下脫落，可分為：

| 等級 | 描述 |
|------|------|
| **I 度** | 子宫頸降至陰道上 1/3 |
| **II 度** | 子宮頸脫出陰道口 |
| **III 度** | 子宮體與頸均脫出陰道口（完全脫垂） |
| **IV 度** | 子宮與陰道完全脫出 |

**病因**：主韌帶與骨盆底肌肉薄弱（多次分娩、衰老、、慢性咳嗽）
**治療**：骨盆底訓練、子宮托（pessary）、手術（骶棘韌帶固定術 sacrospinous fixation）

### 🚨 子宮肌瘤（Uterine Leiomyoma）

- **發生率**：30-50 歲女性最常見的良性腫瘤
- **好發部位**：子宫體（體部），可分為：
  - **黏膜下肌瘤（Submucosal）**：向內突向宮腔
  - **肌層內肌瘤（Intramural）**：最常見
  - **漿膜下肌瘤（Subserosal）**：向外突向腹腔
- **症狀**：經血過多、骨盆腔疼痛、壓迫症狀（頻尿、便祕）
