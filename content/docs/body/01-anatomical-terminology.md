## 概述

**解剖學術語（Anatomical Terminology）** 是描述人體結構、位置與運動的標準化語言。這套術語系統確保醫療專業人員在全球各地都能精確溝通，避免因語言差異而造成的誤解。本章節將系統性地介紹這些基本概念，為後續各章節的學習奠定基礎。

---

## 一、解剖學方位術語（Directional Terms）

方位術語用於描述結構之間的相對位置關係，是解剖學最基本的描述工具。

### 1.1 主要方位術語

| 術語（英文） | 中文 | 定義 | 範例 |
|-------------|------|------|------|
| **Anterior** | 腹側 | 朝向身體前面 | 眼睛位於鼻子前方 |
| **Posterior** | 背側 | 朝向身體後面 | 脊椎位於胸部後方 |
| **Superior** | 上方 | 朝向頭部/較高位置 | 頭部位於頸部上方 |
| **Inferior** | 下方 | 朝向足部/較低位置 | 胃位於橫膈下方 |
| **Medial** | 內側 | 朝向身體正中線 | 心臟位於胸腔內側 |
| **Lateral** | 外側 | 遠離身體正中線 | 小指位於手部外側 |
| **Proximal** | 近端 | 接近軀幹/附肢附著處 | 肘關節是前臂的近端 |
| **Distal** | 遠端 | 遠離軀幹/附肢附著處 | 手腕是前臂的遠端 |
| **Superficial** | 淺層 | 接近體表 | 皮膚位於肌肉淺層 |
| **Deep** | 深層 | 遠離體表 | 骨骼位於肌肉深層 |

### 1.2 對應術語（Equivalent Terms）

某些解剖學術語在不同上下文或解剖區域中有特定對應關係：

| 術語 | 對應詞 | 應用情境 |
|------|--------|----------|
| **Ventral** = Anterior | 腹側 = 前側 | 主要用於人類描述 |
| **Dorsal** = Posterior | 背側 = 後側 | 主要用於人類描述 |
| **Rostral** = Superior | 嘴側 = 上方 | 腦部描述（朝向鼻子方向） |
| **Caudal** = Inferior | 尾側 = 下方 | 朝向脊椎/尾部方向 |

::: {.content-box .clinical}
## 臨床應用（Clinical Correlation）

在臨床工作中，精確使用方位術語至關重要：

- **病史記錄**：患者主訴「腹痛」時，需確認是「右上腹痛（right upper quadrant pain）」還是「左下腹痛（left lower quadrant pain）」，不同位置可能暗示不同疾病
- **體格檢查**：描述傷口位置時使用「膝關節遠端3公分」比「膝蓋下面」更精確
- **手術記錄**：外科醫師需精確記錄病變的「內側」或「外側」位置，以指導後續治療
- **影像報告**：放射科醫師使用標準方位術語描述病變，確保臨床醫師能準確理解
:::

## 二、身體平面（Body Planes）

身體平面是用來描述或切割人體的虛擬三維平面，對應解剖學教育和臨床影像學都極為重要。

### 2.1 三大基本平面

| 平面（英文） | 中文 | 定義 | 臨床應用 |
|-------------|------|------|----------|
| **Coronal Plane** | 冠狀面 | 垂直於矢狀面，將身體分為前後兩部分 | CT、MRI橫斷面；面部手術 |
| **Sagittal Plane** | 矢狀面 | 垂直於地面，將身體分為左右兩部分 | 脊椎側面影像；關節側面評估 |
| **Transverse Plane** | 橫切面 | 水平切割身體，分為上下兩部分 | 超聲、CT軸向影像 |

### 2.2 特殊平面

- **正中矢狀面（Median Sagittal Plane）**：特殊的矢狀面，通過身體正中線，將身體分為左右對稱的兩半
- ** parasagittal plane（旁矢狀面）**：平行於正中矢狀面但不通過正中線

::: {.content-box .clinical}
## 臨床應用（Clinical Correlation）

**影像學中的身體平面**：

- **CT（電腦斷層）**：通常提供橫切面（transverse）影像，臨床醫師需在腦中重建三維結構
- **MRI（磁振造影）**：可選擇任意平面掃描，根據臨床需求選擇最優平面
- **超聲波（Ultrasound）**：即時調整探頭方向，獲取所需平面影像
- **手術入路**：外科醫師根據病變位置選擇最適當的手術平面，以微創方式達成治療目標
:::

## 三、運動術語（Movement Terms）

運動術語描述關節的活動方式，是理解肌肉功能和關節病理的基礎。

### 3.1 基本運動術語

| 運動（英文） | 中文 | 描述 |
|-------------|------|------|
| **Flexion** | 屈 | 減少關節角度 |
| **Extension** | 伸 | 增加關節角度 |
| **Abduction** | 外展 | 向正中線外側移動 |
| **Adduction** | 內收 | 向正中線內側移動 |
| **Medial Rotation** | 內旋 | 向內旋轉 |
| **Lateral Rotation** | 外旋 | 向外旋轉 |
| **Circumduction** | 環繞運動 | 遠端做圓周運動 |

### 3.2 特殊運動

| 運動 | 中文 | 說明 |
|------|------|------|
| **Supination** | 旋後 | 前臂手掌朝上（仰臥位） |
| **Pronation** | 旋前 | 前臂手掌朝下（俯臥位） |
| **Dorsiflexion** | 背屈 | 踝關節向上屈曲 |
| **Plantar Flexion** | 蹠屈 | 踝關節向下伸展 |

::: {.content-box .clinical}
## 臨床應用（Clinical Correlation）

**運動評估（Range of Motion Assessment）**：

- 關節活動度測量是骨科和復健科的基本檢查
- **正常範圍**：肩關節外展約0-180°、肘關節屈曲約0-150°
- **活動受限**可能暗示：關節炎、肌肉攣縮、神經損傷
- **運動傷害**：前十字韌帶（ACL）損傷導致膝關節不穩；旋轉袖（rotator cuff）損傷影響肩關節外展和旋轉
- **術後復健**：精確記錄運動術語有助於追蹤康復進度
:::

## 四、總結與臨床整合

解剖學術語是醫學溝通的基礎，精確使用這些術語能確保：

1. **病史採集**：準確記錄症狀位置和特性
2. **體格檢查**：系統性描述發現
3. **影像學報告**：標準化解讀和溝通
4. **手術記錄**：精確定位和技術描述
5. **學術交流**：國際通用的標準語言

::: {.content-box .key-points}
## 學習要點

- **方位術語**是描述人體結構相對位置的基本工具
- **身體平面**幫助我們在三維空間中定位結構
- **運動術語**使我們能精確描述關節活動範圍
- 這些術語在臨床各領域（病史、檢查、影像、手術）中都有重要應用
:::
