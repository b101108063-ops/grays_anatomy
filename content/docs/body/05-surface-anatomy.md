## 本章重點

- 表面解剖標誌是定位深層結構的參考點
- 頭頸部的眶上孔、眶下孔、頦孔是三叉神經麻醉的常見部位
- 腹部九分法有助於定位內臟和描述腹痛位置
- 脊椎定位可通過C7突起、肩胛骨下角、髂嵴最高點確認
- 掌握表面解剖能提高臨床檢查和操作的準確性
:::

## 概述

**表面解剖學（Surface Anatomy）**是研究人體表面特徵與深層結構之間關係的學科。掌握表面解剖對於**病史採集（疼痛位置的描述）**、**身體檢查（觸診和叩診）**、**侵入性操作（穿刺、注射、放置引流管）**以及**醫學影像的解讀**都至關重要。本章將系統回顧全身重要的表面解剖標誌。

---

## 一、頭頸部（Head and Neck）

### 1.1 顏面部重要孔洞

頭頸部的感覺神經主要來自**三叉神經（Trigeminal Nerve, CN V）**，其三個分支的出口可用於定位和麻醉：

| 孔洞名稱 | 英文 | 位置 | 供應神經 |
|----------|------|------|----------|
| **眶上孔** | Supraorbital Foramen | 眶上緣中線 | 眶上神經（V1） |
| **眶下孔** | Infraorbital Foramen | 眶下緣下方 | 眶下神經（V2） |
| **頦孔** | Mental Foramen | 下頜骨體部 | 頦神經（V3） |

**臨床應用**：這些孔洞是進行**三叉神經阻斷（Trigeminal Nerve Block）**的常用部位，可用於面部疼痛治療或手術麻醉。

### 1.2 下頜骨重要標誌

| 標誌 | 英文 | 位置 | 臨床意義 |
|------|------|------|----------|
| **下頜角** | Mandibular Angle | 下頜骨後下角 | 下頜骨骨折好發部位 |
| **髁突** | Condylar Process | 顴弓下方 | 顳顎關節（TMJ）所在 |
| **冠狀突** | Coronoid Process | 髁突前方 | 咀嚼肌附著 |
| **下頜切跡** | Mandibular Notch | 髁突與冠突之間 | 下齒槽神經通過 |

### 1.3 頸部重要結構

| 結構 | 英文 | 位置 | 臨床意義 |
|------|------|------|----------|
| **胸鎖乳突肌** | Sternocleidomastoid | 頸部兩側 | 頸部手術定位頸三角 |
| **鎖骨** | Clavicle | 頸根與肩部之間 | 創傷、連接肩帶 |
| **胸骨上切跡** | Suprasternal Notch | 胸骨上方 | 氣管切開術定位（胸骨上緣2指寬） |
| **甲狀腺軟骨** | Thyroid Cartilage | 甲狀腺上方 | 甲狀腺手術標誌 |
| **環狀軟骨** | Cricoid Cartilage | 甲狀腺軟骨下方 | 氣管切開術定位（環狀軟骨下緣） |

::: {.content-box .clinical}
## 臨床應用（Clinical Correlation）

**氣管切開術（Tracheostomy）的定位**：
- 傳統氣管切開：環狀軟骨下緣下方1-2指寬（約2-3公分）
- 微創氣管切開：可用支氣管鏡或超聲波輔助定位
- 重要結構：甲狀腺峽部位於2-4氣管環前方，需小心處理

**頸部淋巴結評估**：
- 頭頸部癌症分期的重要檢查
- 評估重點：大小、質地（堅硬/柔軟）、壓痛、可移動性
- 肺癌和乳癌常轉移至鎖骨上淋巴結
:::

## 二、胸部（Thorax）

### 2.1 胸壁肌肉輪廓

胸部的肌肉和骨骼輪廓在瘦人和肌肉發達者身上特別明顯：

| 結構 | 英文 | 位置 |
|------|------|------|
| **胸大肌** | Pectoralis Major | 胸前壁， 男性肌肉發達時輪廓明顯 |
| **前鋸肌** | Serratus Anterior | 胸廓外側，「肩胛骨翼」時可見 |
| **鎖骨** | Clavicle | 連接胸骨和肩峰 |
| **肋骨** | Ribs | 可在瘦人胸部看到弧度 |

### 2.2 鎖骨中線

| 標誌線 | 英文 | 位置 |
|--------|------|------|
| **鎖骨中線** | Midclavicular Line | 通過鎖骨中點的垂直線 |
| **腋窩中線** | Midaxillary Line | 通過腋窩中點的垂直線 |

**心臟叩診的參考**：
- 心臟左側界：正常在鎖骨中線內側
- 心尖搏動：正常在左第5肋間、鎖骨中線內側

### 2.3 腋窩（Axilla）

腋窩是頸部與上肢之間的重要區域，包含重要的神經、血管和淋巴結：

| 結構 | 臨床意義 |
|------|----------|
| **腋动脉** | 上肢的主要供血血管 |
| **臂神經叢** | 上肢運動和感覺神經 |
| **腋淋巴結** | 乳房、上肢的淋巴回流 |

**腋窩境界**：
- 前界：胸大肌、胸小肌
- 後界：背闊肌、大圓肌
- 內側界：前鋸肌
- 外側界：肱二頭肌、喙肱肌

::: {.content-box .clinical}
## 臨床應用（Clinical Correlation）

**乳房自我檢查的表面標誌**：
- 乳房外上象限是**乳癌（Breast Cancer）**最常見的位置
- 乳頭和乳暈位於約第4肋間
- 乳房尾葉（Tail of Spence）延伸至腋窩

**心肺復甦術（CPR）的定位**：
- 胸部按壓位置：兩乳頭連線中點（胸骨中下1/3交界）
- 按壓深度：5-6公分
- 按壓速率：100-120次/分

**胸腔穿刺（Thoracentesis）的定位**：
- 通常在**腋後線或肩胛線第7-8肋間**
- 避免在第5肋間以下，以免損傷肝臟或脾臟
- 穿刺時上緣肋骨下緣進針（避免損傷肋間血管神經）
:::

## 三、腹部（Abdomen）

### 3.1 腹部九分法（Nine Regions）

為便於描述腹痛位置和內臟定位，腹部可分為**九分法（Nine Regions）**：

| 分區 | 中文 | 英文 | 主要內臟 |
|------|------|------|----------|
| **上腹部** | 右季肋部 | Right Hypochondrium | 肝臟、膽囊、右腎 |
| **中上腹** | 上腹部/心窩部 | Epigastrium | 胃、十二指腸、胰臟、肝臟 |
| **左季肋部** | 左季肋部 | Left Hypochondrium | 脾臟、左腎、胃 |
| **右腰部** | 右外側腹 | Right Lumbar/Llank | 升結腸、右腎 |
| **臍部** | 臍周圍 | Umbilical | 小腸、橫結腸 |
| **左腰部** | 左外側腹 | Left Lumbar/Llank | 降結腸、左腎 |
| **右髂部** | 右下腹 | Right Iliac Fossa | 盲腸、蘭尾、右侧卵巢 |
| **下腹部** | 恥骨上部 | Suprapubic/Hypogastrium | 膀胱、子宮、直腸 |
| **左髂部** | 左下腹 | Left Iliac Fossa | 乙狀結腸、左側卵巢 |

### 3.2 麥氏點（McBurney's Point）

**麥氏點（McBurney's Point）**是臨床上定位**蘭尾（Appendix）**的重要表面標誌：

| 特性 | 說明 |
|------|------|
| **位置** | 臍與右髂前上棘連線的中外1/3交界點 |
| **壓痛** | 蘭尾炎時此點壓痛明顯 |
| **蘭尾炎徵狀** | 壓痛、反跳痛（Blumberg sign） |

### 3.3 恥骨聯合

| 結構 | 英文 | 臨床意義 |
|------|------|----------|
| **恥骨聯合** | Pubic Symphysis | 骨盆前壁連接處 |
| **恥骨嵴** | Pubic Crest | 腹股溝管淺環（皮下環）定位 |

**腹股溝管（Inguinal Canal）**：
- 位於腹股溝韌帶上方
- 男性：包含精索
- 女性：包含圓韌帶
- **腹股溝疝氣（Inguinal Hernia）**的發生部位

::: {.content-box .clinical}
## 臨床應用（Clinical Correlation）

**蘭尾炎的診斷要點**：
- **轉移性右下腹疼痛**：先兆部的隱約疼痛，數小時後轉移至右下腹
- **麥氏點壓痛**：蘭尾炎的經典體徵
- **反跳痛（Blumberg Sign）**：突然放手時疼痛加劇
- **輔助檢查**：腹部超聲或CT確診

**膽囊疾病的定位**：
- **膽囊位於右季肋部**
- **Murphy's Sign**：吸氣時按壓右季肋部，吸氣中斷為陽性（急性膽囊炎）
- 疼痛可放射至右肩胛骨

**腹主動脈的觸診**：
- 正常：可在臍部或略偏左觸及博動性腫塊
- **腹主動脈瘤（AAA）**：>3公分或有搏動性腫塊，需進一步影像檢查
- 超聲是首選篩檢工具
:::

## 四、四肢（Extremities）

### 4.1 上肢重要標誌

| 結構 | 英文 | 位置/說明 |
|------|------|-----------|
| **三角肌** | Deltoid | 肩部圓潤輪廓 |
| **肱二頭肌** | Biceps Brachii | 上臂前面，肌腹明顯 |
| **肱三頭肌** | Triceps | 上臂後面 |
| **尺骨鷹嘴** | Olecranon | 肘關節後方 |
| **腕横紋** | Wrist Creases | 掌側皺褶，遠端掌紋標示腕管位置 |
| **鼻窩圈** | anatomical snuffbox | 拇指根部背側，舟狀骨所在地 |

### 4.2 下肢重要標誌

| 結構 | 英文 | 位置/說明 |
|------|------|-----------|
| **髕骨** | Patella | 膝關節前方 |
| **髕腱** | Patellar Tendon | 髕骨下方 |
| **脛骨粗隆** | Tibial Tuberosity | 脛骨前面上方 |
| **踝關節內踝** | Medial Malleolus | 踝關節內側 |
| **踝關節外踝** | Lateral Malleolus | 踝關節外側，外踝較低 |
| **阿基里斯腱** | Achilles Tendon | 踝關節後方 |

### 4.3 主要神經血管走向

| 神經/血管 | 走向 | 臨床意義 |
|-----------|------|----------|
| **肱动脉** | 上臂內側→肘窩→橈側 | 血壓測量部位（肱动脉） |
| **橈动脉** | 腕橈側 | 腕橈側脈搏 |
| **股动脉** | 腹股溝韌帶中點下方 | 侵入性操作部位（穿刺、置管） |
| **腘动脉** | 膝關節後方 | 膝關節後方按摩時需注意 |
| **正中神經** | 上臂內側→前臂前方→掌心 | 腕隧道癥候群（CTS） |
| **尺神經** | 上臂內側→尺側腕屈肌→掌心尺側 | 尺骨管道壓迫 |

::: {.content-box .clinical}
## 臨床應用（Clinical Correlation）

**股动脉穿刺（Femoral Artery Puncture）**：
- 部位：腹股溝韌帶下方、股动脉博動處
- 定位：髂前上棘與恥骨結節連線的中點
- 併發症：出血、血腫、假性動脈瘤

**膝關節注射的定位**：
- 穿刺點：髕骨下緣、內側或外側關節線
- 穿刺路徑：從髕骨外側或內側向股骨踝方向進針

**踝關節注射的定位**：
- 前外側進路：踝關節前外側、距骨前方

**腕隧道（CarPal Tunnel）**：
- 界限：腕骨溝（掌側）和腕橫韌帶（屈肌支持帶）
- 內容物：正中神經和9條屈肌腱
- 腕隧道徵候群：正中神經受壓，表現為拇指側手掌麻痛感
:::

## 五、脊椎定位（Vertebral Levels）

脊椎的表面定位對於許多臨床操作至關重要：

### 5.1 可觸及的脊椎標誌

| 標誌 | 英文 | 對應脊椎水平 |
|------|------|--------------|
| **C7突起** | Vertebra Prominens | 頸椎C7，抬頭時最明顯的頸椎突起 |
| **肩胛骨下角** | Inferior Angle of Scapula | 約平T7（吸氣時可達T8） |
| **髂嵴最高點** | Highest Point of Iliac Crest | 約平L4 |
| **髂後上棘** | Posterior Superior Iliac Spine | 約平S2 |
| **尾骨尖** | Coccygeal Tip | 約平肛門括約肌區域 |

### 5.2 臨床重要的脊椎定位

| 結構/操作 | 對應水平 |
|-----------|----------|
| **甲狀腺** | C5-T1 |
| **氣管分岔** | T4-T5 |
| **食道通過橫膈** | T10 |
| **腹腔乾起始** | T12 |
| **腸繫膜上动脉起始** | L1 |
| **腸繫膜下动脉起始** | L3 |
| **主動脈分岔** | L4 |
| **宮底高度（足月）** | 劍突 |
| **腰穿刺部位** | L3-L4 或 L4-L5（避免損傷脊髓） |

::: {.content-box .clinical}
## 臨床應用（Clinical Correlation）

**腰穿刺（Lumbar Puncture）的定位**：
- 穿刺點：L3-L4 或 L4-L5 椎間隙
- 確認方法：兩側髂嵴最高點連線（約L4棘突上方）
- 成人脊髓終於L1-L2，不易損傷
- 穿刺深度：皮下→棘上韌帶→棘間韌帶→黃韌帶→硬膜外腔→硬膜→蛛網膜下腔

**中心靜脈導管置入（CVC）的定位**：
- 右側鎖骨下靜脈穿刺：氣管右側緣與鎖骨交界處
- 超聲波導引可提高成功率、降低併發症

**脊椎麻醉（Spinal Anesthesia）**的應用：
- 下腹部、下肢手術常用
- 藥物注入蛛網膜下腔（L2-L3以下）
- 需確認脊椎解剖位置
:::

## 六、表面解剖在內臟定位的應用

### 6.1 肝臟

| 特性 | 說明 |
|------|------|
| **位置** | 主要位於右上腹 |
| **上界** | 約平右側乳頭線第5肋間 |
| **下界** | 右側肋弓下緣 |
| **可觸及** | 深吸氣時可在右肋弓下緣觸及 |

### 6.2 脾臟

| 特性 | 說明 |
|------|------|
| **位置** | 左上腹 |
| **上界** | 約平左腋中線第9肋間 |
| **正常大小** | 約11公分長 |
| **正常不可觸及** | 除非病變增大 |

### 6.3 腎臟

| 特性 | 說明 |
|------|------|
| **位置** | 後腹膜腔，T12-L3 |
| **右腎** | 略低於左腎（肝臟壓迫） |
| **深度** | 距後正中線約6公分 |
| **腎移植觸診** | 前腹壁（術前評估捐贈者） |

### 6.4 子宮

| 特性 | 說明 |
|------|------|
| **位置** | 骨盆腔中央，膀胱與直腸之間 |
| **大小（非孕期）** | 約7x5x3 公分 |
| **孕期** | 宮底高度逐週增加 |
| **宮底高度（20週）** | 平臍 |
| **宮底高度（足月）** | 劍突 |

::: {.content-box .clinical}
## 臨床應用（Clinical Correlation）

**肝臟觸診（Liver Palpation）**：
- 雙手触診法：左手置於右季肋部，右手置於右下腹，向上推動
- 評估肝臟大小、質地（正常柔軟）、壓痛
- 硬肝：可能暗示肝硬化
- 壓痛：可能暗示肝炎或膿腫

**脾臟觸診（Splenomegaly）**：
- 正常脾臟在左肋弓下不可觸及
- 脾臟增大時：左肋弓下可觸及，质地較軟
- 病因：感染（單核細胞增多症）、門脈高壓、血液疾病

**腹膜炎的評估**：
- **腹部四個象限觸診**：檢查壓痛、反跳痛
- **板狀腹（Board-like Abdomen）**：腹壁肌肉痙攣，暗示腹膜炎
- 需緊急手術處理（闌尾炎穿孔、胃潰痬穿孔等）

**直腸指診（DRE）的臨床價值**：
- 可評估直腸腫瘤、肛門括約肌張力
- 男性：可觸及攝護腺
- 女性：可觸及子宫頸
- 糞便隱血檢查：有大腸癌篩檢
:::

## 七、總結與臨床整合

表面解剖知識的臨床應用可归纳為以下幾個方面：

| 應用領域 | 具體應用 |
|----------|----------|
| **病史採集** | 準確描述疼痛位置（如「右側麥氏點」） |
| **身體檢查** | 觸診肝脾、淋巴結、脈搏 |
| **侵入性操作** | 穿刺、注射、導管置入 |
| **影像學解讀** | 超聲、CT定位的參考 |
| **外科手術** | 切口規劃、入路選擇 |

::: {.content-box .key-points}
## 學習要點

- **頭頸部**：眶上孔、眶下孔、頦孔是三叉神經分支出口，臨床上常用於神經阻斷
- **胸部**：鎖骨中線是心臟叩診和心音聽診的參考線；腋窩包含重要的神經血管束
- **腹部**：九分法是定位內臟和描述腹痛的基本工具；麥氏點是蘭尾炎的經典型誌
- **四肢**：主要神經血管走向是侵入性操作的安全區域參考
- **脊椎定位**：C7、肩胛骨下角、髂嵴最高點是確認脊椎水平的重要觸診標誌
- 掌握表面解剖能提高臨床檢查的準確性和侵入性操作的安全性
:::
