## 本章重點

- 上皮組織依細胞層數和形狀分為多種類型
- 結締組織是最多樣化的組織類型
- 三種肌肉組織各有獨特的顯微特徵
- 神經組織由神經元和神經膠質細胞組成
- HE染色是組織學最基本和最常用的染色方法
:::

## 概述

**組織學（Histology）**是研究人體顯微結構的科學，是解剖學、病理學和臨床醫學的重要基礎。本章將介紹人體的四大基本組織：**上皮組織（Epithelium）**、**結締組織（Connective Tissue）**、**肌肉組織（Muscle Tissue）**和**神經組織（Nervous Tissue）**，並說明其顯微特徵和功能。

## 一、上皮組織（Epithelium）

### 1.1 上皮組織的特點

上皮組織覆蓋於體表或襯於體腔和器官內表面，具有以下特點：

| 特點 | 說明 |
|------|------|
| **細胞緊密排列** | 細胞多、細胞間質少 |
| **游離面** | 暴露於表面或管腔 |
| **基底面** | 附著於基底膜 |
| **無血管** | 營養來自下方結締組織 |
| **再生能力強** | 細胞更新快 |

### 1.2 上皮組織的分類

#### 根據細胞層數分類

| 類型 | 英文 | 說明 |
|------|------|------|
| **單層上皮** | Simple Epithelium | 一層細胞 |
| **複層上皮** | Stratified Epithelium | 多層細胞 |
| **假複層上皮** | Pseudostratified Epithelium | 看似多層，實際只有一層 |

#### 根據細胞形狀分類

| 形狀 | 英文 | 特點 |
|------|------|------|
| **鱗狀上皮** | Squamous | 扁平，核橢圓形位於中央 |
| **立方上皮** | Cuboidal | 方形，核圓形位於中央 |
| **柱狀上皮** | Columnar | 高方形，核橢圓形位於基部 |

### 1.3 臨床上皮的主要類型

| 上皮類型 | 分布 | 功能 |
|----------|------|------|
| **簡單鱗狀上皮** | 血管內皮、腎絲球囊壁層 | 過濾、物質交換 |
| **簡單立方上皮** | 腎小管、甲狀腺濾泡 | 分泌、吸收 |
| **簡單柱狀上皮** | 胃腸道、子宮 | 吸收、分泌、保護 |
| **假複層柱狀纖毛上皮** | 氣管、支氣管 | 黏液纖毛廓清 |
| **複層鱗狀上皮** | 皮膚、口腔、食道 | 保護、耐磨 |
| **變移上皮** | 膀胱、輸尿管 | 適應張力變化 |

### 1.4 上皮細胞的連接結構

上皮細胞之間有多種連接結構，這些結構位於細胞的**側面接合面（lateral surface）**：

| 連接類型 | 英文 | 功能 |
|----------|------|------|
| **緊密連接** | Tight Junction | 防止物質通過細胞間隙 |
| **隙隙連接** | Gap Junction | 細胞間離子和小的分子流通 |
| **黏著斑（橋粒）** | Desmosome | 機械性連接，抗拉力 |
| **半橋粒** | Hemidesmosome | 將細胞附著於基底膜 |

::: {.content-box .clinical}
## 臨床應用（Clinical Correlation）

**上皮組織的臨床意義**：
- **癌癥分類**：源於上皮細胞的惡性腫瘤稱為**癌（Carcinoma）**，是最常見的癌症類型
- **鱗狀細胞癌**：源於複層鱗狀上皮，如皮膚鱗癌、子宮頸鱗癌
- **腺癌**：源於腺上皮，如大腸腺癌、胃腺癌

**基底膜（Basement Membrane）**的臨床意義：
- 基底膜是上皮細胞和結締組織之間的界線
- 惡性腫瘤的**侵襲（Invasion）**是指癌細胞突破基底膜
- 病理切片中基底膜完整性是判斷惡性程度的重要指標
- **上皮下沈積（Subepithelial Deposition）**：免疫複合體沉積於腎絲球基底膜，導致腎小球腎炎
:::

## 二、結締組織（Connective Tissue）

### 2.1 結締組織的分類

結締組織是人體中最多樣化的組織，根據功能和結構分為：

| 類別 | 英文 | 主要分布 |
|------|------|----------|
| **疏鬆結締組織** | Areolar CT | 器官之間、器官內 |
| **緻密結締組織** | Dense CT | 肌腱、韌帶 |
| **脂肪組織** | Adipose Tissue | 皮下、內臟周圍 |
| **軟骨** | Cartilage | 關節面、耳廓、椎間盤 |
| **骨組織** | Bone Tissue | 骨骼 |
| **血液** | Blood | 血管內 |

### 2.2 疏鬆結締組織（Areolar Connective Tissue）

疏鬆結締組織是最常見的結締組織類型，又稱**蜂窩組織（蜂窝組織）**：

| 組成 | 說明 |
|------|------|
| **纖維** | 膠原纖維（提供張力）、彈性纖維（彈性）、網狀纖維（支撐） |
| **細胞** | 纖維母細胞（合成纖維）、巨噬細胞（吞噬）、肥胖細胞（組織胺） |
| **基質** | 膠狀無結構物質，含水分和營養 |

### 2.3 軟骨（Cartilage）

軟骨是一種堅硬但有彈性的結締組織，無血管和神經分布：

| 軟骨類型 | 英文 | 基質特點 | 分布 |
|----------|------|----------|------|
| **透明軟骨** | Hyaline Cartilage | 均質嗜鹼性，含II型膠原 | 關節面、肋軟骨、呼吸道 |
| **彈性軟骨** | Elastic Cartilage | 含彈性纖維 | 耳廓、會厭 |
| **纖維軟骨** | Fibrocartilage | 含大量粗大膠原纖維 | 椎間盤、恥骨聯合 |

**軟骨內骨化（Endochondral Ossification）**：
- 大部分骨骼的發育方式
- 軟骨先形成模型，再被骨組織取代

### 2.4 骨組織（Bone Tissue）

#### 骨組織結構

| 類型 | 英文 | 特點 | 分布 |
|------|------|------|------|
| **緻密骨（皮質骨）** | Compact Bone | 骨板緊密排列 | 骨幹 |
| **海綿骨（網狀骨）** | Spongy Bone | 骨樑形成網狀 | 骨端、扁骨 |

#### 哈佛系統（Haversian System）

骨組織的基本功能單位是**哈佛系統（Haversian System）**或**骨單位（Osteon）**：

| 結構 | 說明 |
|------|------|
| **哈佛管** | 中央管，容納血管神經 |
| **骨板** | 同心圓排列的骨基質 |
| **骨陷窩** | 含骨細胞的空間 |
| **骨小管** | 骨細胞突起通過的管道 |

::: {.content-box .clinical}
## 臨床應用（Clinical Correlation）

**軟骨損傷的臨床問題**：
- **關節軟骨缺損**：無法自發修復，因為軟骨無血管
- **軟骨修補術**：微骨折術、軟骨移植
- **老化**：軟骨變性導致骨關節炎

**骨折癒合（Bone Healing）**：
1. 血腫形成（發炎期）
2. 纖維性骨痂形成（軟骨形成期）
3. 編織骨形成（硬骨形成期）
4. 骨痂改造（重塑期）

**骨質疏鬆症（Osteoporosis）**：
- 骨質流失導致骨密度降低
- 哈佛系統變薄、骨小梁減少
- 增加骨折風險，特別是髖關節、脊柱和腕部

**骨囊腫（Bone Cyst）**：
- 骨內囊性病變，內容為液體或血液
- 常見於兒童和青少年
:::

## 三、肌肉組織（Muscle Tissue）

### 3.1 肌肉組織的分類

| 類型 | 英文 | 特點 | 控制方式 | 分布 |
|------|------|------|----------|------|
| **骨骼肌** | Skeletal Muscle | 有橫紋、多核 | 隨意 | 附著於骨骼 |
| **心肌** | Cardiac Muscle | 有橫紋、分支連接 | 不隨意 | 心臟 |
| **平滑肌** | Smooth Muscle | 無橫紋 | 不隨意 | 內臟、血管 |

### 3.2 骨骼肌（Skeletal Muscle）

#### 顯微特徵

| 特徵 | 說明 |
|------|------|
| **細胞形狀** | 長圓柱形（肌纖維） |
| **細胞核** | 多核（可達數百個），位於細胞周邊 |
| **橫紋** | 明暗交替的週期性條紋 |
| **肌節** | 相鄰兩Z線之間的結構單位 |

#### 結構層次

| 結構 | 英文 | 組成 |
|------|------|------|
| **肌纖維** | Muscle Fiber | 一個肌肉細胞 |
| **肌原纖維** | Myofibril | 肌動蛋白和肌凝蛋白絲 |
| **肌絲** | Myofilament | 肌動蛋白絲（細）、肌凝蛋白絲（粗） |

### 3.3 心肌（Cardiac Muscle）

#### 顯微特徵

| 特徵 | 說明 |
|------|------|
| **細胞形狀** | 短柱狀、分支吻合 |
| **細胞核** | 單核或雙核，居中 |
| **橫紋** | 有，但不如骨骼肌明顯 |
| **間盤** | 相鄰細胞之間的深染橫線（間隙連接） |
| **收縮特性** | 自律性、節律性、不得意收縮 |

### 3.4 平滑肌（Smooth Muscle）

#### 顯微特徵

| 特徵 | 說明 |
|------|------|
| **細胞形狀** | 梭形，兩端尖細 |
| **細胞核** | 單核，長橢圓形，居中 |
| **橫紋** | 無 |
| **收縮特性** | 緩慢、持久、不隨意 |
| **分布** | 內臟、血管壁 |

::: {.content-box .clinical}
## 臨床應用（Clinical Correlation）

**肌肉萎縮（Muscle Atrophy）**：
- 廢用性萎縮：長期不活動導致肌纖維變細
- 神經性萎縮：運動神經元損傷導致
- 肌肉病變：肌纖維本身疾病

**心肌病理學**：
- **心肌梗塞（Myocardial Infarction）**：冠狀动脉阻塞導致心肌細胞缺血性壞死
- 病理特徵：凝固性壞死、發炎細胞浸潤、之後形成疤痕組織
- **心肌病變（Cardiomyopathy）**：心臟肌肉本身疾病

**平滑肌功能異常**：
- **氣喘**：支氣管平滑肌痙攣
- **高血壓**：血管平滑肌收縮
- **藥物作用**：Beta-2致效劑鬆弛平滑肌，用於治療氣喘
:::

## 四、神經組織（Nervous Tissue）

### 4.1 神經組織的組成

神經組織由**神經元（Neuron）**和**神經膠質細胞（Neuroglial Cells）**組成：

| 組成 | 英文 | 功能 |
|------|------|------|
| **神經元** | Neuron | 接受刺激、傳導衝動 |
| **神經膠質細胞** | Neuroglia/Glia | 支持、保護、營養 |

### 4.2 神經元（Neuron）

#### 神經元的結構

| 結構 | 英文 | 功能 |
|------|------|------|
| **細胞體** | Cell Body (Soma) | 包含細胞核和大部分細胞器 |
| **樹突** | Dendrite | 接受來自其他神經元的信號 |
| **軸突** | Axon | 將神經衝動傳向其他神經元或效應器 |
| **軸丘** | Axon Hillock | 軸突起始處，決定是否產生動作電位 |
| **髓鞘** | Myelin Sheath | 絕緣，加速軸突傳導（ganglion神經元無） |
| **郎飛結** | Node of Ranvier | 軸突的裸露部分，跳躍傳導 |

#### 神經元的分類

| 分類標準 | 類型 | 說明 |
|----------|------|------|
| **根據突觸數目** | 單極、雙極、多極 | 軸突數目區分 |
| **根據功能** | 感覺神經元、運動神經元、 interneuron | 傳入、傳出、整合 |
| **根據軸突長度** | Golgi I型、Golgi II型 | 長軸突、短軸突 |

### 4.3 神經膠質細胞（Neuroglia）

神經膠質細胞是神經系統的支持細胞，數量約為神經元的10倍：

| 細胞類型 | 英文 | 功能 |
|----------|------|------|
| **星狀細胞** | Astrocyte | 支撐、維持環境、形成血腦屏障 |
| **寡突起細胞** | Oligodendrocyte | 生成CNS髓鞘 |
| **許旺細胞** | Schwann Cell | 生成PNS髓鞘 |
| **微膠細胞** | Microglia | 吞噬作用、免疫防禦 |

#### 中樞神經系統 vs 周邊神經系統的膠質細胞

| 系統 | 膠質細胞 |
|------|----------|
| **CNS** | 星狀細胞、寡突起細胞、微膠細胞 |
| **PNS** | 許旺細胞、衛星細胞 |

::: {.content-box .clinical}
## 臨床應用（Clinical Correlation）

**脫髓鞘疾病（Demyelinating Diseases）**：
- **多發性硬化症（Multiple Sclerosis, MS）**：
  - CNS疾病，寡突起細胞受損導致髓鞘脫失
  - 症狀：視力障礙、肢體麻木、無力、平衡失調
  - 反復發作、緩解
- **吉蘭-巴雷綜合徵（Guillain-Barré Syndrome）**：
  - PNS疾病，許旺細胞受損導致髓鞘脫失
  - 症狀：進行性四肢無力、反射消失
  - 可能與感染後自體免疫反應有關

**神經膠質瘤（Glioma）**：
- 源於神經膠質細胞的腦瘤
- 根據細胞類型分為：星狀細胞瘤、寡突起膠質瘤、膠質母細胞瘤
- 膠質母細胞瘤是最高度惡性的原發性腦瘤

**神經再生的臨床限制**：
- CNS神經元損傷後再生能力有限
- PNS神經元有一定再生能力（通過許旺細胞引導）
- 這解釋了為何脊髓損傷的預後較周邊神經損傷差
:::

## 五、組織學染色技術

### 5.1 HE染色（蘇木精-伊紅染色）

**HE染色**是組織學最基本和最廣泛使用的染色方法：

| 染色 | 說明 | 染色結果 |
|------|------|-----------|
| **蘇木精（Hematoxylin）** | 鹼性染劑 | 細胞核染藍紫色 |
| **伊紅（Eosin）** | 酸性染劑 | 細胞質和細胞外基質染粉紅色 |

#### 各組織的HE染色特徵

| 組織類型 | HE染色特徵 |
|----------|-----------|
| **上皮組織** | 細胞緊密排列，核位於細胞周邊 |
| **結締組織** | 細胞外基質豐富，粉色（膠原） |
| **肌肉組織** | 細胞長柱狀，粉紅色胞質 |
| **神經組織** | 細胞體藍紫色，突起粉紅色 |

### 5.2 常用特殊染色

| 染色方法 | 應用 |
|----------|------|
| **Masson三色染色** | 區分膠原纖維（藍綠）和肌肉（紅） |
| **Elastic染色** | 顯示彈性纖維（黑色） |
| **PAS染色** | 顯示多醣類（洋紅色），常用於腎絲球疾病 |
| **銀染色** | 顯示網狀纖維、神經纖維、腫瘤細胞 |
| **油紅O染色** | 顯示脂肪組織（紅色） |

### 5.3 免疫組織化學（Immunohistochemistry, IHC）

| 特點 | 說明 |
|------|------|
| **原理** | 利用抗原抗體反應檢測組織中的特定蛋白質 |
| **常用標記** | 角蛋白（Keratin）、波形蛋白（Vimentin）、CD系列 |
| **臨床應用** | 腫瘤分類、來源鑒定、預後指標 |

::: {.content-box .clinical}
## 臨床應用（Clinical Correlation）

**病理學中的HE染色**：
- 幾乎所有手術標本和穿刺標本都先用HE染色評估
- 細胞核的形態是判斷細胞分化程度的重要指標
- 核異型性（Nulcear Atypia）是診斷惡性腫瘤的關鍵

**免疫組織化學在腫瘤病理的應用**：
| 腫瘤類型 | 免疫標記 |
|----------|-----------|
| 肺癌 | TTF-1, CK7, p63 |
| 肝癌 | Hep Par-1, AFP |
| 乳腺癌 | ER, PR, HER2, Ki-67 |
| 淋巴瘤 | CD20, CD3, CD30 |
| 黑色素瘤 | S-100, HMB-45, Melan-A |

**常見組織病理學描述**：
- **良性腫瘤**：分化良好、核分裂少、無壞死
- **惡性腫瘤**：分化差、核異型、核分裂多、壞死
- **原位癌**：腫瘤細胞未突破基底膜
- **侵襲性癌**：腫瘤細胞突破基底膜
:::

## 六、組織學與臨床應用總結

組織學是理解正常組織結構和病理變化的基礎：

| 應用領域 | 說明 |
|----------|------|
| **病理診斷** | 顯微鏡下評估組織切片，診斷疾病 |
| **腫瘤分類** | 根據組織來源和細胞特徵分類 |
| **法醫學** | 死亡原因的組織學證據 |
| ** Forensic Pathology** | 組織學變化推斷死亡時間 |
| **研究** | 了解正常和疾病狀態的細胞機制 |

## 學習要點

- **上皮組織**：單層/複層、鱗狀/立方/柱狀；細胞間連接（tight junction、gap junction、desmosome）是重要特徵
- **結締組織**：最多樣化，包括疏鬆、緻密、脂肪、軟骨、骨骼；各有獨特的細胞和基質成分
- **肌肉組織**：骨骼肌（隨意、有紋、多核）、心肌（不隨意、有紋、分支）、平滑肌（不隨意、無紋）
- **神經組織**：神經元（細胞體、樹突、軸突）和神經膠質細胞（支持、保護功能）組成
- **HE染色**是組織學的基礎染色，蘇木精染細胞核（藍紫）、伊紅染細胞質（粉紅）
- 組織學知識是理解病理變化和臨床疾病的顯微基礎
