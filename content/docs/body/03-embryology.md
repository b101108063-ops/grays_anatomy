## 本章重點

- 三胚層的形成是胚胎發育的基礎
- 外胚層形成神經系統和皮膚
- 中胚層形成肌肉、骨骼和心血管系統
- 內胚層形成消化道和呼吸道上皮
- 胎兒循環在出生後發生重大轉變
:::

## 概述

**胚胎學（Embryology）** 是研究人體從受精到出生的發育過程的科學。理解胚胎發育對於掌握人體結構、預防先天性疾病、以及解釋臨床異常都至關重要。胚胎發育是一個精密調控的過程，任何環節的異常都可能導致先天性缺陷或發育障礙。

---

## 一、三胚層（Germ Layers）

胚胎發育的核心事件是**三胚層（Germ Layers）**的形成。這三層細胞群將來會分化為人體的所有組織和器官。

### 1.1 三胚層總覽

| 胚層 | 中文 | 英文 | 主要衍生結構 |
|------|------|------|--------------|
| **外胚層** | 上胚層 | Ectoderm | 神經系統、皮膚表皮 |
| **中胚層** | 中胚層 | Mesoderm | 肌肉、骨骼、心血管、泌尿生殖 |
| **內胚層** | 下胚層 | Endoderm | 消化道、呼吸道上皮、消化腺 |

### 1.2 外胚層（Ectoderm）

外胚層是胚胎最外層的細胞，在**原腸胚形成（Gastrulation）**過程中形成。

**主要衍生結構**：

| 系統/結構 | 英文 | 說明 |
|-----------|------|------|
| **神經系統** | Nervous System | 腦、脊髓、周邊神經 |
| **皮膚表皮** | Epidermis | 皮膚外層 |
| **眼睛** | Eyes | 視網膜、角膜、晶狀體 |
| **耳朵** | Ears | 內耳上皮 |
| **口腔黏膜** | Oral Mucosa | 口腔內襯 |
| **牙釉質** | Tooth Enamel | 牙齒外層 |

::: {.content-box .clinical}
## 臨床應用（Clinical Correlation）

**神經管缺陷（Neural Tube Defects）**：
- **脊柱裂（Spina Bifida）**：椎弓閉合不全
  - 隱性脊柱裂：僅骨骼異常
  - 開放性脊柱裂：脊髓/腦膜外露
- **無腦畸形（Anencephaly）**：顱骨和大腦發育不全
- **預防**：孕前及孕期補充**葉酸（Folic Acid）**可降低70%風險
:::

### 1.3 中胚層（Mesoderm）

中胚層位於外胚層和內胚層之間，在胚胎發育中扮演核心角色。

**主要衍生結構**：

| 系統/結構 | 英文 | 說明 |
|-----------|------|------|
| **肌肉系統** | Muscular System | 骨骼肌、平滑肌、心肌 |
| **骨骼系統** | Skeletal System | 中軸骨、四肢骨 |
| **心血管系統** | Cardiovascular System | 心臟、血管、血液 |
| **泌尿系統** | Urinary System | 腎臟、輸尿管、膀胱 |
| **生殖系統** | Reproductive System | 卵巢、睪丸、附屬器官 |
| **真皮** | Dermis | 皮膚深層 |

**中胚層分區**：

| 分區 | 位置 | 主要分化 |
|------|------|----------|
| **軸旁中胚層** | 背中線兩側 | 體節（Somites）→ 肌肉、脊椎 |
| **中間中胚層** | 軸旁與側板之間 | 泌尿生殖系統 |
| **側板中胚層** | 胚胎最外層 | 體壁/臟壁層、心血管 |

::: {.content-box .clinical}
## 臨床應用（Clinical Correlation）

**先天性心臟病（Congenital Heart Defects）**：
- 最常見的先天性畸形，發生率約1%
- 常見類型：
  - 心室間隔缺損（VSD）
  - 心房間隔缺損（ASD）
  - 開放性动脉導管（PDA）
  - 法洛氏四重症（Tetralogy of Fallot）
- 遺傳與環境因素共同影響
- 產前超聲波可早期篩檢
:::

### 1.4 內胚層（Endoderm）

內胚層是胚胎最內層的細胞層，形成原始消化道。

**主要衍生結構**：

| 系統/結構 | 英文 | 說明 |
|-----------|------|------|
| **消化道上皮** | GI Epithelium | 口腔到肛門（除口腔） |
| **肝臟** | Liver | 膽汁合成 |
| **胰臟** | Pancreas | 胰液、胰島素 |
| **呼吸道上皮** | Respiratory Epithelium | 氣管到肺泡 |
| **膀胱** | Bladder | 泌尿道上皮 |
| **甲狀腺** | Thyroid | 甲狀腺激素 |

## 二、胚胎發育分期（Stages of Embryonic Development）

### 2.1 發育時間線

| 時期 | 英文 | 時間 | 重要事件 |
|------|------|------|----------|
| **受精** | Fertilization | 第1週 | 卵子與精子結合 |
| **卵裂** | Cleavage | 第1-2週 | 細胞分裂 |
| **囊胚期** | Blastocyst Stage | 第5-7天 | 著床 |
| **胚期** | Embryonic Period | 第3-8週 | 器官形成（關鍵期） |
| **胎期** | Fetal Period | 第9週-分娩 | 快速生長成熟 |

### 2.2 胚期（Embryonic Period）關鍵事件

胚期（第3-8週）是**器官形成（Organogenesis）**的關鍵時期，這段時間對外界因素最為敏感：

| 週數 | 發育里程碑 |
|------|-----------|
| **第3週** | 原腸胚形成、三胚層建立、神經板形成 |
| **第4週** | 原始心臟開始跳動、神經管閉合、體節形成 |
| **第5週** | 肢芽出現、眼杯形成、耳泡形成 |
| **第6週** | 面部特徵形成、手/足板出現 |
| **第7週** | 腸胃道閉合、腎臟開始發育 |
| **第8週** | 所有主要器官已形成、外部性徵開始發育 |

::: {.content-box .clinical}
## 臨床應用（Clinical Correlation）

**致畸因子（Teratogens）**對胚期的影響最為顯著：

| 致畸因子 | 英文 | 影響 |
|----------|------|------|
| **沙利竇邁** | Thalidomide | 四肢畸形 |
| **酒精** | Alcohol | 胎兒酒精症候群（FAS） |
| **德國麻疹** | Rubella | 白內障、心臟缺陷、聾啞 |
| ** Cocaine** | 可卡因 | 腦血管意外、生長遲緩 |
| **維生素A過量** | Hypervitaminosis A | 顱面畸形、心臟缺陷 |
| **風疹病毒** | CMV | 視網膜病變、腦鈣化 |

建議孕婦在**胚期（Embryonic Period）**避免任何不必要的藥物暴露。
:::

## 三、主要發育過程

### 3.1 受精（Fertilization）

**受精**發生在**輸卵管的壺腹部（ ampulla）**，過程包括：

1. **精子獲能（Capacitation）**：在女性生殖道中發生，獲得受精能力
2. **頂體反應（Acrosome Reaction）**：精子釋放酶類，穿透卵子透明層
3. **皮層反應（Cortical Reaction）**：防止多精子受精
4. **第二極體排出**：完成減數分裂
5. **原核融合**：雌雄原核結合

受精結果：**受精卵（Zygote）**形成，開始細胞分裂。

### 3.2 卵裂（Cleavage）

受精卵進行快速細胞分裂，但不增加整體體積：

| 階段 | 時間 | 細胞數 |
|------|------|--------|
| **卵裂球** | 第1-3天 | 2→4→8 細胞 |
| **桑葚胚** | 第3-4天 | 16細胞 |
| **胚泡** | 第4-5天 | 空洞結構 |

### 3.3 囊胚（Blastocyst）

第5-7天形成**囊胚（Blastocyst）**，結構包括：

| 結構 | 英文 | 命運 |
|------|------|------|
| **滋養層** | Trophoblast | 將來形成胎盤 |
| **內細胞團** | Inner Cell Mass | 將來形成胚胎本身 |
| **囊胚腔** | Blastocoele | 充滿液體的腔室 |

### 3.4 著床（Implantation）

第6-7天開始**著床（Implantation）**：

| 時期 | 時間 | 事件 |
|------|------|------|
| 附著 | 第6-7天 | 囊胚附著於、子宮內膜 |
| 侵入 | 第7-12天 | 滋養層侵入、子宮內膜 |
| 完成 | 第12天 | 完全埋入、子宮內膜 |

::: {.content-box .clinical}
## 臨床應用（Clinical Correlation）

**異位妊娠（Ectopic Pregnancy）**：
- 受精卵在子宫外著床
- 95%發生在**輸卵管的壺腹部（ ampulla）**
- 危險因子：輸卵管炎、輸卵管手術史
- 症狀：腹痛、肩痛（血液刺激膈神經）、陰道出血
- 診斷：超聲波、絨毛膜促性腺激素（hCG）
- 緊急情況：輸卵管的部破裂可致命，需緊急手術
:::

### 3.5 胚層形成（Gastrulation）

第2-3週最重要的事件是**胚層形成（Gastrulation）**，外胚層細胞移動形成三層結構：

| 結構 | 英文 | 形成 |
|------|------|------|
| **原條** | Primitive Streak | 外胚層細胞移動形成 |
| **原結** | Primitive Node | 頭側結構，確定頭尾方向 |
| **脊索** | Notochord | 來自原結，形成骨骼軸心 |
| **體腔** | Coelom | 中胚層形成的體腔 |

## 四、胎兒循環（Fetal Circulation）

### 4.1 胎兒特有結構

胎兒在子宫內的氧氣和營養來自胎盤，胎兒循環有其獨特結構：

| 結構 | 英文 | 功能 |
|------|------|------|
| **臍靜脈** | Umbilical Vein | 從胎盤輸送富氧血到胎兒 |
| **臍动脉** | Umbilical Arteries | 將缺氧血送回胎盤 |
| **靜脈導管** | Ductus Venosus | 繞過肝臟，直接進入下腔靜脈 |
| **动脉導管** | Ductus Arteriosus | 繞過肺部，將血液導向主動脈 |
| **卵圓孔** | Foramen Ovale | ，左右心房之間的通道 |

### 4.2 胎兒循環路徑

胎兒血液循環路徑：

```
胎盤 → 臍靜脈 → 靜脈導管 → 下腔靜脈 → 右心房
                                              ↓
                            卵圓孔 → 左心房 → 左心室 → 主動機
                                              ↓
右心房 ← 下腔靜脈（部分混合血）
    ↓
右心室 → 肺动脉 → 动脉導管 → 降主動機
                    ↓
            臍动脉 → 胎盤
```

### 4.3 胎兒血氧分佈

| 區域 | 氧飽和度 | 說明 |
|------|----------|------|
| **胎盤** | 80% | 最高 |
| **心臟、腦** | 60-70% | 重要臟器 |
| **下肢** | 40-50% | 最低 |

::: {.content-box .clinical}
## 臨床應用（Clinical Correlation）

**胎兒循環到新生兒循環的轉變（Transition at Birth）**：

胎兒出生後，胎盤循環中斷，肺部開始呼吸，循環系統必須快速適應：

| 變化 | 機制 |
|------|------|
| **臍血管關閉** | 臍帶結紮後，臍靜脈和臍动脉功能性關閉 |
| **靜脈導管關閉** | 成為**肝圓韌帶（Ligamentum Venosum）** |
| **卵圓孔關閉** | 左心壓力增加使瓣膜關閉，形成**卵圓窩（Fossa Ovalis）** |
| **动脉導管關閉** | 出生後24-48小時內功能性關閉，2-3週形成**动脉韌帶（Ligamentum Arteriosum）** |

**開放性动脉導管（Patent Ductus Arteriosus, PDA）**：
- 产后动脉導管未能關閉
- 症狀：心臟收縮期雜音、脈搏增強
- 治療：藥物（NSAIDs抑制前列腺素）、手術結紮
:::

## 五、胚胎發育與臨床應用總結

### 5.1 先天性疾病分類

| 類型 | 說明 | 範例 |
|------|------|------|
| **畸形** | 結構異常 | 脊柱裂、唇腭裂 |
| **變形** | 外部壓力導致 | 斜頭畸形 |
| **分裂** | 組織正常但分佈異常 | 多指症 |
| **發育不良** | 組織未完全發育 | 發育性髖關節發育不良 |

### 5.2 產前診斷

| 方法 | 時機 | 可檢測 |
|------|------|--------|
| **唐氏症篩檢** | 10-13週 | 染色體異常 |
| **羊膜穿刺** | 16-20週 | 染色體異常 |
| **絨毛取樣** | 10-12週 | 染色體異常 |
| **超聲波** | 各孕期 | 結構畸形 |
| **無創產前檢測（NIPT）** | 10週後 | 染色體異常 |

::: {.content-box .key-points}
## 學習要點

- **三胚層**是所有器官系統的起源：外胚層（神經/皮膚）、中胚層（肌肉/骨骼/心血管）、內胚層（消化/呼吸）
- **胚期（0-8週）**是器官形成的關鍵時期，對致畸因子最敏感
- **胎兒循環**有三大特殊通道（靜脈導管、动脉導管、卵圓孔），出生後各自關閉
- 理解胚胎發育有助於解釋先天性疾病的原因和進行產前診斷
- **致畸因子**預防是孕期保健的核心
:::
