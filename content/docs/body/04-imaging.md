## 本章重點

- 各種影像學方法有不同的原理和適用範圍
- X光是首選篩檢工具，但軟組織對比差
- CT適用於創傷和緊急情況，提供快速横断面影像
- MRI軟組織對比最佳，但有金屬禁忌
- 超聲波無輻射，適合產科和即時評估
- 核醫提供功能性而非解剖性影像
:::

## 概述

**醫學影像學（Medical Imaging）**是現代醫學不可或缺的工具，使臨床醫師能夠非侵入性地觀察人體內部結構。不同的影像學技術各有其物理原理、優勢和限制，選擇適當的影像學方法對於準確診斷至關重要。本章將系統介紹臨床上常用的各種影像學技術。

## 一、X光檢查（Plain Radiograph）

### 1.1 原理

**X光（X-ray）**是一種波長極短的電磁輻射，具有穿透人體組織的能力：

| 組織類型 | 密度 | X光穿透性 | 影像表現 |
|----------|------|-----------|----------|
| **骨骼** | 高 | 低 | 白色（高密度） |
| **軟組織** | 中 | 中 | 灰階 |
| **脂肪** | 低 | 高 | 深灰 |
| **氣體** | 最低 | 最高 | 黑色（低密度） |

### 1.2 優勢與限制

| 優勢 | 限制 |
|------|------|
| 快速、便宜 | 軟組織對比差 |
| 可及性高 | 影像重疊結構 |
| 幅射劑量低 | 僅提供二維影像 |
| 骨折、骨病變首選 | 早期病變可能不明顯 |

### 1.3 臨床應用

| 應用 | 說明 |
|------|------|
| **骨折** | 明確骨折類型和位置 |
| **肺部疾病** | 肺炎、肺結節、胸腔積液 |
| **關節疾病** | 關節炎、脫位 |
| **空腔臟器** | 腸道阻塞、異物 |
| **牙科** | 牙齒和牙周疾病 |
| **乳房攝影** | 乳癌篩檢 |

::: {.content-box .clinical}
## 臨床應用（Clinical Correlation）

**創傷評估的X光攝影原則**：
- **C-spine（頸椎）**：創傷患者排除頸椎損傷
- **Chest X-ray（胸部X光）**：創傷患者首要檢查，評估氣胸、血胸、心臟輪廓
- **Pelvis（骨盆）**：評估骨盆骨折（出血風險高）
- **四肢**：疑似骨折處需包含上下關節

**輻射劑量參考**：
- 胸部X光：0.1 mSv（約10天自然背景幅射）
- 腹部X光：1 mSv（約4個月自然背景幅射）
- 頭部CT：2 mSv（約8個月自然背景幅射）
:::

## 二、電腦斷層掃描（Computed Tomography, CT）

### 2.1 原理

**CT**利用X光環繞人體旋轉，收集多角度投影數據，經電腦重建為**横断面（axial）**影像：

| 特性 | 說明 |
|------|------|
| **横断面影像** | 消除結構重疊 |
| **密度解析度** | 可區分細微密度差異 |
| **3D重建** | 可後處理成立體影像 |
| **掃描速度** | 快速，適合緊急情況 |

### 2.2 CT類型

| 類型 | 英文 | 應用 |
|------|------|------|
| **傳統CT** | Conventional CT | 逐層掃描 |
| **螺旋CT** | Helical/Spiral CT | 連續掃描，速度快 |
| **多排探頭CT** | MDCT | 同步多層掃描 |
| **雙能量CT** | Dual-energy CT | 區分不同組織特性 |

### 2.3 臨床應用

| 部位/情況 | 臨床應用 |
|-----------|----------|
| **顱內** | 腦出血（中風創傷）、顱骨骨折 |
| **頸部** | 評估甲狀腺、淋巴結 |
| **胸部** | 肺栓塞（CTPA）、肺癌分期 |
| **腹部** | 創傷、急腹症、腫瘤評估 |
| **骨盆腔** | 泌尿結石、婦科腫瘤 |
| **脊椎** | 椎間盤突出、骨質評估 |

::: {.content-box .clinical}
## 臨床應用（Clinical Correlation）

**創傷重點創傷超聲評估（FAST）與CT互補**：
- **FAST超聲**：快速評估腹腔游離液體（創傷患者）
- **CT**：詳細評估各臟器損傷程度

**CT結腸ography（虛擬大腸鏡）**：
- 對比劑充滿大腸後進行CT掃描
- 可檢測大息肉和腫瘤
- 非侵入性，但需腸道清潔準備

**幅射劑量注意**：
- 腹部CT約10 mSv（約3年自然背景幅射）
- 應遵守**ALARA原則（As Low As Reasonably Achievable）**
- 兒童應盡量降低劑量
:::

## 三、磁振造影（Magnetic Resonance Imaging, MRI）

### 3.1 原理

**MRI**利用強大磁場和無線電波，使體內氫原子核（主要存在於水分子中）產生訊號，經電腦重建為影像：

| 特性 | 說明 |
|------|------|
| **軟組織對比** | 極佳，區分灰白質、脂肪、肌肉 |
| **無離子幅射** | 不使用X光 |
| **多平面成像** | 可任意方向掃描（軸向、冠狀、矢狀） |
| **功能性成像** | fMRI、MR波譜 |

### 3.2 MRI信號與組織特性

| 組織 | T1加權 | T2加權 |
|------|--------|--------|
| **脂肪** | 高信號（亮） | 中等信號 |
| **水/腦脊液** | 低信號（暗） | 高信號（亮） |
| **肌肉** | 中等信號 | 中等信號 |
| **骨皮質** | 低信號（暗） | 低信號（暗） |

### 3.3 臨床應用

| 系統 | 臨床應用 |
|------|----------|
| **腦部** | 腦瘤、腦中風、多發性硬化症 |
| **脊髓** | 椎間盤突出、脊髓損傷 |
| **關節** | 十字韌帶、半月軟骨損傷 |
| **軟組織** | 肌肉損傷、軟組織腫瘤 |
| **心臟** | 心肌病變、心包疾病 |
| **腹部** | 肝臟、胰臟、腎臟腫瘤 |

### 3.4 禁忌症

| 絕對禁忌 | 相對禁忌 |
|----------|----------|
| 心律調節器（舊型） | 腦室分流管（需確認類型） |
| 植入式心臟復律器/除顫器（ICD） | 關節置換術（金屬） |
| 磁性植入物 | 藥物幫浦 |
| 子宮內避孕器（部分） | 懷孕早期（相對） |
| 耳蝸植入物 |  |

::: {.content-box .clinical}
## 臨床應用（Clinical Correlation）

**腦部MRI在急性中風的角色**：
- **DWI（擴散加權影像）**：可在數分鐘內檢出缺血性中風
- **ADC圖**：區分細胞毒性水腫（急性中風）與血管性水腫
- 溶栓治療決策依據MRI結果

**MRI在運動傷害的應用**：
- **前十字韌帶（ACL）撕裂**：MRI準確率>95%
- **半月軟骨損傷**：關節腔注射MRI顯影劑可提高準確率
- **旋轉袖（Rotator Cuff）撕裂**：評估肌腱撕裂程度

**腎功能不良患者使用MRI對比劑的考量**：
- 舊式對比劑（Gadolinium）可能引起**腎因性全身性硬化癥（Nephrogenic Systemic Fibrosis）**
- 需先評估腎功能（eGFR）
- 新一代對比劑安全性較高
:::

## 四、超聲波（Ultrasound）

### 4.1 原理

**超聲波（Ultrasound）**使用高頻聲波（2-18 MHz）穿透人體，根據不同組織的聲學特性反射回聲，構成影像：

| 特性 | 說明 |
|------|------|
| **無離子幅射** | 安全，適合產科 |
| **即時影像** | 可觀察運動和血流 |
| **可攜性** | 可在床邊進行 |
| **成本低** | 設備相對便宜 |
| **操作者依賴** | 結果受操作者經驗影響 |

### 4.2 超聲波類型

| 類型 | 英文 | 應用 |
|------|------|------|
| **2D超聲** | B-mode | 基本灰階影像 |
| **都卜勒超聲** | Doppler | 評估血流方向和速度 |
| **彩色都卜勒** | Color Doppler | 血流視覺化 |
| **都卜勒超聲** | Spectral Doppler | 定量分析血流 |
| **3D/4D超聲** | 3D/4D Ultrasound | 胎兒面容、立體影像 |

### 4.3 臨床應用

| 領域 | 臨床應用 |
|------|----------|
| **產科** | 孕期評估、胎兒結構篩檢 |
| **腹部** | 肝臟、胆囊、腎臟、胰臟 |
| **甲狀腺** | 甲狀腺結節評估 |
| **心臟** | 心臟功能和結構評估（Echo） |
| **血管** | 靜脈曲張、深層靜脈血栓 |
| **肌肉關節** | 肌肉撕裂、肌腱炎 |
| **婦科** | 子宮、卵巢評估 |

::: {.content-box .clinical}
## 臨床應用（Clinical Correlation）

**產科超聲波的時機和目的**：

| 孕期 | 超聲類型 | 主要目的 |
|------|----------|----------|
| 6-9週 | 早期妊娠超聲 | 確認著床位置、胎兒心跳 |
| 11-14週 | 初期唐氏症篩檢 | 胎兒頸部透明帶測量 |
| 18-22週 | 解剖掃描 | 胎兒結構異常篩檢 |
| 28-32週 | 胎兒生長評估 | 預估體重、胎位 |
| 36週後 | 胎位確認 | 评估胎位、胎盤位置 |

**超聲引導下介入治療**：
- 膿瘡引流
- 甲狀腺結節穿刺切片
- 肝/腎囊腫抽吸
- 關節注射

**超聲波的限制**：
- 骨骼後方結構難以評估
- 空氣和骨骼阻擋聲波
- 操作者經驗影響診斷準確性
:::

## 五、核醫學（Nuclear Medicine）

### 5.1 原理

**核醫學（Nuclear Medicine）**利用放射性同位素製劑（radiopharmaceuticals）引入體內，根據其生理分布發射伽傌射線，經過**單光子發射電腦斷層（SPECT）**或**正電子發射電腦斷層（PET）**偵測，形成功能性影像：

| 特性 | 說明 |
|------|------|
| **功能性影像** | 顯示代謝、功能，而非結構 |
| **全身掃描** | 可一次評估全身 |
| **早期病變偵測** | 可在解剖改變前發現異常 |
| **幅射暴露** | 低至中等劑量 |

### 5.2 主要核醫檢查

| 檢查 | 英文/縮寫 | 放射性藥物 | 主要應用 |
|------|-----------|------------|----------|
| **正子發射電腦斷層** | PET | 18F-FDG | 腫瘤分期、腦部代謝、心肌活性 |
| **甲狀腺掃描** | Thyroid Scan | I-123/I-131 | 甲狀腺功能、甲狀腺結節 |
| **骨骼掃描** | Bone Scan | Tc-99m MDP | 骨轉移、應力性骨折 |
| **心肌灌注掃描** | MPI | Tc-99m Sestamibi | 冠狀動脈疾病、心肌活性 |
| **肺部灌注掃描** | V/Q Scan | Tc-99m MAA | 肺栓塞 |
| **腎功能掃描** | Renal Scan | Tc-99m DMSA/MAG3 | 腎功能、分流 |

### 5.3 PET vs SPECT

| 特性 | **PET** | **SPECT** |
|------|---------|-----------|
| 偵測粒子 | 正電子 | 伽傌射線 |
| 解析度 | 較佳 | 較差 |
| 靈敏度 | 較高 | 較低 |
| 成本 | 較高 | 較低 |
| 可用性 | 較少 | 普遍 |

::: {.content-box .clinical}
## 臨床應用（Clinical Correlation）

**18F-FDG PET在腫瘤學的應用**：
- **肺癌分期**：區分良性與惡性結節、淋巴結轉移、遙處轉移
- **淋巴瘤**：分期和治療效果評估
- **大腸癌**：肝轉移評估、復發偵測
- **黑色素瘤**：哨兵淋巴結定位
- **乳癌**：炎性乳癌評估、遠處轉移

**心肌灌注掃描（Myocardial Perfusion Imaging）**：
- 評估冠狀動脈血流
- 運動或藥物負荷試驗
- 區域性缺血的定位
- 左心室功能評估

**核醫甲狀腺掃描的判讀**：
- **熱結節（Hot Nodule）**：攝取增加，絕大多數為良性
- **冷結節（Cold Nodule）**：攝取缺乏，約5-15%為惡性，需進一步穿刺切片
:::

## 六、影像學選擇原則

### 6.1 根據臨床情況選擇

| 臨床情況 | 首选影像 | 理由 |
|----------|----------|------|
| **創傷（疑似骨折）** | X光 | 快速、便宜、幅射低 |
| **創傷（嚴重、多發傷）** | CT（全來源） | 快速、完整、敏感 |
| **急性中風（排除出血）** | CT | 快速區分出血與缺血 |
| **急性中風（詳細評估）** | MRI DWI | 早期缺血偵測 |
| **軟組織腫塊** | MRI | 最佳軟組織對比 |
| **孕期（安全優先）** | 超聲波 | 無幅射 |
| **關節損傷** | MRI | 軟骨、韌帶評估 |
| **肺部結節** | CT | 細節佳、低幅射 |

### 6.2 幅射劑量比較

| 檢查 | 幅射劑量（mSv） | 相當於自然背景時間 |
|------|-----------------|---------------------|
| 胸部X光 | 0.1 | 10天 |
| 乳房攝影 | 0.4 | 6週 |
| 頭部CT | 2 | 8個月 |
| 胸部CT | 7 | 2年 |
| 腹部CT | 10 | 3年 |
| PET全身 | 25 | 8年 |
| 自然背景 | 3/年 | — |

### 6.3 影像學方法總比較

| 方法 | 幅射 | 軟組織對比 | 速度 | 成本 | 主要優勢 |
|------|------|-----------|------|------|----------|
| **X光** | 低 | 差 | 快 | 低 | 骨頭、空腔臟器 |
| **CT** | 中-高 | 良好 | 快 | 中 | 快速、廣泛應用 |
| **MRI** | 無 | 極佳 | 慢 | 高 | 軟組織、神經 |
| **超聲** | 無 | 良好 | 快 | 低 | 產科、即時 |
| **核醫** | 中 | 功能性 | 慢 | 中-高 | 功能性、全身 |

::: {.content-box .key-points}
## 學習要點

- **X光**是骨折和肺部疾病的首選篩檢工具，但軟組織對比差
- **CT**提供快速横断面影像，適用於創傷和緊急情況，但幅射劑量較高
- **MRI**軟組織對比最佳，適合腦、脊髓、關節軟骨評估，但有金屬禁忌
- **超聲波**無幅射且可即時成像，適合產科和淺層結構評估
- **核醫**提供功能性影像，適合腫瘤分期和器官功能評估
- 選擇影像學方法時需綜合考慮臨床情況、幅射風險、設備可及性和成本
:::
