## 📌 本章重點

- **股神經**（L2-L4）支配股四頭肌，損傷導致伸膝無力
- **閉孔神經**（L2-L4）支配內收肌群
- **坐骨神經**（L4-S3）是全身最大的神經，在梨狀肌下方出骨盆腔
- **腓總神經**（L4-S2）損傷最常見，導致**垂足**（foot drop）
- **隱神經**（L3-L4）是股神經的純感覺分支，支配小腿內側感覺

---

## 1. 股神經（Femoral Nerve, L2-L4）

### 1.1 走行

| 位置 | 說明 |
|------|------|
| 起點 | 腰大肌後方（L2-L4後支） |
| 走行 | 腰大肌與髂肌之間→腹股溝韌帶下方→大腿前面 |
| 終點 | 分支支配大腿前側肌肉與感覺 |

### 1.2 分支與支配

| 類型 | 結構 | 功能 |
|------|------|------|
| **運動分支** | **股四頭肌**（quadriceps femoris） | 伸膝 |
| **運動分支** | **縫匠肌**（sartorius） | 屈髖、屈膝 |
| **運動分支** | **恥骨肌**（pectineus） | 屈髖、內收 |
| **感覺分支** | 前皮質支（前大腿皮神經） | 大腿前側感覺 |
| **感覺分支** | 內側皮質支 | 大腿內側感覺 |
| **感覺分支** | **隱神經**（saphenous nerve） | 小腿內側至內踝感覺 |

> **臨床應用**：股神經損傷的原因包括：
> - 髖關節手術或骨盆骨折
> - 腹膜後血腫（retroperitoneal hematoma）
> - 股动脉穿刺並發症
> - **股神經損傷**導致**伸膝無力**（quadriceps weakness），患者上樓梯困難，膝反射消失

---

## 2. 閉孔神經（Obturator Nerve, L2-L4）

### 2.1 走行

| 位置 | 說明 |
|------|------|
| 起點 | 腰大肌內側（L2-L4） |
| 走行 | 腰大肌內側→**閉孔**（obturator foramen）→大腿內側 |
| 終點 | 支配內收肌群 |

### 2.2 分支與支配

| 類型 | 結構 | 功能 |
|------|------|------|
| **運動分支** | **股薄肌**（gracilis） | 內收大腿、屈膝 |
| **運動分支** | **內收長肌**（adductor longus） | 內收大腿 |
| **運動分支** | **內收短肌**（adductor brevis） | 內收大腿 |
| **運動分支** | **內收大肌**（adductor magnus）（部分） | 內收大腿 |
| **運動分支** | **閉孔外肌**（obturator externus） | 外旋大腿 |
| **感覺分支** | — | 大腿內側感覺（狹窄區域） |

> **臨床應用**：閉孔神經損傷可導致：
> - **內收無力**（adductor weakness）
> - 大腿內側感覺減退
> - 臨床上可見於骨盆骨折、子宮切除術後

---

## 3. 坐骨神經（Sciatic Nerve, L4-S3）

### 3.1 走行

| 位置 | 說明 |
|------|------|
| 起點 | 梨狀肌下方（骶叢，L4-S3） |
| 走行 | 梨狀肌下方→坐骨大切跡→大腿後側 |
| 終點 | 在大腿近端1/3下方分為**脛神經**與**腓總神經** |

> **臨床應用**：**坐骨神經**（sciatic nerve）是全身最大的神經，直徑可達2cm。在骨盆腔內，走行於梨狀肌前方。**梨狀肌綜合症**（piriformis syndrome）是指梨狀肌痙攣或肥大壓迫坐骨神經，導致類似**坐骨神經痛**的癥狀。

### 3.2 分支

| 分支 | 說明 |
|------|------|
| **脛神經**（tibial nerve） | 坐骨神經的內側分支，支配後側所有肌肉 |
| **腓總神經**（common peroneal nerve） | 坐骨神經的外側分支，支配前側與外側肌肉 |

### 3.3 支配

| 類型 | 結構 | 功能 |
|------|------|------|
| **運動分支** | 股二頭肌（長頭）（biceps femoris, long head） | 屈膝、外旋小腿 |
| **運動分支** | 半腱肌（semitendinosus） | 屈膝、內旋小腿 |
| **運動分支** | 半膜肌（semimembranosus） | 屈膝、內旋小腿 |
| **運動分支** | 內收大肌（adductor magnus）（部分） | 內收大腿 |

> **臨床應用**：**坐骨神經痛**（sciatica）是指沿坐骨神經分布區域的疼痛，典型症狀：
> - 疼痛由下背部/臀部向下放射至大腿後側、小腿、足部
> - 可伴隨感覺減退、麻木、刺痛
> - **直腿抬高的經典測試**（straight leg raise test, SLRT）陽性
> - 常見原因：**椎間盤突出**（L4-S1）、椎管狹窄、梨狀肌綜合症

## 4. 腓總神經（Common Peroneal Nerve, L4-S2）

### 4.1 走行

| 位置 | 說明 |
|------|------|
| 起點 | 坐骨神經分支（大腿後側遠端） |
| 走行 | 繞過**腓骨頭**（fibular head）→小腿前側與外側 |
| 終點 | 分為**腓淺神經**與**腓深神經** |

> **臨床應用**：**腓總神經**在腓骨頭處位置最表淺，是下肢最常損傷的神經之一。常見原因：
> - 腓骨頭骨折
> - 膝關節脫位
> - 長時間臥床（姿勢性壓迫）
> - 石膏或止血帶壓迫

### 4.2 分支與支配

| 分支 | 英文名 | 支配肌肉 | 功能 |
|------|--------|---------|------|
| **腓淺神經** | Superficial peroneal nerve | 腓骨長肌、腓骨短肌 | 外翻 |
| **腓深神經** | Deep peroneal nerve | 脛骨前肌、趾長伸肌、拇長伸肌 | 背屈 |

| 分支 | 感覺區域 |
|------|---------|
| **腓淺神經** | 足背（除第1-2趾間） |
| **腓深神經** | 第1-2趾間（足背一小區域） |

### 4.3 臨床表現

> **臨床應用**：**腓總神經損傷**的典型臨床表現：
> - **垂足**（foot drop）：無法背屈，步行時足部拖地
> - **跨閾步態**（steppage gait）：患者步行時高抬大腿以避免足尖拖地
> - 感覺減退：足背與小腿外側

## 5. 隱神經（Saphenous Nerve, L3-L4）

| 項目 | 說明 |
|------|------|
| **起源** | 股神經（L3-L4）的最大感覺分支 |
| **走行** | 股动脉外側→內收管（adductor canal）→小腿內側 |
| **終點** | 內踝前方，終於足內側 |
| **感覺區域** | 小腿內側至足內側（內踝前方） |

> **臨床應用**：隱神經是股神經的純感覺分支，不支配任何肌肉。其行程經過**內收管**（adductor canal），在該處易被卡壓。臨床上可做為**神經阻滞**（nerve block）的目標，也常被用於**微創手術**（如靜脉曲張手術）的取皮瓣區域。

---

## 6. 總表：下肢主要神經功能

| 神經 | 運動功能 | 感覺區域 |
|------|---------|---------|
| **股神經**（L2-L4） | 伸膝（股四頭肌）、屈髖（縫匠肌、恥骨肌） | 大腿前側、內側、小腿內側（隱神經） |
| **閉孔神經**（L2-L4） | 內收（內收肌群） | 大腿內側（狹窄區域） |
| **坐骨神經**（L4-S3） | 屈膝（腘繩肌）、後側所有肌肉 | 小腿與足部（除隱神經分布區） |
| **腓總神經**（L4-S2） | 背屈（脛骨前肌）、外翻（腓骨肌） | 足背、小腿外側 |
| **脛神經**（L4-S3） | 蹠屈（腓腸肌、比目魚肌）、內翻（脛骨後肌） | 足底、小腿後側 |
| **隱神經**（L3-L4） | 無 | 小腿內側至足內側 |

---

## 7. 臨床相關

> **臨床應用**：**下肢神經損傷的診斷流程**：
> 1. 詳細病史（創傷史、手術史、姿勢）
> 2. 運動功能檢查（各肌肉肌力）
> 3. 感覺檢查（各皮區）
> 4. 反射檢查（膝反射、踝反射）
> 5. 特殊測試（SLRT、Thompson test等）
> 6. 影像學檢查（必要時）
> 7. 神經電生理檢查（EMG/NCV）

> **臨床應用**：**腰骶叢**（lumbosacral plexus）損傷的常見原因：
> - 糖尿病性神經病變
> - 骨盆骨折
> - 腫瘤浸潤
> - 血腫壓迫
> - **腰骶叢病變**（lumbosacral plexopathy）的典型表現為大腿前側、內側、後側以及小腿和足部的混合運動和感覺障礙
