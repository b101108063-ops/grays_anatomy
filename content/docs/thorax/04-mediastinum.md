## 本章重點

- 縱膈分為**上縱膈**與**下縱膈**（前、中、後三區）
- 上縱膈包含**胸腺**、**大血管**、**氣管**、**食道**等重要結構
- **主肺動窗**是左側喉返神經和动脉韌帶經過的重要區域

---

## 縱膈分區

縱膈是位於左右肺之間的區域，以**氣管分叉**為界分為上下兩部分：

```
        縱膈分區示意圖
━━━━━━━━━━━━━━━━━━━━━━━━━
       上縱膈
━━━━━━━━━━━━━━━━━━━━━━━━━
前縱膈  │  中縱膈  │  後縱膈
━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 分界標誌

| 界線 | 結構 |
|------|------|
| **上下分界** | 胸骨角（T4）與氣管分叉水平 |
| **前後分界** | 心包膜前緣與胸椎前緣 |

---

## 上縱膈內容物

上縱膈位於胸腔入口與氣管分叉之間，含有以下重要結構：

| 結構 | 位置 | 說明 |
|------|------|------|
| **胸腺（Thymus）** | 前方 | 免疫器官，成年後退化為脂肪 |
| **頭臂靜脈（Brachiocephalic Veins）** | 兩側 | 匯合成上腔靜脈 |
| **無名动脉（Innominate Artery）** | 中線偏左 | 主動脉弓第一分支 |
| **主動脉弓（Aortic Arch）** | 中部 | 跨越左肺門上方 |
| **氣管（Trachea）** | 後方中線 | 進入縱膈後分為左右主支氣管 |
| **食道（Esophagus）** | 氣管後方 | 穿過橫膈進入腹腔 |
| **胸導管（Thoracic Duct）** | 食道後方 | 淋巴回流總管 |
| **迷走神經（Vagus Nerve）** | 氣管兩側 | 支配內臟運動 |

---

## 下縱膈前區（Anterior Mediastinum）

### 位置
- 位於**胸骨體**與**心包膜**之間
- 是四個縱膈分區中最小的

### 內容物

| 結構 | 說明 |
|------|------|
| **胸腺殘餘** | 成年後退化為脂肪組織 |
| **脂肪組織** | 主要由脂肪組成 |
| **淋巴結** | 胸骨旁淋巴結 |

### 臨床意義
前縱膈是**胸腺瘤**、**畸胎瘤**的好發部位。

---

## 下縱膈中區（Middle Mediastinum）

### 位置
- 含有**心臟**和**心包膜**
- 是縱膈中最主要的區域

### 內容物

| 結構 | 說明 |
|------|------|
| **心臟（Heart）** | 偏左位於中縱膈 |
| **心包膜（Pericardium）** | 包繞心臟的雙層膜 |
| **升主動脉（Ascending Aorta）** | 起於左心室 |
| **肺血管** | 左右肺總动脉、肺靜脈 |
| **主肺動窗（Aortopulmonary Window）** | 主動脉弓與肺總动脉之間 |
| **氣管分叉** | 位於約T4-T5水平 |
| **左右主支氣管** | 進入肺門 |

### 主肺動窗（Aortopulmonary Window）

這是位於**主動脉弓**下方與**肺總动脉**之間的空間，是一個重要的臨床區域。

| 結構 | 說明 |
|------|------|
| **左側喉返神經** | 繞過动脉韌帶上行 |
| **动脉韌帶（Ligamentum Arteriosum）** | 胎兒時期肺總动脉與主動脉弓之間的連接 |
| **淋巴結** | 主肺動窗淋巴結 |

> ⚠️ **臨床要點**：左側肺癌或主肺動窗淋巴結病變可侵犯**左側喉返神經**，導致**聲帶麻痺**和**聲音嘶啞**。

---

## 下縱膈後區（Posterior Mediastinum）

### 位置
- 位於**心包膜**後方與**胸椎**之間

### 內容物

| 結構 | 說明 |
|------|------|
| **食道（Esophagus）** | 中線偏左 |
| **降主動脉（Descending Aorta）** | 脊柱左前方 |
| **胸導管（Thoracic Duct）** | 食道後方 |
| **奇靜脈（Azygos Vein）** | 脊柱右側上行 |
| **半奇靜脈（Hemiazygos Vein）** | 脊柱左側 |
| **交感神經鏈** | 椎體兩側 |
| **內臟大神經（Greater Splanchnic Nerve）** | 穿越橫膈 |
| **迷走神經** | 沿食道下行 |

### 奇靜脈系統

| 靜脈 | 匯入 |
|------|------|
| **奇靜脈（Azygos）** | 上腔靜脈 |
| **半奇靜脈（Hemiazygos）** | 奇靜脈 |
| **副奇靜脈（Accessory Hemiazygos）** | 半奇靜脈或奇靜脈 |

---

## 縱膈分區内容物總表

| 區域 | 主要內容物 |
|------|------------|
| **上縱膈** | 胸腺、頭臂靜脈、無名动脉、主動脉弓、氣管、食道、胸導管 |
| **下縱膈前區** | 胸腺殘餘、脂肪組織、淋巴結 |
| **下縱膈中區** | 心臟、心包膜、升主动脉、肺血管、主肺動窗 |
| **下縱膈後區** | 食道、降主動脉、胸導管、奇靜脈、半奇靜脈、交感神經鏈 |

---

## 臨床應用：縱膈疾病

### 縱膈腫瘤分布

| 腫瘤類型 | 常見位置 |
|----------|----------|
| **胸腺瘤** | 前縱膈 |
| **畸胎瘤** | 前縱膈 |
| **淋巴瘤** | 中縱膈（前或中） |
| **神經鞘瘤** | 後縱膈 |
| **食道癌** | 後縱膈 |

### 臨床表現

| 症狀 | 原因 |
|------|------|
| **呼吸困難** | 氣管或支氣管受壓 |
| **吞嚥困難** | 食道受壓 |
| **聲音嘶啞** | 喉返神經麻痺 |
| **胸痛** | 腫瘤侵犯胸壁 |
| **上腔靜脈症候群** | 靜脈回流受阻 |

---

## 臨床要點

1. **縱膈淋巴結**是肺癌分期的重要參考
2. **左側喉返神經**在主肺動窗易受侵犯
3. **縱膈氣腫**常見於氣管損傷後
4. **心臟位置**決定了中縱膈的主要内容
