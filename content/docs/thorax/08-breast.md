## 本章重點

- 乳房位於**第2-6肋骨**表面，主要由**脂肪**和**乳腺**組成
- **Cooper韌帶**支撐乳房結構
- 乳房血液供應主要來自**胸廓內动脉**、**胸外側动脉**、**肋間後动脉**
- **腋窩淋巴結**是乳房淋巴引流的主要目的地

---

## 乳房的位置與界限

### 表面解剖

| 項目 | 說明 |
|------|------|
| **上界** | 第2肋骨 |
| **下界** | 第6肋骨 |
| **內側界** | 胸骨緣 |
| **外側界** | 腋中線 |
| **深度** | 胸肌筋膜前方 |

### 乳房分區

| 分區 | 說明 |
|------|------|
| **乳頭（Nipple）** | 中心突起，含平滑肌 |
| **乳暈（Areola）** | 乳頭周圍色素沉着區 |
| **中央區** | 乳腺集中區 |

---

## 乳房的結構

### 乳腺組織

| 結構 | 說明 |
|------|------|
| **葉（Lobes）** | 15-20個獨立腺體 |
| **小葉（Lobules）** | 每葉包含許多小葉 |
| **乳腺導管（Ducts）** | 收集並輸送乳汁 |
| **脂肪組織** | 包圍腺體，決定乳房大小 |

### Cooper韌帶（Suspensory Ligaments）

| 項目 | 說明 |
|------|------|
| **名稱** | Cooper韌帶（又名懸韌帶） |
| **組成** | 纖維性結締組織 |
| **功能** | 支撐乳房，連接皮膚與胸肌筋膜 |
| **臨床意義** | 乳癌侵犯可導致韌帶攣縮，形成「橘皮樣」改變 |

---

## 乳房血液供應

### 动脉供應

| 血管 | 來源 | 供應區域 |
|------|------|----------|
| **胸廓內动脉（Internal Thoracic Artery）** | 鎖骨下动脉 | 乳房內側 |
| **胸外側动脉（Lateral Thoracic Artery）** | 腋动脉 | 乳房外側 |
| **肋間後动脉（Posterior Intercostal Arteries）** | 主動脉 | 乳房後方 |

### 静脉回流

| 靜脈 | 說明 |
|------|------|
| **內乳靜脈** | 伴隨胸廓內动脉，注入頭臂靜脈 |
| **胸外側靜脈** | 伴隨胸外側动脉 |
| **肋間靜脈** | 注入奇靜脈或半奇靜脈 |

## 乳房淋巴引流

### 主要淋巴引流途徑

```
乳房淋巴引流示意圖

乳房 → 腋窩淋巴結 → 鎖骨下淋巴結 → 鎖骨上淋巴結
                    ↓
              中央群淋巴結
                    ↓
              胸肌間淋巴結
```

### 腋窩淋巴結（Axillary Lymph Nodes）

| 群組 | 位置 | 引流區域 |
|------|------|----------|
| **外側群（ Lateral/Humeral）** | 腋靜脈外側 | 上肢 |
| **前群（Anterior/Pectoral）** | 胸小肌外側 | 乳房外側和上部 |
| **後群（Posterior/Scapular）** | 肩胛下血管周圍 | 背部、肩胛區 |
| **中央群（Central）** | 腋窩中央 | 接收前三群 |
| **尖群（Apical/Supraclavicular）** | 腋靜脈近端 | 乳房最上部 |

### 其他淋巴引流途徑

| 途徑 | 說明 |
|------|------|
| **胸廓內淋巴結** | 乳房內側淋巴引流至縱膈淋巴結 |
| **對側乳房** | 少量交叉引流 |
| **腹直肌鞘淋巴管** | 連接肝臟和横膈淋巴系統 |

## 臨床應用：乳癌淋巴轉移

### 淋巴轉移途徑

| 優先途徑 | 說明 |
|----------|------|
| **腋窩淋巴結** | 最常見轉移途徑 |
| **鎖骨下淋巴結** | 第二站轉移 |
| **鎖骨上淋巴結** | 晚期轉移 |
| **內乳淋巴結** | 乳房內側腫瘤常見 |

### 臨床分期評估

| 分期 | 淋巴結狀態 |
|------|------------|
| **N0** | 無區域淋巴結轉移 |
| **N1** | 可移動的同側腋窩淋巴結 |
| **N2** | 固定的腋窩淋巴結 |
| **N3** | 鎖骨下或鎖骨上淋巴結 |

### 前哨淋巴結（ Sentinel Lymph Node）

| 項目 | 說明 |
|------|------|
| **定義** | 腫瘤引流第一站淋巴結 |
| **定位方法** | 淋巴造影、藍染料、放射性核種 |
| **臨床意義** | 前哨淋巴結陰性可避免過度淋巴結清除 |

## 乳房臨床檢查

### 視診

| 觀察項目 | 異常表現 |
|----------|----------|
| **大小不對稱** | 單側發育或腫瘤 |
| **皮膚改變** | 橘皮樣、紅腫、潰瘍 |
| **乳頭改變** | 內陷、偏斜、分泌物 |
| **靜脈怒張** | 可能是炎性乳癌 |

### 觸診

| 檢查方法 | 目的 |
|----------|------|
| **坐位或仰臥** | 充分暴露乳房 |
| **使用指腹** | 檢查深部組織 |
| **同心圓或放射狀** | 系統性檢查 |
| **檢查淋巴結** | 腋窩、鎖骨上 |

### 影像學檢查

| 檢查 | 適用情況 |
|------|----------|
| **乳房X光攝影（ Mammography）** | 40歲以上篩檢 |
| **乳房超聲波** | 年輕女性、囊腫鑒別 |
| **乳房MRI** | 高風險族群、術前評估 |

---

## 臨床要點

1. **乳房外側**淋巴主要引流入**腋窩淋巴結**
2. **乳房內側**淋巴主要引流入**胸廓內淋巴結**
3. **前哨淋巴結活檢**是乳癌分期的重要步驟
4. **橘皮樣改變**是乳癌侵犯Cooper韌帶的特徵性表現
5. **炎性乳癌**表現為皮膚紅腫熱痛，類似乳腺炎
