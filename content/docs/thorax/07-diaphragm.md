## 本章重點

- 橫膈是**胸腔**與**腹腔**之間的肌肉性分隔
- 三個主要裂孔：主動脉裂孔（T12）、食道裂孔（T10）、Caval裂孔（T8）
- 橫膈由**左、右膈神經**支配（C3, C4, C5）
- 吸氣時橫膈下降**1-10cm**，增加胸腔容積

---

## 橫膈的結構

### 組成部分

| 結構 | 說明 |
|------|------|
| **中心腱（Central Tendon）** | 橫膈的強韌中心，無肌肉纖維 |
| **周圍肌肉** | 起於胸骨、肋骨和腰椎 |

### 肌肉來源

| 來源 | 說明 |
|------|------|
| **胸骨部（Sternal Part）** | 起於劍突後面 |
| **肋骨部（Costal Part）** | 起於第7-12肋骨軟骨內面 |
| **腰椎部（Lumbar Part）** | 起於上3-4腰椎（左右膈腳） |

### 重要神經血管孔道

| 結構 | 位置 | 穿過內容物 |
|------|------|-------------|
| **主動脉裂孔（Aortic Hiatus）** | T12 | 主動脉、胸導管 |
| **食道裂孔（Esophageal Hiatus）** | T10 | 食道、迷走神經 |
| **Caval裂孔（Caval Hiatus）** | T8 | 下腔靜脈 |

---

## 三個主要裂孔

### 主動脉裂孔（Aortic Hiatus）

| 項目 | 說明 |
|------|------|
| **位置** | T12椎體前方 |
| **穿過結構** | 主動脉（降主動脉）、胸導管 |
| **特點** | 不是真正穿過橫膈，而是位於T12與橫膈之間 |

### 食道裂孔（Esophageal Hiatus）

| 項目 | 說明 |
|------|------|
| **位置** | T10水平 |
| **穿過結構** | 食道、迷走神經（前幹和後幹） |
| **臨床意義** | 食道裂孔疝氣的好發部位 |

### Caval裂孔（Caval Hiatus）

| 項目 | 說明 |
|------|------|
| **位置** | T8水平 |
| **穿過結構** | 下腔靜脈、右膈神經 |
| **特點** | 中心腱內的開口 |

---

## 其他孔洞與薄弱區

### 胸肋三角（Sternal Triangle / Parasternal Space）

| 項目 | 說明 |
|------|------|
| **位置** | 胸骨柄與劍突交界處兩側 |
| **組成** | 內側和外側半月線 |
| **特點** | 橫膈胸骨部與肋骨部之間的間隙 |
| **臨床意義** | 先天性橫膈疝氣的可能部位 |

### 腰肋三角（Lumbocostal Triangle）

| 項目 | 說明 |
|------|------|
| **位置** | 腰椎與第12肋骨之間 |
| **組成** | 橫膈腰椎部與肋骨部之間 |
| **特點** | 橫膈最薄弱區域 |
| **臨床意義** | 先天性橫膈疝氣（Morgagni孔和Bochdalek孔） |

### 橫膈裂孔總結

| 裂孔名稱 | 椎體水平 | 穿過結構 |
|----------|----------|----------|
| **主動脉裂孔** | T12 | 主動脉、胸導管 |
| **食道裂孔** | T10 | 食道、迷走神經 |
| **Caval裂孔** | T8 | 下腔靜脈、右膈神經 |
| **胸肋三角** | - | 無重要結構通過 |
| **腰肋三角** | - | 無重要結構通過 |

## 橫膈的神經支配

### 膈神經（Phrenic Nerve）

| 項目 | 說明 |
|------|------|
| **來源** | C3、C4、C5（前頸叢） |
| **左側** | 左心包膜、中心腱、左半橫膈 |
| **右側** | 右心包膜、中心腱、右半橫膈 |
| **感覺纖維** | 分布於中心腱和胸膜、腹膜 |

### 臨床要點

| 情況 | 說明 |
|------|------|
| **打嗝（Hiccup）** | 膈神經受刺激導致橫膈痙攣 |
| **高位頸椎損傷** | 可能影響雙側膈神經 |
| **肺癌侵犯** | 可侵犯同側膈神經 |

---

## 橫膈的呼吸功能

### 吸氣時的運動

| 變化 | 說明 |
|------|------|
| **橫膈下降** | 收縮時向腹腔方向移動 |
| **下降幅度** | 平靜呼吸：1-2cm；用力深呼吸：可達10cm |
| **胸腔容積增加** | 垂直徑增加 |
| **腹壓增加** | 腹腔臟器被向下推移 |

### 呼氣時的運動

| 變化 | 說明 |
|------|------|
| **橫膈上升** | 被動放鬆或主動收縮 |
| **胸腔容積減少** | 垂直徑減少 |
| **腹壓減少** | 腹腔臟器回位 |

### 輔助呼吸肌

| 吸氣輔助肌 | 呼氣輔助肌 |
|------------|------------|
| 斜角肌 | 腹直肌 |
| 胸鎖乳突肌 | 腹內斜肌 |
| 肋間外肌 | 腹外斜肌 |
| 胸大肌 | 肋間內肌 |

---

## 臨床應用：橫膈疾病

### 橫膈疝氣

| 類型 | 說明 |
|------|------|
| **先天性後外側疝氣（Bochdalek孔疝）** | 嬰兒期，多在左側 |
| **先天性胸骨後疝氣（Morgagni孔疝）** | 成人，少見 |
| **食道裂孔疝氣** | 最常見，胃食道交界處 |

### 橫膈麻痺

| 情況 | 說明 |
|------|------|
| **單側橫膈麻痺** | 多因肺癌或甲狀腺手術損傷膈神經 |
| **雙側橫膈麻痺** | 可能導致呼吸衰竭 |

### 橫膈刺激症狀

| 症狀 | 原因 |
|------|------|
| **肩部疼痛** | 膈神經（C3-C5）支配肩部感覺 |
| **打嗝** | 膈神經受刺激 |
| **呼吸困難** | 橫膈功能障礙 |

---

## 臨床要點

1. **膈神經**來源於C3、C4、C5，因此第3-5頸椎損傷會影響呼吸
2. **橫膈是最重要的吸氣肌肉**，佔靜息通氣量的60-80%
3. **左側膈神經**與心包膜關係密切
4. **打嗝**是橫膈間歇性痙攣，可通過刺激迷走神經緩解
