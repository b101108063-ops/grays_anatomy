## 本章重點

- **胸腔出口**是連接頸部與胸腔的重要通道
- 上胸腔出口包含多個重要結構：氣管、食道、鎖骨下血管等
- **胸腔出口症候群**是常見的臨床問題

---

## 上胸腔出口（Thoracic Inlet）

### 邊界結構

上胸腔出口又稱**胸廓入口**，由以下結構圍繞：

| 結構 | 位置 |
|------|------|
| **第一胸椎（T1）** | 後方 |
| **第一對肋骨** | 兩側 |
| **胸骨柄（Manubrium）** | 前方 |

### 重要內容物

穿過上胸腔出口的重要結構：

| 結構 | 說明 |
|------|------|
| **氣管（Trachea）** | 位於中線 |
| **食道（Esophagus）** | 氣管後方 |
| **左側鎖骨下动脉（Left Subclavian Artery）** | 左側 |
| **胸導管（Thoracic Duct）** | 食道後方 |
| **迷走神經（Vagus Nerve）** | 伴隨氣管和食道 |
| **膈神經（Phrenic Nerve）** | 穿越下方的横膈 |

---

## 下胸腔出口（Thoracic Outlet）

### 邊界結構

下胸腔出口又稱**胸廓出口**，由以下結構圍繞：

| 結構 | 說明 |
|------|------|
| **第十二胸椎（T12）** | 後方 |
| **第十二對肋骨** | 兩側後份 |
| **劍突（Xiphoid Process）** | 前方 |
| **橫膈（Diaphragm）** | 下方 |

---

## 臨床應用：胸腔出口症候群

### 胸腔出口症候群（Thoracic Outlet Syndrome, TOS）

胸腔出口症候群是指**臂叢（Brachial Plexus）**和**鎖骨下血管**在胸腔出口處受壓所引起的症候群。

#### 受壓結構

| 結構 | 臨床表現 |
|------|----------|
| **臂叢神經** | 上肢疼痛、麻木、無力 |
| **鎖骨下动脉** | 手指缺血、蒼白 |
| **鎖骨下靜脈** | 上肢水腫、靜脈怒張 |

#### 常見致病原因

| 原因 | 說明 |
|------|------|
| **頸肋（Cervical Rib）** | 第7頸椎橫突過長 |
| **肌肉異常** | 斜角肌肥大或痙攣 |
| **外傷** | 鎖骨骨折後癒合不良 |
| **姿勢不良** | 長期肩部下垂 |

#### 診斷方法

- **Adson 測試**：頭部轉向患側並深吸氣，檢測橈動脉脈搏變化
- **Wright 測試**：手臂外展90度外旋，檢測脈搏變化
- **影像學檢查**：X光、CT、MRI

#### 治療方式

| 治療方式 | 適應症 |
|----------|--------|
| **保守治療** | 物理治療、姿勢矫正、消炎藥物 |
| **手術治療** | 頸肋切除、斜角肌切斷術 |

---

## 胸腔出口重要解剖關係

```
         前斜角肌
            │
    臂叢 ───┼─── 鎖骨下动脉
            │
         中斜角肌
            │
         胸腔出口
```

### 重要通道

- **前斜角肌（Anterior Scalene）**與**中斜角肌（Middle Scalene）**之間的間隙是臂叢和鎖骨下动脉的通道
- **第一肋骨**是胸腔出口的底座

---

## 臨床要點

1. **胸腔出口症候群**好發於30-50歲女性
2. **頸肋**約見於1%人口，但僅少數有症狀
3. **職業因素**：長期使用滑鼠、反覆抬手動作者風險較高
4. **鑑別診斷**：需排除頸椎病變、腕隧道症候群、心絞痛等
