## 本章重點

- **主動脉**是體循環的主幹，分為升主動脉、主動脉弓、降主動脉
- **主動脉弓**發出三個分支供應頭頸部及上肢
- **肺血管**負責肺循環的血液運輸
- **奇靜脈系統**是胸腔重要的側支循環

---

## 主動脉（Aorta）

### 主動脉分部

| 分部 | 範圍 | 重要分支 |
|------|------|----------|
| **升主動脉（Ascending Aorta）** | 左心室至主動脉弓起點 | 左右冠狀动脉 |
| **主動脉弓（Aortic Arch）** | 跨越左肺門上方 | 頭臂干、左頸總动脉、左鎖骨下动脉 |
| **降主動脉（Descending Aorta）** | T4至橫膈 | 肋間动脉、內臟动脉 |

### 升主動脉

| 結構 | 說明 |
|------|------|
| **起始** | 左心室主動脉口 |
| **長度** | 約5cm |
| **重要分支** | 左右冠狀动脉（供應心臟） |
| **位置** | 心包膜內，肺總动脉後方 |

### 主動脉弓

主動脉弓從前向後跨越左肺門上方，然後在T4水平延續為降主動脉。

| 分支 | 說明 |
|------|------|
| **頭臂干（Brachiocephalic Trunk）** | 右側第一分支，分為右頸總动脉和右鎖骨下动脉 |
| **左頸總动脉（Left Common Carotid Artery）** | 直接發出，供應頸部和頭部左側 |
| **左鎖骨下动脉（Left Subclavian Artery）** | 直接發出，供應左上肢和左側腦 |

### 降主動脉

| 項目 | 說明 |
|------|------|
| **位置** | 胸椎前方，偏左 |
| **穿過橫膈** | 主動脉裂孔（T12） |
| **延續** | 腹主動脉 |

## 肺血管（Pulmonary Vessels）

### 肺總动脉（Pulmonary Trunk）

| 結構 | 說明 |
|------|------|
| **起始** | 右心室漏斗部 |
| **分支** | 左右肺动脉 |
| **特點** | 攜帶缺氧血（體循環靜脈血） |

### 左右肺动脉

| 分支 | 進入肺葉 |
|------|----------|
| **右肺动脉** | 進入右肺門，分為上中下三支 |
| **左肺动脉** | 進入左肺門，分為上下二支 |

### 肺靜脈（Pulmonary Veins）

| 數量 | 名稱 |
|------|------|
| **4條** | 左上肺靜脈、左下肺靜脈、右上肺靜脈、右下肺靜脈 |
| **特點** | 攜帶含氧血（肺循環動脈血） |

---

## 上腔靜脈（Superior Vena Cava, SVC）

### 組成

| 靜脈 | 匯合 |
|------|------|
| **左頭臂靜脈（Left Brachiocephalic Vein）** | 與右頭臂靜脈 |
| **右頭臂靜脈（Right Brachiocephalic Vein）** | 匯合形成SVC |

### 解剖特點

| 項目 | 說明 |
|------|------|
| **形成位置** | 左右無名静脉匯合 |
| **接收** | 奇靜脈（通過半奇靜脈） |
| **注入** | 右心房 |
| **長度** | 約6-8cm |

---

## 下腔靜脈（Inferior Vena Cava, IVC）

### 穿過橫膈

| 結構 | 位置 |
|------|------|
| **Caval裂孔** | T8椎體 |
| **下腔靜脈** | 通過裂孔後立即注入右心房 |

### 相關結構

| 結構 | 說明 |
|------|------|
| **肝靜脈** | 在橫膈下方注入IVC |
| **腎靜脈** | L2水平注入IVC |
| **肝門靜脈** | 通過肝臟後注入IVC |

## 奇靜脈系統（Azygos Venous System）

奇靜脈系統是胸腔後壁的重要靜脈回流通道，與椎靜脈系統有廣泛吻合。

### 奇靜脈（Azygos Vein）

| 項目 | 說明 |
|------|------|
| **起始** | 右腰升靜脈（穿橫膈後） |
| **走行** | 沿胸椎右側上行 |
| **接收** | 右肋間靜脈、半奇靜脈、食道靜脈、支氣管靜脈 |
| **注入** | 上腔靜脈（後方） |

### 半奇靜脈（Hemiazygos Vein）

| 項目 | 說明 |
|------|------|
| **起始** | 左腰升靜脈（穿橫膈後） |
| **走行** | 沿胸椎左側上行 |
| **接收** | 左下3-4肋間靜脈 |
| **注入** | 奇靜脈（T7-T9水平） |

### 副奇靜脈（Accessory Hemiazygos Vein）

| 項目 | 說明 |
|------|------|
| **位置** | T3-T7椎體左側 |
| **接收** | 左上4-5肋間靜脈 |
| **注入** | 半奇靜脈或奇靜脈 |

### 臨床意義

| 情況 | 說明 |
|------|------|
| **上腔靜脈阻塞** | 奇靜脈系統成為重要側支通道 |
| **門靜脈高壓** | 可經奇靜脈系統分流 |
| **椎靜脈系統** | 與奇靜脈系統廣泛吻合 |

## 臨床應用：大血管疾病

### 主動脉疾病

| 疾病 | 說明 |
|------|------|
| **主動脉夾層** | 內膜撕裂，血液進入中層 |
| **主動脉瘤** | 主動脉局部擴張 |
| **主動脉竇瘤** | 主動脉竇部擴張 |

### 主動脉夾層 Stanford 分型

| 分型 | 說明 |
|------|------|
| **Type A** | 涉及升主動脉（需緊急手術） |
| **Type B** | 仅涉及降主動脉（可用藥物控制） |

### 肺血管疾病

| 疾病 | 說明 |
|------|------|
| **肺栓塞** | 血栓阻塞肺动脉 |
| **肺動脈高壓** | 肺循環阻力增加 |
| **肺靜脈血栓** | 導致肺淤血 |

---

## 臨床要點

1. **主動脉弓**在左側喉返神經下方繞過
2. **頭臂干**是主動脉弓最粗的分支
3. **奇靜脈系統**是胸腔重要的側支循環
4. **肺靜脈**沒有瓣膜，肺循環回心血流直接進入左心房
