## 本章重點

- 心臟位於**中縱膈**，偏左，受**心包膜**包繞
- 心臟由**四個腔室**（左右心房、左右心室）組成
- **冠狀循環**供應心臟肌肉本身
- **傳導系統**確保心臟協調收縮

---

## 心臟位置與心包膜

### 心臟位置

| 項目 | 說明 |
|------|------|
| **位置** | 中縱膈，偏左 |
| **水平** | 約 T5-T8 |
| **前面** | 胸骨和肋軟骨 |
| **後面** | 食道和主動脉 |
| **下面** | 橫膈 |

### 心包膜（Pericardium）

心包膜是包繞心臟的雙層膜結構：

| 層次 | 名稱 | 說明 |
|------|------|------|
| 外層 | **壁層心包膜（Fibrous Pericardium）** | 堅韌的纖維層 |
| 內層 | **臟層心包膜（Visceral Pericardium/Epicarium）** | 附著於心臟表面 |
| 腔隙 | **心包腔（Pericardial Cavity）** | 含少量漿液（約20-50ml） |

## 心臟外部結構

### 心臟表面標誌

| 結構 | 位置 | 說明 |
|------|------|------|
| **冠狀溝（Coronary Sulcus）** | 心房與心室交界 | 含冠狀血管和脂肪 |
| **前室間溝（Anterior Interventricular Sulcus）** | 左右心室前面 | 含左冠狀动脉前降支 |
| **後室間溝（Posterior Interventricular Sulcus）** | 左右心室後面 | 含後降支动脉 |
| **心尖（Appex）** | 左心室尖端 | 朝向左下前方 |

### 心臟外形

| 表面 | 主要構成 |
|------|----------|
| **胸肋面（Sternocostal Surface）** | 右心房、右心室、左心室部分 |
| **膈面（Diaphragmatic Surface）** | 左心室、右心室部分 |
| **肺面（Pulmonary Surface）** | 左心室 |

---

## 心臟內部結構

### 右心房（Right Atrium）

| 結構 | 位置 | 說明 |
|------|------|------|
| **卵圓窩（Fossa Ovalis）** | 房間隔中部 | 胎兒時期卵圓孔的遺蹟 |
| **竇房結（SA Node）** | 右心房上部外側壁 | 心臟正常起搏點 |
| **界嵴（Crista Terminalis）** | 右心房外側壁 | 竇房結所在地 |
| **上下腔靜脈入口** | 卵圓窩兩側 | 回收體循環靜脈血 |

### 右心室（Right Ventricle）

右心室是心臟最前面的腔室，結構如下：

| 結構 | 說明 |
|------|------|
| **Triad（三合一結構）** | 流入道、流出道、乳頭肌 |
| **流入道（Inlet）** | 三尖瓣口，接收右心房血液 |
| **流出道（Outlet）** | 肺动脉口，通向肺循環 |
| **乳頭肌（Papillary Muscles）** | 控制腱索，防止瓣膜脫垂 |
| **腱索（Chordae Tendineae）** | 連接乳頭肌與瓣膜邊緣 |

右心室壁厚度：**2-3mm**（因需克服低肺循環阻力）

### 左心房（Left Atrium）

| 結構 | 說明 |
|------|------|
| **肺靜脈入口** | 4條肺靜脈匯入（左、右各2條） |
| **左心耳（Left Atrial Appendage）** | 胚胎時期梳狀肌殘餘 |
| **房間隔** | 與右心房相隔 |

### 左心室（Left Ventricle）

| 結構 | 說明 |
|------|------|
| **壁厚度** | **9-12mm**（最厚，因需克服體循環高血壓） |
| **二尖瓣口** | 流入道 |
| **主動脉口** | 流出道 |
| **乳頭肌** | 兩群（前外側、後內側） |

## 心臟瓣膜

### 房室瓣（Atrioventricular Valves）

| 瓣膜 | 位置 | 結構特點 |
|------|------|----------|
| **三尖瓣（Tricuspid Valve）** | 右心房與右心室之間 | 3個瓣葉 |
| **二尖瓣（Mitral Valve）** | 左心房與左心室之間 | 2個瓣葉（前瓣較大） |

### 半月瓣（Semilunar Valves）

| 瓣膜 | 位置 | 結構特點 |
|------|------|----------|
| **肺動脈瓣（Pulmonary Valve）** | 右心室與肺總动脉之間 | 3個半月瓣 |
| **主動脉瓣（Aortic Valve）** | 左心室與主動脉之間 | 3個半月瓣 |

## 冠狀循環（Coronary Circulation）

### 左冠狀动脉（Left Coronary Artery, LCA）

| 分支 | 供應區域 |
|------|----------|
| **左前降支（Left Anterior Descending, LAD）** | 左心室前壁、室間隔前2/3、右心室部分 |
| **左迴旋支（Left Circumflex, LCx）** | 左心室側壁、後壁部分 |

### 右冠狀动脉（Right Coronary Artery, RCA）

| 分支 | 供應區域 |
|------|----------|
| **右邊緣支（Right Marginal）** | 右心室 |
| **後降支（Posterior Descending Artery, PDA）** | 室間隔後1/3、左心室後壁 |

### 冠狀静脉

| 静脉 | 說明 |
|------|------|
| **心大静脉** | 伴隨LAD |
| **心中静脉** | 伴隨PDA |
| **心小静脉** | 直接注入冠狀窦 |
| **冠狀窦（Coronary Sinus）** | 注入右心房 |

## 心臟傳導系統

心臟傳導系統確保心房和心室的協調收縮：

```
竇房結 (SA Node)
    ↓
房室結 (AV Node)
    ↓
His束 (Bundle of His)
    ↓
左右束支 (Bundle Branches)
    ↓
Purkinje纖維 (Purkinje Fibers)
    ↓
心室肌肉
```

### 各結構特點

| 結構 | 位置 | 功能 |
|------|------|------|
| **竇房結（SA Node）** | 右心房上部 | 正常心臟起搏點（60-100bpm） |
| **房室結（AV Node）** | 房間隔下部 | 延遲傳導，保護心室 |
| **His束** | 室間隔上部 | 傳導興奮到心室 |
| **左右束支** | 沿室間隔下行 | 分布到心室各處 |
| **Purkinje纖維** | 心室肌內 | 快速傳導，確保同步收縮 |

## 臨床應用：心臟疾病

### 心肌缺血分布

| 冠狀动脉 | 供應區域 | 缺血症狀 |
|----------|----------|----------|
| LAD | 前壁、室間隔 | 胸前導聯ST壓低 |
| LCx | 側壁 | I, aVL導聯ST變化 |
| RCA | 下壁、後壁 | II, III, aVF導聯ST變化 |

### 傳導系統障礙

| 病變部位 | 心電圖表現 |
|----------|------------|
| **竇房結** | 竇性心動過緩、竇性停搏 |
| **房室結** | AV block（不同程度） |
| **His束以下** | 束支傳導阻滯 |

---

## 臨床要點

1. **左心室壁最厚**（9-12mm），因體循環血壓高
2. **冠狀动脉**主要在心舒張期灌注
3. **竇房結**由右冠狀动脉供血者約佔60%
4. **二尖瓣狹窄**可導致左心房增大和肺淤血
