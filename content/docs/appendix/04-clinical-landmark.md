## 本章重點

> 📌 **臨床解剖標誌的實用價值**
> - 頸部：**頸總动脉搏動**（胸鎖乳突肌前方）；甲狀軟骨（Adam's apple）；氣管
> - 胸部：心尖搏動（第5肋間、鎖骨中線內側）；肝上界（右鎖骨中線第5肋間）；闌尾壓痛點（McBurney's point）
> - 四肢：主要**动脉搏動點**（橈动脉、尺动脉、股动脉、膕动脉、足背动脉、脛後动脉）
> - 神經：**面神经**（耳屏前方）；**腋神经**（三角肌後方）；**坐骨神经**（梨狀肌下方）
> - 穿刺位置：腰椎穿刺（L3-L4或L4-L5）；硬膜外麻醉（L2以下）

## 頭頸部臨床標誌

### 頸部表面解剖

| 標誌 | 位置/描述 | 臨床應用 |
|------|----------|---------|
| **甲狀軟骨（Thyroid Cartilage）** | 頸部前方、C4-C5水平；男性俗稱「Adam's apple」 | 甲狀腺手術定位；喉結識別 |
| **環狀軟骨（Cricoid Cartilage）** | 甲狀軟骨下方、C6水平 | 氣管切開術定位（切開環甲膜） |
| **胸鎖乳突肌（Sternocleidomastoid, SCM）** | 兩側斜向走行的肌肉 | 頸部淋巴結分區標誌；SCM前緣為**頸總动脉搏動點** |
| **鎖骨上窩（Supraclavicular Fossa）** | 鎖骨上方、三角形凹陷 | **Virchow's Node（左側）**位置；肺癌轉移信號 |
| **氣管（Tachea）** | 頸部正中線、甲狀軟骨與胸骨之間 | 氣管偏移（張力性氣胸、血胸）；氣管切開術 |
| **甲狀腺（Thyroid Gland）** | 氣管前方、環狀軟骨下方 | 甲狀腺腫大（Goiter）；甲狀旁腺位置（甲狀腺後方） |

:::臨床應用
**頸部三角（Cervical Triangles）**
- **頸前三角（Anterior Triangle）**：SCM前緣、頸正中線、下頜骨下緣之間
  - 包含：頸總动脉、頸內静脉、迷走神经、喉返神经、甲狀腺
- **頸後三角（Posterior Triangle）**：SCM後緣、斜方肌前緣、鎖骨之間
  - 包含：副神经（accessory nerve）、臂叢、鎖骨下动脉

**頸部淋巴結分期手術**需注意保護副神经（CN XI）- 支配斜方肌
:::

### 頭部表面標誌

| 標誌 | 位置 | 臨床應用 |
|------|------|---------|
| **顱骨縫線（Skull Sutures）** | 冠狀縫、矢狀縫、人字縫 | 顱內壓升高時分開；嬰兒顱縫 |
| **前囪（Anterior Fontanelle）** | 額骨與頂骨之間 | 嬰兒顱內壓評估；腦積水時飽滿或突出 |
| **翼點（Pterion）** | 額骨、頂骨、顳骨、蝶骨交匯處 | 硬膜外血腫（**中腦膜动脉**破裂）；顱骨切開術 |
| **星點（Asterion）** | 頂骨、顳骨、枕骨交匯處 | 乙狀竇定位 |
| **乳突（ Mastoid Process）** | 耳後骨性突起 | 乳突炎壓痛；面神经離開莖乳孔位置 |
| **莖乳孔（Stylomastoid Foramen）** | 乳突前方 | **面神经（CN VII）**出口 |
| **枕外粗隆（External Occipital Protuberance）** | 枕骨中部 | 腰椎穿刺體表定位（連線兩側乳突） |

## 胸部臨床標誌

### 胸前壁重要標誌

| 標誌 | 位置/描述 | 臨床應用 |
|------|----------|---------|
| **胸骨柄（Manubrium）** | 胸骨上部 | 第2肋間（胸骨旁）- 心包膜穿刺（向左） |
| **胸骨角（Angle of Louis）** | 胸骨柄與胸骨體交界處、T4-T5水平 | 第2肋間定位；縱隔分界標誌 |
| **劍突（Xiphoid Process）** | 胸骨最下端 | 肝左葉定位；心包膜穿刺（左側） |
| **鎖骨（Clavicle）** | 橫跨胸廓上方 | 鎖骨中線定位（心尖搏動）；第一肋骨定位 |
| **肋骨（Ribs）** | 12對 | 肋間定位；肋骨骨折壓痛點 |
| **肋間隙（Intercostal Spaces, ICS）** | 相鄰兩肋之間 | 胸腔穿刺定位 |

### 心臟與胸腔重要定位

| 結構 | 解剖位置 | 臨床相關 |
|------|---------|---------|
| **心尖搏動（Apical Impulse）** | 第5肋間、**鎖骨中線內側**約1cm | 左心室擴大；心肌梗塞定位 |
| **心臟濁音界** | 右側：胸骨右緣；左側：心尖；上界：第3肋間 | 心臟大小評估 |
| **肝上界（Hepatic Dullness）** | 右鎖骨中線第**5**肋間 | 肝臟大小；肝臟觸診（正常右肋弓下不可觸及） |
| **脾濁音界** | 左腋中線第9-11肋 | 脾腫大觸診 |
| **肺肝境界（Traube's Space）** | 左鎖骨中線第6肋間以下 | 鼓音（肺）；若濁音可能脾腫大 |

:::臨床應用
**心包膜穿刺（Pericardiocentesis）**
- 適應症：心包膜積液、心包膜填塞（Cardiac Tamponade）
- 穿刺位置：劍突與左肋緣呈45度角，向上向後進針
- 或：左第5肋間、心濁音界內側1-2cm（向左肩胛骨方向）
- 風險：心肌刺穿、冠狀动脉損傷、氣胸
:::

### 腹部重要標誌與壓痛點

| 標誌 | 位置 | 臨床應用 |
|------|------|---------|
| **McBurney's Point** | 右髂前上棘（ASIS）與臍連線外**1/3**處 | **闌尾壓痛點**；闌尾炎診斷（反跳痛、Blumberg's sign） |
| **Lanz Point** | 左右髂前上棘連線**右1/3**處 | 闌尾壓痛點變異 |
| **Murphy's Sign** | 右肋緣下、膽囊點（鎖骨中線） | 急性膽囊炎（深吸氣時壓痛） |
| **Grey-Turner's Sign** | 腰區兩側瘀斑 | 急性壞死性胰臟炎（胰酶外滲） |
| **Cullen's Sign** | 臍周瘀斑 | 急性壞死性胰臟炎（血液外滲） |
| **Rovsing's Sign** | 左下腹壓痛誘發右下腹痛 | 闌尾炎輔助診斷 |

:::臨床應用
**腹部九分法（九象限）**
- **右上象限（RUQ）**：肝、膽囊、胰頭、腎上腺、右結腸曲
- **左上象限（LUQ）**：脾、胃、胰尾、左結腸曲、左腎
- **右下象限（RLQ）**：盲腸、闌尾、右輸尿管、右卵巢（女）
- **左下象限（LLQ）**：乙狀結腸、左輸尿管、左卵巢（女）
- **中上象限（Epigastrium）**：胃、十二指腸、胰、肝（部分）、主動脈

**急腹症鑑別診斷**需結合：壓痛點、肌肉防禦（Guarding）、反跳痛（Rebound tenderness）
:::

## 四肢臨床標誌

### 上肢动脉搏動點

| 动脉 | 觸摸位置 | 臨床意義 |
|------|---------|---------|
| **鎖骨下动脉（Subclavian A.）** | 鎖骨中點上方 | 測量血壓（上肢）；鎖骨下动脉竊取症候群 |
| **腋动脉（Axillary A.）** | 腋窩（手臂外展90度） | 腋窝淋巴結手術注意；腋动脉損傷 |
| **肱动脉（Brachial A.）** | 肘窩內側、肱二頭肌腱內側 | 血壓測量（聽診柯氏音）；心導管術（股动脉失敗時） |
| **橈动脉（Radial A.）** | 腕掌側、橈骨莖突內側、**掌長肌腱外側** | 傳統把脈位置；Allen test（測試尺动脉側支） |
| **尺动脉（Ulnar A.）** | 腕掌側、尺骨莖突內側、屈指淺肌腱外側 | 尺神经损伤的血管徵象 |
| **掌弓（Palmar Arches）** | 手掌 | 深弓（尺动脉為主）；淺弓（橈动脉為主） |

:::臨床應用
**Allen Test（尺动脉側支循環測試）**
- 方法：同時壓迫橈动脉和尺动脉→令患者握拳放開→解除尺动脉壓迫
- 正常：手掌在5秒內充血（尺动脉側支暢通）
- 異常：手掌不充血→尺动脉側支不足→不宜做橈动脉穿刺或橈动脉-冠狀动脉搭橋
:::

### 上肢神經標誌

| 神經 | 表面位置 | 臨床相關 |
|------|---------|---------|
| **正中神经（Median Nerve）** | 腕管內、掌長肌腱與橈側腕屈肌腱之間 | **腕管症候群（CTS）**；腕管切開減壓術 |
| **尺神經（Ulnar Nerve）** | 尺神經溝（尺骨鷹嘴與肱骨內上髁之間） | 尺神经損傷（肘關節外傷）；尺神经溝減壓 |
| **橈神經（Radial Nerve）** | 肱骨中段後方（螺旋溝）→前臂外側 | 肱骨骨折常見損傷；橈神经感覺支（前臂外側、手背） |
| **肌皮神经（Musculocutaneous Nerve）** | 肘窩外側、肱二頭肌腱外側 | 前臂外側感覺（前臂外側皮神经） |
| **腋神经（Axillary Nerve）** | 三角肌後緣 | 三角肌萎縮；肩關節脫位常見損傷 |

### 下肢动脉搏動點

| 动脉 | 觸摸位置 | 臨床意義 |
|------|---------|---------|
| **股动脉（Femoral A.）** | **腹股溝韌帶中點**（恥骨結節與髂前上棘連線中點） | 介入手術入路（心導管）；股动脉搏動消失（主動脈縮窄） |
| **膕动脉（Popliteal A.）** | 膕窩中央、膝關節屈曲時易觸摸 | 膝關節手術注意；膕动脉瘤 |
| **脛前动脉（Anterior Tibial A.）** | 踝關節前方、內外踝連線中點（**足背动脉 dorsalis pedis**） | 足背动脉搏動減弱→周邊动脉疾病（PAD） |
| **脛後动脉（Posterior Tibial A.）** | 內踝後方、跟腱內側 | 糖尿病足評估；PT artery bypass |
| **腓动脉（Peroneal A.）** | 外踝後方 | 足外側供血；糖尿病足常受侵犯 |

:::臨床應用
**下肢慢性周邊动脉疾病（PAD）評估**
- **觸診順序**：股动脉→膕动脉→足背动脉→脛後动脉
- **正常**：所有搏動存在且對稱
- **異常**：搏動減弱或消失→ABI（踝肱指數）<0.9
- **常見病因**：動脈粥樣硬化、糖尿病、雷諾氏症
- **間歇性跛行（Claudication）**：行走時小腿疼痛，休息緩解
:::

### 下肢神經標誌

| 神經 | 表面位置 | 臨床相關 |
|------|---------|---------|
| **坐骨神经（Sciatic Nerve）** | 梨狀肌（Piriformis）下方→大腿後側 | 梨狀肌症候群；坐骨神经痛（Sciatica） |
| **腓總神经（Common Peroneal Nerve）** | 腓骨頭外側 | 創傷常見；垂足（Foot Drop） |
| **隱神经（Saphenous Nerve）** | 內踝前方、大腿內側 | 大隱靜脈手術時易受傷；感覺異常 |
| **股外側皮神经（LFCN）** | 髂前上棘內側、腹股溝韌帶下方 | **感覚異常性股痛（Meralgia Paresthetica）** |
| **腓腸神经（Sural Nerve）** | 外踝後方、小腿後外側 | 疼痛門診（神經瘤）；取神經移植 |

## 穿刺位置與操作標誌

### 腰椎穿刺（Lumbar Puncture, LP）

| 項目 | 內容 |
|------|------|
| **穿刺位置** | **L3-L4** 或 **L4-L5** 椎間隙 |
| **定位方法** | 兩側髂嵴最高點連線（Tuffier's line）＝**L3-L4** 或 **L4** 棘突間隙 |
| **穿刺層次** | 皮膚→皮下→棘上韌帶→棘間韌帶→黃韌帶→硬膜外腔→硬膜→蛛網膜下腔 |
| **穿刺角度** | 稍向頭側（15-20度），兒童可垂直 |
| **正常腦脊髓液** | 無色透明、壓力70-180 mmH₂O、蛋白<45mg/dL、葡萄糖40-70mg/dL |

:::臨床應用
**腰椎穿刺禁忌症**
- **顱內壓升高（疑似腦疝）**：腰穿後顱內壓驟降→腦組織向下移位→小腦扁桃體嵌頓
- 穿刺部位感染
- 出血體質（血小板<50,000、凝血障礙）
- 脊髓佔位病變

**腦積水（Hydrocephalus）**時腦室-腹腔（VP）分流術前需排除顱內感染
:::

### 硬膜外麻醉（Epidural Anesthesia）

| 項目 | 內容 |
|------|------|
| **穿刺位置** | **L2以下**（避免損傷脊髓終絲） |
| **間隙判定** | 阻力消失法（Loss of Resistance）：使用空針，穿過黃韌帶時阻力突然消失 |
| **置管深度** | 硬膜外腔3-5cm |
| **孕婦麻醉** | 常選L3-L4；藥物擴散範圍受孕婦骨盆影響 |

### 胸腔穿刺（Thoracentesis）

| 項目 | 內容 |
|------|------|
| **穿刺位置** | **患側**第**7-8肋間**、**腋中線**或**腋後線** |
| **進針位置** | 下一肋上緣（避免損傷肋間神经血管束） |
| **穿刺層次** | 皮膚→皮下→肋間外肌→肋間內肌→胸內筋膜→壁層胸膜 |
| **超聲定位** | 首選超聲引導，確認積液深度及安全性 |

:::臨床應用
**肋間神经血管束位置**
- 每一肋骨下緣有**肋間神经（Nerve）、肋間动脉（Artery）、肋間靜脈（Vein）**（由上而下）
- 穿刺時應沿下一肋**上緣**進針，以免損傷神經血管束
- 錯誤：肋間下緣進針→損傷神經→術後神經痛
:::

### 心包膜穿刺（Pericardiocentesis）

| 項目 | 內容 |
|------|------|
| **穿刺位置** | 劍突與左肋緣夾角（**左劍肋角**）向上向後進針 |
| **或** | 左第5或第6肋間、心濁音界內側1-2cm |
| **深度** | 3-5cm（可達心包膜前壁） |
| **適應症** | 心包膜填塞（Cardiac Tamponade）- 抽出液體可立即緩解症狀 |

### 腹腔穿刺（Paracentesis）

| 項目 | 內容 |
|------|------|
| **穿刺位置** | 臍與恥骨連線中點或左下腹（避開手術疤痕） |
| **深度** | 2-3cm（腹壁各層） |
| **適應症** | 腹水引流（肝硬化、癌症）；診斷性化驗 |
| **注意** | 大量腹水時應緩慢放液（避免低血壓）；術前排空膀胱 |

### 關節穿刺常見位置

| 關節 | 穿刺位置 |
|------|---------|
| **膝關節** | 髕骨外側或內側緣中點、屈膝90度 |
| **肩關節** | 前方（肱骨頭與肩胛喙突之間）或後方（肩峰下） |
| **肘關節** | 後方（尺骨鷹嘴與肱骨外上髁之間） |
| **腕關節** | 背側（鼻咽窩-拇指肌腱外側）或掌側 |
| **踝關節** | 前方（伸趾長肌腱外側）或內踝下方 |
| **髖關節** | 前方（恥骨結節外側、下方）｜後方（大轉子與髂後上棘連線） |

## 神經搏動點與易損傷部位

### 主要神經搏動點（神經外科/麻醉參考）

| 神經 | 表面位置 | 臨床意義 |
|------|---------|---------|
| **面神经（Facial Nerve, CN VII）** | 耳屏前方約2.5cm、莖乳孔出口 | 耳後手术（乳突手術）時注意；面癱修復定位 |
| **腋神经（Axillary Nerve）** | 三角肌後方、四邊孔（Quadrangular Space） | 肩關節脫位常見損傷 |
| **坐骨神经（Sciatic Nerve）** | 梨狀肌下方、坐骨大切跡 | 梨狀肌症候群；臀部肌肉注射定位（外上象限） |
| **股神经（Femoral Nerve）** | 腹股溝韌帶下方、股动脉外側 | 腹膜後手術注意；股动脉穿刺定位 |
| **閉孔神经（Obturator Nerve）** | 閉孔膜上方 | 內收肌阻斷麻醉 |

### 常見骨折與神經損傷關聯

| 骨折部位 | 常見神經損傷 |
|---------|------------|
| 肱骨中段 | 橈神经（Radial N.） |
| 肱骨內上髁 | 尺神经（Ulnar N.） |
| 肱骨外上髁 | 橈神经深支 |
| 前臂（Monteggia） | 橈神经 |
| 腓骨頭 | **腓總神经（Common Peroneal N.）** |
| 鎖骨 | 臂叢（Brachial Plexus） |
| 骨盆 | 坐骨神经（髖臼骨折） |

:::臨床應用
**肌肉注射（IM Injection）安全部位**
- **三角肌（Deltoid）**：上臂外側、肩峰下2-3横指
  - 風險：腋神经損傷；應避開三角肌下方（易傷及橈神经）
- **臀大肌（Gluteus Maximus）**：外上象限（避免內下象限-坐骨神经）
  - 安全定位：十字交叉法（髂前上棘與尾骨連線×連線中點垂線）
- **股外側肌（Vastus Lateralis）**：大腿前外側
  - 適合兒童；無重大神經血管
- **臀中肌（Gluteus Medius）**：更安全取代臀大肌（外上象限）
:::

## 體表面積計算（BSA）與劑量調整

| 方法 | 公式/說明 | 臨床應用 |
|------|---------|---------|
| **Mosteller公式** | √(身高cm × 體重kg / 3600) | 化療藥物劑量計算 |
| **Du Bois公式** | 0.007184 × 身高^0.725 × 體重^0.425 | 輸液、熱量計算 |
| **9法則（Rule of 9）** | 頭9%、上肢各9%、前軀幹18%、後軀幹18%、下肢各18%、會陰1% | **燒傷面積評估（TBSA）** |
