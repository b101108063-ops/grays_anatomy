## 本章重點

> 📌 **全身主要血管走向**
> - 頭頸部：**頸總动脉→頸外动脉+頸內动脉**；**椎动脉**供應腦部
> - 主動脈弓三大分支：**無名动脉、左頸總动脉、左鎖骨下动脉**
> - 腹主动脉三個主要不成對分支：**腹腔干（Celiac Trunk）、腸繫膜上动脉（SMA）、腸繫膜下动脉（IMA）**
> - 下肢動脉順序：髂外动脉→**股动脉（Femoral A.）**→膕动脉→**脛前/脛後/腓动脉**
> - 靜脈回流：上/下腔靜脈系統；**門靜脈系統**（脾靜脈+SMV→門靜脈）

## 頭頸部血管

### 頸部动脉

| 动脉 | 起源 | 主要分支 | 供應區域 |
|------|------|---------|---------|
| **頸總动脉（Common Carotid A.）** | 右側：無名动脉；左側：主動脈弓 | 甲狀軟骨上緣分為頸內/頸外动脉 | 頸部、甲狀腺、腦（經頸內动脉） |
| **頸內动脉（Internal Carotid A.）** | 頸總动脉 | 大腦前动脉、大脑中动脉、眼动脉 | 大腦（基底核、額葉、頂葉、顳葉）、眼眶 |
| **頸外动脉（External Carotid A.）** | 頸總动脉 | 甲狀腺上动脉、舌动脉、面动脉、顳浅动脉、上頜动脉 | 甲狀腺、舌頭、面部、頭皮、顱外結構 |
| **椎动脉（Vertebral A.）** | 鎖骨下动脉 | 基底动脉、大腦後动脉 | 腦幹、小腦、大腦後1/3 |

:::臨床應用
**頸總动脉搏動點**
- 位置：**胸鎖乳突肌（SCM）**前方，氣管外側
- 臨床意義：高血壓患者血壓測量部位；頸總动脉粥樣硬化好發處
- 觸摸時應輕柔，避免同時按壓兩側（可能引起腦血流減少）
:::

### 頭頸部靜脈

| 靜脈 | 收集區域 | 匯入 |
|------|---------|------|
| **頸內靜脈（Internal Jugular V.）** | 顱內靜脈竇、面部深層結構 | 鎖骨下靜脈（右側直接、左側經胸導管） |
| 頸外靜脈（External Jugular V.） | 顏面部淺層、甲狀腺 | 鎖骨下靜脈 |
| 面前靜脈（Anterior Facial V.） | 面部前面 | 頸內靜脈 |
| 顳淺靜脈（Superficial Temporal V.） | 顱頂、顳部 | 下頜後靜脈 |

## 主動脈弓及其分支

### 主動脈弓（Aortic Arch）三大分支

| 分支 | 起源順序 | 主要供應區域 |
|------|---------|-------------|
| **無名动脉（Brachiocephalic Trunk）** | 第1分支 | 右側頭頸部、右上肢（分為右頸總+右鎖骨下） |
| **左頸總动脉（Left Common Carotid A.）** | 第2分支 | 左側頭頸部 |
| **左鎖骨下动脉（Left Subclavian A.）** | 第3分支 | 左上肢、椎动脉→腦 |

:::臨床應用
**主動脈弓相關疾病**
- **主動脈夾層（Aortic Dissection）**：高血壓控制不良導致主動脈內膜撕裂
  - Stanford A型：累及升主動脈（需緊急手術）
  - Stanford B型：僅累及降主動脈（藥物治療為主）
- **大動脈炎症候群（Takayasu Arteritis）**：年輕女性好發，主動脈及其分支慢性炎症
:::

### 胸主動脈（Thoracic Aorta）分支

| 分支 | 供應區域 |
|------|---------|
| 支氣管动脉（Bronchial A.） | 支氣管、肺臟營養血管 |
| 食道动脉（Esophageal A.） | 食道 |
| 肋間动脉（Intercostal A.） | 胸壁、腹壁 |
| 橫膈动脉（Phrenic A.） | 橫膈 |

---

## 腹主動脈及其主要分支

### 腹主動脈（Abdominal Aorta）三個不成對主要分支

| 分支 | 起源位置 | 主要分支 | 供應器官 |
|------|---------|---------|---------|
| **腹腔干（Celiac Trunk）** | T12水平 | 胃左动脉、肝总动脉、脾动脉 | 胃、肝、膽囊、胰、脾 |
| **腸繫膜上动脉（SMA）** | L1水平（腹腔干下方） | 胰十二指腸下动脉、空腸动脉、回腸动脉、右結腸动脉、中結腸动脉 | 胰頭、十二指腸、空腸、回腸、升結腸、横結腸 |
| **腸繫膜下动脉（IMA）** | L3水平 | 左結腸动脉、乙狀結腸动脉、直腸上动脉 | 降結腸、乙狀結腸、直腸 |

:::臨床應用
**腸繫膜缺血（Mesenteric Ischemia）**
- 病因：SMA或IMA粥樣硬化、血栓、低心輸出量
- 典型表現：飯後腹痛（恐食症）、體重減輕、便血
- 急性腸繫膜缺血：**劇烈腹痛但體徵輕微**（「疼痛與體徵不符」）
- 診斷：CT血管造影（CTA）、腸繫膜血管Doppler
:::

### 腹主動脈成對分支

| 分支 | 起源 | 供應區域 |
|------|------|---------|
| 腎动脉（Renal A.） | L1-L2水平 | 腎臟、腎上腺 |
| 性腺动脉（Gonadal A.） | L2水平 | 睪丸（男）或卵巢（女） |
| 腰动脉（Lumbar A.） | 腹主動脈後壁（4對） | 腹壁、後腹壁、脊髓 |

## 盆部及下肢血管

### 髂總动脉（Common Iliac A.）分支

| 动脉 | 供應區域 |
|------|---------|
| 髂內动脉（Internal Iliac A.） | 盆腔臟器（膀胱、子宮、直腸）、臀肌、會陰 |
| 髂外动脉（External Iliac A.） | 下肢（股动脉延續） |

### 下肢动脉

| 动脉 | 走行 | 主要分支 | 供應區域 |
|------|------|---------|---------|
| **股动脉（Femoral A.）** | 腹股溝韌帶中點→大腿內側→內收肌裂孔 | 旋股外側动脉、旋股內側动脉、股深动脉、膝降动脉 | 大腿、膝關節 |
| **膕动脉（Popliteal A.）** | 膕窩深部 | 膝上/下內側/外側动脉、腓腸动脉 | 膝關節、小腿 |
| **脛前动脉（Anterior Tibial A.）** | 骨間膜上方→小腿前側 | 足背动脉（延伸） | 小腿前側、足背 |
| **脛後动脉（Posterior Tibial A.）** | 小腿後側深層 | 腓动脉（重要側支）、內踝後动脉 | 小腿後側、足底 |
| **腓动脉（Peroneal A.）** | 脛後动脉分支 | 外踝动脉、跟动脉 | 小腿外側、足外側 |

:::臨床應用
**下肢慢性周邊动脉疾病（PAD）**
- 病因：下肢动脉粥樣硬化（最常見）、血栓、栓塞
- 分期（Fontaine classification）：
  - I期：無症狀
  - II期：間歇性跛行（Intermittent Claudication）
  - III期：休息痛（Rest Pain）
  - IV期：組織壞死、潰瘍
- 檢查：**足背动脉（DP A.）搏動**減弱或消失；ABI（踝肱指數）<0.9
- 治療：藥物（抗血小板、血管擴張）、血管重建手術、PTA支架
:::

## 靜脈回流系統

### 上腔靜脈系統

| 靜脈 | 收集區域 | 匯入 |
|------|---------|------|
| 頸內靜脈（IJV） | 顱內、顏面深層 | 鎖骨下靜脈 |
| 鎖骨下靜脈（Subclavian V.） | 上肢 | 頭臂靜脈 |
| 頭臂靜脈（Brachiocephalic V.） | 頸部、上肢 | 上腔靜脈 |
| **上腔靜脈（SVC）** | 頭頸部、上肢、胸壁 | 右心房 |

### 下腔靜脈系統

| 靜脈 | 收集區域 | 匯入 |
|------|---------|------|
| **股靜脈（Femoral V.）** | 下肢淺層、深層 | 髂外靜脈 |
| **髂外靜脈（External Iliac V.）** | 下肢 | 髂總靜脈 |
| **髂總靜脈（Common Iliac V.）** | 盆腔、下肢 | **下腔靜脈** |
| **下腔靜脈（IVC）** | 腹部、盆腔、下肢 | 右心房 |

### 門靜脈系統

| 組成 | 收集區域 | 功能 |
|------|---------|------|
| **脾靜脈（Splenic V.）** | 脾臟、胰體、尾 | 匯入門靜脈 |
| **腸繫膜上靜脈（SMV）** | 空腸、回腸、盲腸、升結腸、横結腸 | 匯入門靜脈 |
| **門靜脈（Portal V.）** | 脾靜脈+SMV會合 | 送血至肝臟解毒 |
| **胃左靜脈（LGV）** | 胃底、食道下端 | 門靜脈→胃左靜脈→食道靜脈叢→奇靜脈（門腔分流路徑） |

:::臨床應用
**門靜脈高壓（Portal Hypertension）**
- 病因：肝硬化（最常見）、門靜脈血栓、Budd-Chiari症候群
- 表現：**食道靜脈曲張（Esophageal Varices）**、腹水、脾腫大、**臍周靜脈曲張（Caput Medusae）**
- 併發症：靜脈曲張出血（可能致命）、肝性腦病
- 治療：內視鏡結紮、藥物（β受體阻斷劑）、TIPS（經頸靜脈肝內門腔分流）
:::

## 主要側支循環路徑

### 頸部側支

| 路徑 | 說明 |
|------|------|
| 頸外→頸內 | 甲狀腺上动脉↔甲狀腺下动脉（經頸總动脉） |
| 椎动脉↔頸內动脉 | 後交通动脉連接 |

### 主動脈側支

| 路徑 | 說明 |
|------|------|
| 鎖骨下↔髂外 | 乳內动脉→腹壁上动脉→腹壁下动脉→股动脉 |
| 肋間动脉↔股动脉 | 胸壁外側动脉↔旋髂深动脉 |

### 盆腔側支

| 路徑 | 說明 |
|------|------|
| 髂內↔髂外 | 子宮动脉↔卵巢动脉；臀上/下动脉↔股动脉 |
| 直腸周圍 | 腸繫膜下动脉（痔上）↔髂內动脉（痔中、痔下） |

### 下肢側支

| 路徑 | 說明 |
|------|------|
| 股深动脉側支 | 旋股內/外側动脉↔膕动脉 |
| 膝關節周圍 | 膝降动脉↔腘动脉（膝關節網） |

:::臨床應用
**主動脈縮窄（Coarctation of Aorta）側支**
- 狹窄位於左鎖骨下动脉與PDA之間
- 側支：乳內动脉→腹壁上动脉→腹壁下动脉→股动脉
- 臨床上可見**肋間动脉擴張**（第3-8對），胸片見「rib notching」
:::

## 器官血液供應概覽

| 器官 | 动脉供應 | 靜脈回流 |
|------|---------|---------|
| 甲狀腺 | 甲狀腺上/下动脉 | 甲狀腺上/中/下靜脈→頸內靜脈 |
| 腎臟 | **腎动脉**（L1-L2） | **腎静脉**→下腔靜脈 |
| 肝臟 | 肝动脉（25%）+**門靜脈**（75%） | **肝静脉**→下腔靜脈 |
| 脾臟 | 脾动脉（腹腔干分支） | 脾静脉→門靜脈 |
| 胰臟 | 胰十二指腸上/下动脉 | 胰靜脈→脾靜脈或SMV |
| 胃 | 胃左动脉（腹腔干）、胃右动脉（肝总）、胃網膜左/右动脉 | 胃右/左靜脈→門靜脈 |
| 小腸 | SMA分支（空腸、回腸动脉） | 腸繫膜上靜脈→門靜脈 |
| 大腸 | SMA（右側）；IMA（左側） | 腸繫膜上/下靜脈→門靜脈 |
| 子宮 | 子宮动脉（髂內动脉分支） | 子宮静脉→髂內靜脈 |
| 睪丸/卵巢 | 性腺动脉（腹主动脉分支） | 性腺静脉（右→IVC，左→左腎静脉） |

## 臨床血管檢查要點

1. **觸診**：頸總动脉、顳浅动脉、橈动脉、股动脉、膕动脉、足背动脉、脛後动脉
2. **聽診**：頸部（頸總动脉）、腹部（主動脈、腎动脉、腸繫膜动脉）、股动脉（血管雜音）
3. **血壓測量**：四肢血壓差異（主動脈縮窄、鎖骨下动脉竊取症候群）
4. **ABI（踝肱指數）**：診斷周邊动脉疾病
5. **都卜勒超聲**：無創血流評估
6. **CT/MR血管造影**：精確定位狹窄或栓塞
