## 附錄內容說明

Gray's Anatomy for Students 的附錄包含以下重要參考資料：

- **表面解剖總複習（Surface Anatomy）**：全身各區域表面標誌的整合性複習
- **影像學（Imaging）**：X光、CT、MRI、超聲、核醫在全身各部位的應用
- **軀幹（Trunk）**：脊椎、胸廓、腹部的扼要複習表格
- **四肢（Limbs）**：上肢和下肢神經、血管、肌肉的快速參照表

---

## 快速參照

### 全身主要神經支配速查

| 區域 | 神經 | 來源 |
|------|------|------|
| 上肢外側 | 正中神經 | 臂叢（內側+外側束） |
| 上肢內側 | 尺神經 | 臂叢（內側束） |
| 上肢後側 | 橈神經 | 臂叢（後束） |
| 下肢前側 | 股神經 | 腰叢（L2-L4） |
| 下肢內側 | 閉孔神經 | 腰叢（L2-L4） |
| 下肢後側 | 坐骨神經 | 骶叢（L4-S3） |

### 顱神經快速記憶

```
Ⅰ 嗅 — 感（嗅覺）
Ⅱ 視 — 感（視覺）
Ⅲ 動眼神經 — 動（眼球運動 + 瞳孔）
Ⅳ 滑車神經 — 動（眼球運動）
Ⅴ 三叉神經 — 感+動（面部感覺 + 咀嚼）
Ⅵ 外展神經 — 動（眼球運動）
Ⅶ 顏面神經 — 動+感（表情 + 味覺）
Ⅷ 前庭耳蝸 — 感（聽覺 + 平衡）
Ⅸ 舌咽神經 — 感+動（咽部 + 味覺）
Ⅹ 迷走神經 — 動（副交感）
Ⅺ 副神經 — 動（斜方肌 + 胸鎖乳突肌）
Ⅻ 舌下神經 — 動（舌頭運動）
```
