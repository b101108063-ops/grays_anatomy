::: {.callout-tip appearance="note"}
## 本章重點

- 甲狀腺位於 **C1-C4 氣管前方**，由左右葉 + 峽部組成
- 甲狀腺血液供應豐富：**甲狀腺上动脉**（頸外动脉）、**甲狀腺下动脉**（甲狀頸干）
- **喉返神經**與甲狀腺下动脉關係密切，甲狀腺手術時需小心
- 甲狀旁腺 4 顆，分泌 **甲狀旁腺素（PTH）** 調節血鈣
:::

## 甲狀腺（Thyroid Gland）

### 甲狀腺位置與形態

| 項目 | 說明 |
|------|------|
| **位置** | 氣管前方，C1-C4 水準 |
| **組成** | 左右葉（Lateral lobes）+ 峽部（Isthmus） |
| **外形** | H 形或 U 形 |
| **大小** | 長約 4-6 cm，寬約 3-4 cm |
| **重量** | 15-30 g |

### 甲狀腺變異結構

| 結構 | 出現率 | 說明 |
|------|--------|------|
| **錐狀叶**（Pyramidal lobe） | 約 10% | 從峽部向上延伸至舌骨；是甲狀腺胚胎髮育的遺蹟 |

### 甲狀腺被膜

| 被膜 | 說明 |
|------|------|
| **甲狀腺真被膜**（True capsule） | 覆蓋甲狀腺表面的纖維囊 |
| **甲狀腺鞘/假被膜**（False capsule, Pretracheal fascia） | 氣管前筋膜延伸，包圍甲狀腺 |

::: {.callout-note appearance="default"}
### 臨床應用：甲狀腺與喉返神經的解剖關係

**喉返神經**（Recurrent Laryngeal Nerve）是甲狀腺手術中最重要的結構之一：

| 側別 | 行走路徑 | 與甲狀腺的關係 |
|------|----------|----------------|
| **左側** | 繞過主动脉弓 | 在甲狀腺下动脉後方上行 |
| **右側** | 繞過鎖骨下动脉 | 在甲狀腺下动脉後方上行 |

**手術要點**：甲狀腺下动脉是尋找喉返神經的重要標誌。神經通常在动脉後方、氣管食管溝內上行。

**損傷後果**：
- 單側損傷：聲音嘶啞（Vocal cord paralysis）
- 雙側損傷：呼吸困難、失聲（Emergency）
:::

## 甲狀腺血液供應

甲狀腺血液供應非常豐富，是人體血液供應最豐富的器官之一：

| 动脉 | 來源 | 分布 | 臨床意義 |
|------|------|------|----------|
| **甲狀腺上动脉**（Superior thyroid artery） | 頸外动脉（面动脉起始部） | 甲狀腺上極 | 喉上神經與之並行 |
| **甲狀腺下动脉**（Inferior thyroid artery） | 甲狀頸干（甲狀腺最下动脉，有時存在） | 甲狀腺下極 | 喉返神經與之交叉 |
| **甲狀腺最下动脉**（Thyroid ima artery） | 主动脉弓或頭臂动脉 | 甲狀腺峽部 | 出現率低（約 10%） |

### 甲狀腺靜脈回流

| 靜脈 | 去向 |
|------|------|
| **甲狀腺上靜脉** | 頸內靜脉 |
| **甲狀腺中靜脉** | 頸內靜脉 |
| **甲狀腺下靜脉** | 頭臂靜脉 |

## 甲狀腺淋巴引流

甲狀腺淋巴引流有一定的規律性：

```
甲狀腺實質內淋巴
    ↓
甲狀腺周圍淋巴結（Perithyroidal nodes）
    ↓
氣管前淋巴結（Pretracheal nodes）
    ↓
氣管旁淋巴結（Paratracheal nodes）
    ↓
頸深淋巴結（Deep cervical nodes）
    ↓
右淋巴導管（Right lymphatic duct）
左淋巴導管（Thoracic duct）
```

| 淋巴結群 | 引流區域 |
|----------|----------|
| **甲狀腺前面淋巴結** | 甲狀腺前表面 |
| **氣管前淋巴結** | 甲狀腺峽部、氣管前 |
| **氣管旁淋巴結** | 甲狀腺背側、氣管食管溝 |
| **頸深淋巴結** | 甲狀腺全部，最終引流 |

## 甲狀腺功能與激素

| 項目 | 說明 |
|------|------|
| **分泌激素** | 甲狀腺素（T4）、三碘甲狀腺素（T3） |
| **功能** | 調節新陳代謝、生長發育 |
| **控制** | 受 **TSH**（甲狀腺刺激素）調節，TSH 受 **TRH**（下視丘）控制 |

## 甲狀旁腺（Parathyroid Glands）

### 甲狀旁腺位置

| 項目 | 說明 |
|------|------|
| **數量** | 通常 4 顆（2 上 + 2 下） |
| **位置** | 甲狀腺後方，甲狀腺被膜內 |

### 上、下甲狀旁腺的區別

| 項目 | 上甲狀旁腺 | 下甲狀旁腺 |
|------|------------|------------|
| **位置** | 甲狀腺下动脉上方 | 甲狀腺下动脉下方 |
| **發生来源** | 第四鰓囊 | 第三鰓囊（與胸腺一起下降） |
| **與胸腺關係** | 無 | 下甲狀旁腺可能位於胸腺內或附近 |

::: {.callout-note appearance="default"}
### 臨床應用：甲狀旁腺功能

**甲狀旁腺素**（PTH, Parathyroid hormone）是維持血鈣平衡的關鍵激素：

| 功能 | 作用 |
|------|------|
| **升血鈣** | 促進骨質吸收、腎小管鈣重吸收、活化維生素 D |
| **降血磷** | 抑制腎小管磷重吸收 |

**甲狀旁腺功能減退**：
- 原因：甲狀腺手術時意外切除或損傷甲狀旁腺
- 表現：低血鈣→手足抽搐、痙攣、白內障
- 治療：補鈣、維生素 D、甲狀旁腺素替代

**甲狀旁腺功能亢進**：
- 原因：甲狀旁腺瘤（最常見）、增生
- 表現：高血鈣→骨痛、腎結石、消化性潰瘍
- 治療：手術切除
:::

## 甲狀腺與甲狀旁腺的超聲解剖

超聲是評估甲狀腺與甲狀旁腺疾病的首選影像學檢查：

| 結構 | 超聲表現 |
|------|----------|
| **正常甲狀腺** | 均勻中等回聲 |
| **甲狀腺結節** | 低回聲（癌性風險較高）、高回聲（良性可能性大） |
| **甲狀旁腺** | 低回聲小結節，正常難以顯示 |
| **增大甲狀旁腺** | 可識別的的低回聲團塊 |

## 甲狀腺手術的解剖要點

| 手術步驟 | 解剖要點 |
|----------|----------|
| **切口** | 頸前橫切口，位於胸骨切跡上方約 2-3 cm |
| **皮瓣** | 切開頸闊肌，向上游離皮瓣 |
| **分開正中線** | 切開頸前肌群，顯露甲狀腺 |
| **顯露甲狀腺** | 游離甲狀腺表面，辨認甲狀腺下动脉 |
| **尋找喉返神經** | 甲狀腺下动脉與氣管食管溝之間 |
| **保護喉上神經** | 甲狀腺上动脉分支附近 |
| **確認甲狀旁腺** | 甲狀腺後方，術中確認血供 |
