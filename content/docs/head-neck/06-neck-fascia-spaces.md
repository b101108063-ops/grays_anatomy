::: {.callout-tip appearance="note"}
## 本章重點

- 頸部筋膜分為 **淺層** 與 **深層** 頸部筋膜
- 深層頸部筋膜又分為 **臟層** 與 **壁層**
- 頸部分為 **舌骨上區** 與 **舌骨下區**
- 重要間隙：椎前間隙、氣管前間隙、嚼肌旁間隙、翼間隙
- 胸鎖乳突肌分為 **頸前三角** 與 **頸後三角**
:::

## 頸部筋膜層（Cervical Fascia）

### 淺層頸部筋膜（Superficial Cervical Fascia）

| 項目 | 說明 |
|------|------|
| **位置** | 皮下脂肪層中 |
| **內容物** | 含 **頸闊肌**（Platysma） |
| **特點** | 頸闊肌是頸部最大、最表淺的肌肉 |

### 深層頸部筋膜（Deep Cervical Fascia）

深層頸部筋膜又稱為「頸部筋膜」，包繞頸部深部結構：

| 層次 | 包繞結構 |
|------|----------|
| **臟層**（Visceral layer） | 甲狀腺、唾液腺、咽、喉、氣管、食道 |
| **壁層**（Parietal layer） | 包繞頸部肌肉與其他深部結構 |

#### 壁層的分区

| 分區 | 範圍 |
|------|------|
| **舌骨上部分**（Suprahyoid portion） | 覆蓋二腹肌、顎骨舌骨肌 |
| **舌骨下部分**（Infrahyoid portion） | 覆蓋胸鎖乳突肌、舌骨下肌群 |

### 頸部筋膜形成的鞘

| 鞘名 | 構成 | 內容物 |
|------|------|--------|
| **甲狀腺鞘**（Thyroid sheath） | 臟層筋膜延伸 | 甲狀腺 |
| **頸動脈鞘**（Carotid sheath） | 壁層筋膜局部增厚 | 頸總/內动脉、頸內靜脈、迷走神經 |
| **氣管前筋膜**（Pretracheal fascia） | 臟層筋膜 | 甲狀腺峽部、氣管前肌肉 |

## 頸部分区（Regions of Neck）

### 舌骨上區（Suprahyoid Region）

| 組成 | 說明 |
|------|------|
| 面部下份 | 顏面部下方結構 |
| 口腔底部 | 含舌頭外在肌、下頜下腺、舌下腺 |
| 嚼肌旁間隙 | 嚼肌與翼內肌之間 |

### 舌骨下區（Infrahyoid Region）

| 組成 | 說明 |
|------|------|
| 甲狀腺區 | 甲狀腺、甲狀旁腺 |
| 氣管區 | 氣管、喉 |
| 食道區 | 食道頸段 |
| 頸總动脉區 | 總颈动脉、頸內靜脈、迷走神經 |

## 頸部重要間隙（Cervical Spaces）

::: {.callout-note appearance="default"}
### 臨床應用：頸部間隙感染的臨床意義

頸部筋膜間隙是感染蔓延的重要通道：
- **椎前間隙感染**：可蔓延至縱隔（Mediastinum）
- **氣管前間隙感染**：可向上、下蔓延
- **嚼肌旁間隙感染**：可導致牙關緊閉（Trismus）

感染源常為**牙源性**或**咽源性**，應及早引流。
:::

### 椎前間隙（Prevertebral Space）

| 項目 | 說明 |
|------|------|
| **位置** | 椎體前方，椎前筋膜之後 |
| **境界** | 前：椎前筋膜；後：椎體 |
| **內容** | 頭長肌、頸長肌、椎體前緣 |
| **交通** | 可向下延伸至後縱隔 |

### 氣管前間隙（Pretracheal Space）

| 項目 | 說明 |
|------|------|
| **位置** | 甲狀腺前方，氣管前筋膜與氣管之間 |
| **內容** | 甲狀腺峽部、靜脈、無名动脉 |
| **交通** | 向上：舌骨下區；向下：前縱隔 |

### 嚼肌旁間隙（Parapharyngeal Space）

| 項目 | 說明 |
|------|------|
| **位置** | 咽的兩側 |
| **境界** | 內：咽縮肌；外：下頜骨、嚼肌、腮腺 |
| **內容** | 脂肪組織、淋巴結 |
| **交通** | 向上：顱底；向下：顎扁桃體周圍 |

### 翼間隙（Pterygomandibular Space）

| 項目 | 說明 |
|------|------|
| **位置** | 翼內肌與嚼肌之間 |
| **內容** | 下頜神經（V3）、耳神經節、翼靜脈叢 |
| **臨床意義** | 牙源性感染常累及此間隙 |

## 頸部三角（Triangles of Neck）

頸部三角以 **胸鎖乳突肌** 為界分為兩大區域：

### 頸前三角（Anterior Triangle）

| 三角 | 邊界 | 內容 |
|------|------|------|
| **頦下三角**（Submental triangle） | 雙側下頜骨下緣、舌骨 | 頦下淋巴結、脂肪 |
| **下頜下三角**（Submandibular triangle） | 下頜骨下緣、二腹肌前腹 | 下頜下腺、舌下腺、舌神經、舌動静脉、下頜下淋巴結 |
| **頸動脈三角**（Carotid triangle） | 胸鎖乳突肌前緣、二腹肌後腹、肩胛舌骨肌 | 頸總动脉、頸內靜脉、頸外动脉分支、迷走神經、交感幹 |
| **肌三角**（Muscular triangle） | 胸鎖乳突肌前緣、肩胛舌骨肌、舌骨 | 舌骨下肌群、甲狀腺 |

### 頸後三角（Posterior Triangle）

| 三角 | 邊界 | 內容 |
|------|------|------|
| **枕三角**（Occipital triangle） | 胸鎖乳突肌後緣、斜方肌前緣、肩胛舌骨肌下腹 | 副神經（XI）、淋巴結 |
| **肩胛舌骨肌鎖骨三角**（Omoclavicular/ subclavian triangle） | 胸鎖乳突肌後緣、肩胛舌骨肌下腹、鎖骨 | 鎖骨下动脉、靜脉、臂叢 |
| **椎三角**（Transverse cervical triangle） | 枕三角 + 肩胛舌骨肌鎖骨三角的總稱 | — |

### 頸部三角重要結構總表

| 結構 | 所在三角 |
|------|----------|
| **下頜下腺** | 下頜下三角 |
| **舌下腺** | 下頜下三角 |
| **甲狀腺** | 肌三角 |
| **頸總动脉** | 頸動脈三角 |
| **頸內靜脉** | 頸動脈三角 |
| **迷走神經** | 頸動脈三角 |
| **副神經（XI）** | 枕三角 |
| **臂叢** | 肩胛舌骨肌鎖骨三角 |

## 頸部肌肉概覽

### 舌骨上肌群（Suprahyoid Muscles）

| 肌肉 | 起點 | 止點 | 功能 | 神經 |
|------|------|------|------|------|
| **二腹肌**（Digastric） | 乳突切跡、頦下窩 | 舌骨 | 提舌骨、降下頜 | V3 + VII |
| **下頜舌骨肌**（Mylohyoid） | 下頜骨內面 | 舌骨 | 提舌骨、提口腔底 | V3 |
| **顎骨舌骨肌**（Geniohyoid） | 頦棘 | 舌骨 | 提舌骨 | C1（經舌下神經） |
| **莖突舌骨肌**（Stylohyoid） | 莖突 | 舌骨 | 提舌骨 | VII |

### 舌骨下肌群（Infrahyoid Muscles）

| 肌肉 | 起點 | 止點 | 功能 | 神經 |
|------|------|------|------|------|
| **胸骨舌骨肌**（Sternohyoid） | 胸骨柄 | 舌骨 | 降舌骨 | C1-C3 |
| **肩胛舌骨肌**（Omohyoid） | 肩胛上緣 | 舌骨 | 降舌骨 | C1-C3 |
| **胸骨甲狀肌**（Sternothyroid） | 胸骨柄 | 甲狀軟骨 | 降喉 | C1-C3 |
| **甲狀舌骨肌**（Thyrohyoid） | 甲狀軟骨 | 舌骨 | 降舌骨、提喉 | C1 |

### 胸鎖乳突肌（Sternocleidomastoid, SCM）

| 項目 | 說明 |
|------|------|
| **起點** | 胸骨柄前面、鎖骨內側 |
| **止點** | 乳突 |
| **功能** | 單側：同側屈、對側旋；雙側：屈頸（脫力）或仰頭 |
| **神經** | 副神經（XI） |
| **臨床意義** | 是頸部手術的重要標誌；分為頸前/後三角 |
