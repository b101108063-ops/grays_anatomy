## 本章重點

- 眼眶四壁：上壁（薄，鄰顱前窩）、下壁（薄，鄰上頜竇）、內壁（篩骨迷路）、外壁（顴骨+蝶骨大翼）
- 眼外肌 6 塊：由 **III、IV、VI** 神經支配
- **眶上裂**通過 III、IV、V1、VI 神經；**眶下裂**通過 V2
- 淚器包括淚腺、淚小管、淚囊、**鼻淚管（nasolacrimal duct）**
:::

## 眼眶骨壁（Orbital Walls）

眼眶是一個錐體形腔室，四壁結構如下：

| 骨壁 | 組成骨頭 | 臨床特點 |
|------|----------|----------|
| **上壁**（Roof） | 蝶骨小翼、額骨眶板 | 薄，與顱前窩相鄰；顱前窩骨折可累及眼眶 |
| **下壁**（Floor） | 上頜骨眶面、顴骨眶面 | 薄，與**上頜竇**相鄰；上頜竇腫瘤可侵犯眼眶 |
| **內壁**（Medial wall） | 篩骨迷路、上頜骨額突、淚骨 | 薄，由篩骨紙板（Lamina papyracea）構成；易因外傷而骨折 |
| **外壁**（Lateral wall） | 顴骨、蝶骨大翼 | 最厚，保護性結構 |

### 眼眶重要裂隙與孔道

| 結構 | 位置 | 通過內容物 |
|------|------|------------|
| **眶上裂**（Superior orbital fissure） | 蝶骨大翼与小翼之間 | **動眼神經（III）**、**滑車神經（IV）**、**眼神經（V1）**、**外展神經（VI）**、眼上靜脈 |
| **眶下裂**（Inferior orbital fissure） | 蝶骨大翼與上頜骨之間 | **上頜神經（V2）**、眶下動静脉、翼靜脈叢交通 |
| **視神經孔**（Optic canal） | 蝶骨體 | **視神經（II）**、眼动脉 |

## 眼眶內容物（Orbital Contents）

| 內容物 | 說明 |
|--------|------|
| **眼球**（Eyeball） | 視覺器官，由三層膜包圍 |
| **眼外肌**（Extraocular muscles） | 6 塊，支配眼球運動 |
| **淚器**（Lacrimal apparatus） | 淚液分泌與引流系統 |
| **眶脂體**（Intraorbital fat） | 填充眼眶空隙，緩衝保護 |

## 眼外肌（Extraocular Muscles）

眼球共有 6 塊眼外肌，分為 2 組：

### 直肌（Rectus muscles）

| 肌肉 | 神經支配 | 主要作用 | 輔助作用 |
|------|----------|----------|----------|
| **上直肌**（Superior rectus） | III 動眼神經 | 內收、內旋 | 上提 |
| **下直肌**（Inferior rectus） | III 動眼神經 | 內收、外旋 | 下壓 |
| **內直肌**（Medial rectus） | III 動眼神經 | **內收** | — |
| **外直肌**（Lateral rectus） | VI 外展神經 | **外展** | — |

### 斜肌（Oblique muscles）

| 肌肉 | 神經支配 | 主要作用 | 輔助作用 |
|------|----------|----------|----------|
| **上斜肌**（Superior oblique） | IV 滑車神經 | **外旋** | 內收 |
| **下斜肌**（Inferior oblique） | III 動眼神經 | **外旋** | 外展 |

### 其他眼外肌

| 肌肉 | 神經支配 | 功能 |
|------|----------|------|
| **上瞼提肌**（Levator palpebrae superioris） | III 動眼神經 | 提上眼瞼 |

### 眼球運動方向總結

| 肌肉 | 內收 | 外展 | 上提 | 下壓 | 內旋 | 外旋 |
|------|------|------|------|------|------|------|
| 內直肌 | ✓ | | | | | |
| 外直肌 | | ✓ | | | | |
| 上直肌 | ✓ | | ✓ | | ✓ | |
| 下直肌 | ✓ | | | ✓ | | ✓ |
| 上斜肌 | ✓ | | | | | ✓ |
| 下斜肌 | | ✓ | | | ✓ | |

### 眼外肌的神經支配順序（臨床記憶）

> **「Holland 346」** 或 **「LR6SO4Rest3」**
>
> - **L**ateral rectus → **6**th nerve（VI 外展神經）
> - **S**uperior **O**blique → **4**th nerve（IV 滑車神經）
> - 其餘 → **3**rd nerve（III 動眼神經）

## 眶脂體（Intraorbital Fat）

眶脂體填充在眼球、眼肌與眼眶骨壁之間的空隙，具有以下功能：
- **緩衝保護**：減少眼球運動時的摩擦
- **支撐結構**：維持眼眶內容物的位置
- **血管神經通道**：提供血管與神經的走行空間

## 淚器（Lacrimal Apparatus）

淚器包括淚液的分泌與引流結構：

### 淚液分泌系統

| 結構 | 位置 | 功能 |
|------|------|------|
| **淚腺**（Lacrimal gland） | 眼眶外上方，額骨顴突後方 | 分泌淚液 |

### 淚液引流系統

```
淚腺分泌淚液
    ↓ 沖洗眼球表面
淚點（Lacrimal puncta, 上/下眼瞼內側）
    ↓
淚小管（Lacrimal canaliculi）
    ↓
淚囊（Lacrimal sac）
    ↓
鼻淚管（Nasolacrimal duct）
    ↓
鼻腔下鼻道（Inferior nasal meatus）
```

| 結構 | 說明 |
|------|------|
| **淚小管** | 長約 10mm，連接淚點與淚囊 |
| **淚囊** | 位於淚囊窩內，長約 12mm |
| **鼻淚管** | 連接淚囊與鼻腔，長約 18mm |

::: {.callout-note appearance="default"}
### 臨床應用：溢淚症（Epiphora）

淚液引流系統阻塞可導致溢淚，常見原因包括：
- 先天性鼻淚管阻塞（新生兒常見）
- 老化導致淚點或淚小管狹窄
- 鼻腔疾病（鼻炎、鼻竇炎）
- 外傷或手術後粘連

治療方式包括淚道沖洗、探通術或手術重建。
:::

## 眶內神經血管

### 眶內神經

| 神經 | 功能 | 進眶位置 |
|------|------|----------|
| **視神經（II）** | 視覺 | 視神經孔 |
| **動眼神經（III）** | 運動眼外肌（除外直肌、上斜肌） | 眶上裂 |
| **滑車神經（IV）** | 支配上斜肌 | 眶上裂 |
| **外展神經（VI）** | 支配外直肌 | 眶上裂 |
| **三叉神經（V1）** | 眼部感覺 | 眶上裂 |

### 眶內血管

| 血管 | 類型 | 來源/去向 |
|------|------|----------|
| **眼动脉**（Ophthalmic artery） | 动脉 | 頸內动脉分支，供應眶內結構 |
| **眼上靜脈**（Superior ophthalmic vein） | 靜脈 | 引流眶內上半部→海綿竇 |
| **眼下靜脈**（Inferior ophthalmic vein） | 靜脈 | 引流眶內下半部→翼靜脈叢/海綿竇 |
