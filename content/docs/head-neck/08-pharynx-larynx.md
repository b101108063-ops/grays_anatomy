::: {.callout-tip appearance="note"}
## 本章重點

- 咽分為 **鼻咽**、**口咽**、**喉咽** 三部分
- 咽扁桃體（Adenoid）位於 **鼻咽**，齶扁桃體位於 **口咽**
- 喉軟骨：**甲狀軟骨**、**環狀軟骨**、**會厭軟骨**、**杓狀軟骨**
- 環甲韌帶是緊急穿刺位置（**Cricothyrotomy**）
- 喉腔分為 **喉前庭**、**聲門**、**聲門下區**
:::

## 咽（Pharynx）概覽

咽是連接鼻腔、口腔與食道、喉的共同通道：

| 項目 | 說明 |
|------|------|
| **位置** | 頸椎前方，C1-C6 水準 |
| **長度** | 約 12-14 cm |
| **功能** | 消化道與呼吸道的共同通道 |
| **分區** | 鼻咽、口咽、喉咽 |

## 咽的分區

### 鼻咽（Nasopharynx）

| 項目 | 說明 |
|------|------|
| **位置** | 鼻腔後方，軟腭以上 |
| **境界** | 上：蝶骨體、枕骨基部；下：軟腭 |
| **前界** | 鼻後孔（Choanae），通鼻腔 |
| **後界** | 咽縮肌上段 |
| **側壁** | 咽鼓管連接口（Auditory tube opening） |

#### 鼻咽重要結構

| 結構 | 位置 | 臨床意義 |
|------|------|----------|
| **咽扁桃體**（Pharyngeal tonsil, Adenoid） | 鼻咽後壁上份 | 兒童常見肥大；成人萎縮 |
| **咽鼓管扁桃體**（Tubal tonsil） | 咽鼓管連接口周圍 | 咽鼓管阻塞→中耳炎 |
| **咽鼓管連接口**（Auditory tube opening） | 鼻咽側壁 | 通中耳，平衡鼓膜兩側壓力 |
| **Rosenmüller 窩**（Pharyngeal recess） | 咽鼓管連接口後方 | 鼻咽癌好發部位 |

### 口咽（Oropharynx）

| 項目 | 說明 |
|------|------|
| **位置** | 軟腭至會厭軟骨上緣 |
| **境界** | 上：軟腭；下：會厭上緣 |
| **前界** | 口腔後部，齶舌弓 |
| **後界** | 咽縮肌中段 |

#### 口咽重要結構

| 結構 | 位置 | 臨床意義 |
|------|------|----------|
| **齶扁桃體**（Palatine tonsils） | 齶舌弓與齶咽弓之間 | 扁桃腺炎、扁桃腺切除術 |
| **舌扁桃體**（Lingual tonsil） | 舌根背面 | 舌根膿腫 |
| **輪廓乳頭**（Vallate papillae） | 舌背，舌根前方 | 味覺（IX神經） |
| **會厭谿**（Vallecula） | 會厭與舌根之間 | 插入支撐喉鏡時的標誌 |

### 喉咽（Laryngopharynx）

| 項目 | 說明 |
|------|------|
| **位置** | 會厭軟骨上緣至環狀軟骨下緣 |
| **境界** | 上：會厭上緣；下：環狀軟骨下緣 |
| **前界** | 喉頭後面 |
| **後界** | 咽縮肌下段 |
| **交通** | 向下連接食道 |

## 咽壁肌肉

### 咽縮肌（Pharyngeal Constrictors）

| 肌肉 | 起点 | 止點 | 功能 |
|------|------|------|------|
| **上咽縮肌**（Superior constrictor） | 翼突下頜縫、頦舌骨線、舌根 | 咽縫（Pharyngeal raphe） | 收縮咽腔，推送食物向下 |
| **中咽縮肌**（Middle constrictor） | 舌骨大角、小角 | 咽縫 | 收縮咽腔 |
| **下咽縮肌**（Inferior constrictor） | 甲狀軟骨、環狀軟骨 | 咽縫 | 收縮咽腔，最有力的縮肌 |

### 咽提肌（Pharyngeal Elevators）

| 肌肉 | 起点 | 止點 | 功能 |
|------|------|------|------|
| **莖突咽肌**（Stylopharyngeus） | 莖突 | 甲狀軟骨甲狀舌骨膜 | 提咽，協助吞嚥 |
| **咽鼓管咽肌**（Salpingopharyngeus） | 咽鼓管軟骨 | 咽壁 | 提咽側壁 |
| **齶咽肌**（Palatopharyngeus） | 軟腭 | 咽壁、甲狀軟骨 | 提咽、下降軟腭 |

## 喉（Larynx）概覽

喉是呼吸通道與發聲器官：

| 項目 | 說明 |
|------|------|
| **位置** | C3-C6，舌骨下方 |
| **功能** | 呼吸通道、發聲、保護氣道 |
| **组成** | 軟骨、韌帶、肌肉、黏膜 |

## 喉軟骨（Laryngeal Cartilages）

| 軟骨 | 數量 | 形狀 | 特點 |
|------|------|------|------|
| **甲狀軟骨**（Thyroid cartilage） | 1 | 盾牌狀 | 最大，構成喉前壁；男性有喉結（Adam's apple） |
| **環狀軟骨**（Cricoid cartilage） | 1 | 環狀 | 唯一完整環繞氣道的軟骨；下接氣管 |
| **會厭軟骨**（Epiglottis） | 1 | 葉狀 | 覆蓋喉入口，防止食物進入氣道 |
| **杓狀軟骨**（Arytenoid cartilages） | 2 | 三稜錐形 | 聲帶附著處，可滑動與旋轉 |
| **小角軟骨**（Corniculate cartilages） | 2 | 小角狀 | 杓狀軟骨上方 |
| **楔狀軟骨**（Cuneiform cartilages） | 2 | 楔狀 | 會厭皺襞中 |

### 甲狀軟骨的特點

| 項目 | 說明 |
|------|------|
| **性別差異** | 男性角度約 90°（喉結明顯），女性約 120°（喉結不明顯） |
| **甲狀舌骨韌帶** | 連接甲狀軟骨上角與舌骨大角 |
| **甲狀上切跡** | 甲狀軟骨上緣中央，是甲狀軟骨手術的標誌 |

## 喉韌帶（Laryngeal Ligaments）

| 韌帶 | 連接 | 臨床意義 |
|------|------|----------|
| **甲狀舌骨韌帶**（Thyrohyoid ligament） | 甲狀軟骨上角↔舌骨大角 | 甲狀軟骨與舌骨之間 |
| **甲狀會厭韌帶**（Thyroepiglottic ligament） | 甲狀軟骨前面↔會厭軟骨 | 會厭附著 |
| **環甲韌帶**（Cricothyroid ligament） | 環狀軟骨↔甲狀軟骨下緣 | **緊急穿刺位置（Cricothyrotomy）** |
| **環狀軟骨氣管韌帶**（Cricotracheal ligament） | 環狀軟骨↔第一氣管軟骨 | 連接喉與氣管 |
| **聲韌帶**（Vocal ligament） | 甲狀軟骨后面↔杓狀軟骨聲突 | 構成聲帶的基礎 |

::: {.callout-note appearance="default"}
### 臨床應用：環甲軟骨切開術（Cricothyrotomy）

環甲韌帶是緊急建立呼吸通道的首選位置，因為：
1. 位置表淺
2. 操作簡單快速
3. 不需要特殊設備
4. 併發症相對較少

**適應症**：
- 急性上呼吸道阻塞（如異物、喉水腫）
- 緊急情況下無法進行氣管插管
- 面部創傷無法進行氣管插管

**步驟**：
1. 定位環甲韌帶（環狀軟骨與甲狀軟骨之間）
2. 橫向切開皮膚與環甲韌帶
3. 插入氣管套管或氣管切開導管
:::

## 喉腔分區（Laryngeal Cavity）

喉腔由聲帶分為三個區域：

| 區域 | 範圍 | 臨床意義 |
|------|------|----------|
| **喉前庭**（Vestibule/Laryngeal vestibule） | 喉口至假聲帶之間 | 會厭軟骨覆蓋喉入口 |
| **聲門**（Glottis） | 假聲帶與聲帶之間；聲帶間的裂隙 | 聲門裂（Rima glottidis）是氣道最狹窄處之一 |
| **聲門下區**（Infraglottic cavity） | 聲帶至環狀軟骨下緣 | 聲門下水腫可致嚴重呼吸困難 |

### 喉內部的分層結構

| 層次 | 結構 | 說明 |
|------|------|------|
| **第一層** | 喉口 | 會厭軟骨上緣 |
| **第二層** | 前庭壁（Vestibular wall） | 含前庭韌帶/假聲帶 |
| **第三層** | 聲門（Glottis） | 聲帶（True vocal cords） |
| **第四層** | 聲門下壁 | 環狀軟骨內面 |

## 聲帶（Vocal Cords）

### 聲帶結構

| 結構 | 說明 |
|------|------|
| **聲韌帶**（Vocal ligament） | 甲狀軟骨內面↔杓狀軟骨聲突 |
| **聲帶肌**（Vocalis muscle） | 位於聲韌帶深層，是甲狀腺杓狀肌的一部分 |
| **黏膜** | 覆蓋聲韌帶與聲帶肌，薄而光滑 |

### 聲帶運動

| 肌肉 | 神經 | 功能 |
|------|------|------|
| **環杓後肌**（Posterior cricoarytenoid） | 喉返神經 | **外展**聲帶（吸氣時開大聲門） |
| **環杓側肌**（Lateral cricoarytenoid） | 喉返神經 | **內收**聲帶（發聲時） |
| **杓間肌**（Interarytenoid） | 喉返神經 | 內收聲帶，關閉聲門後部 |
| **環甲肌**（Cricothyroid） | 喉外神經 | **拉長**聲帶（提高音調） |
| **甲狀杓狀肌/聲帶肌**（Thyroarytenoid/Vocalis） | 喉返神經 | **縮短**聲帶（降低音調） |

::: {.callout-note appearance="default"}
### 臨床應用：喉返神經損傷與聲帶運動障礙

**喉返神經**（Recurrent laryngeal nerve）損傷會導致聲帶運動障礙：

| 損傷情況 | 聲帶位置 | 聲音變化 |
|----------|----------|----------|
| 單側喉返神經麻痹 | 旁正中位（Paramedian position） | 聲音嘶啞，嚴重時失聲 |
| 雙側喉返神經麻痹 | 旁正中位 | 嚴重呼吸困難，需要氣管切開 |
| 喉上神經外支损伤 | 聲帶拉長、張力降低 | 音調降低，無法發高音 |

**甲狀腺手術**是喉返神經損傷最常見的原因，手術中識別並保護喉返神經至關重要。
:::

## 喉的血液供應

| 血管 | 來源 | 去向 |
|------|------|------|
| **喉上动脉**（Superior laryngeal artery） | 甲狀腺上动脉 | 喉上神經同行，穿甲狀舌骨膜入喉 |
| **喉下动脉**（Inferior laryngeal artery） | 甲狀腺下动脉 | 喉返神經同行，入喉後下部 |

## 喉的神經支配

| 神經 | 來源 | 支配 |
|------|------|------|
| **喉上神經**（Superior laryngeal nerve） | 迷走神經（X） | 感覺（聲門以上）、環甲肌（運動） |
| **喉返神經**（Recurrent laryngeal nerve） | 迷走神經（X） | 運動（所有喉內肌）、感覺（聲門以下） |

## 吞嚥與發聲時的喉運動

| 動作 | 喉的變化 |
|------|----------|
| **吞嚥** | 喉上提，會厭下降覆蓋喉口，聲帶內收 |
| **發聲** | 聲帶內收，氣流通過聲門裂振動聲帶 |
| **深吸氣** | 聲帶外展，聲門開大 |
| **Valsalva 動作** | 聲帶內收，喉內壓升高 |
