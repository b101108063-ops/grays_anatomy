## 本章重點

- 腦膜三層：**硬膜（dura mater）**、**蛛網膜（arachnoid mater）**、**軟膜（pia mater）**
- 蛛網膜下腔含 **腦脊液（CSF）**，保護腦組織
- 腦脊液循環：側腦室→Monro孔→第三腦室→Cerebral aqueduct→第四腦室→蛛網膜下腔
- 12 對顱神經分為 **感覺神經**、**運動神經**、**混合神經**
:::

## 腦膜三層結構（Meninges）

腦膜是覆蓋在腦表面的三層保護膜：

| 層次 | 名稱 | 特點 |
|------|------|------|
| 最外層 | **硬膜**（Dura mater） | 厚而堅韌，與顱骨內膜緊密相連；在特定部位形成皺襞 |
| 中間層 | **蛛網膜**（Arachnoid mater） | 薄膜狀，與軟膜之間形成蛛網膜下腔 |
| 最內層 | **軟膜**（Pia mater） | 緊贴脑表面，富含血管 |

### 腦膜腔隙

| 腔隙 | 位置 | 內容 |
|------|------|------|
| **硬膜下腔**（Subdural space） | 硬膜與蛛網膜之間 | 含少量液體，正常為潛在腔隙 |
| **蛛網膜下腔**（Subarachnoid space） | 蛛網膜與軟膜之間 | 含 **腦脊液（CSF）**、腦表面血管 |

::: {.callout-note appearance="default"}
### 臨床應用：蛛網膜下腔出血

外傷或动脉瘤破裂可導致蛛網膜下腔出血，血液進入腦脊液中。由於腦脊液不斷循環，出血後血細胞會在數天內被清除，但可能引起腦血管痙攣等併發症。
:::

## 腦脊液循環（Cerebrospinal Fluid Circulation）

### 腦脊液產生與循環路徑

```
側腦室（Lateral ventricles）
    ↓ Monro孔（Interventricular foramen）
第三腦室（Third ventricle）
    ↓ 大腦水管（Cerebral aqueduct）
第四腦室（Fourth ventricle）
    ↓ Luschka 孔（側孔）& Magendie 孔（中孔）
蛛網膜下腔（Subarachnoid space）
    ↓ arachnoid villi（蛛網膜絨毛）
靜脈竇（Venous sinuses）
```

| 項目 | 說明 |
|------|------|
| **產生位置** | 側腦室、第三腦室、第四腦室的脈絡叢（Choroid plexus） |
| **總量** | 約 125-150 mL |
| **壓力** | 70-180 mmH₂O（側臥位） |
| **吸收** | 通過蛛網膜絨毛（Arachnoid villi）進入靜脈竇 |

### 腦脊液功能

1. **機械性保護**：緩衝腦組織受到的衝擊
2. **營養供應**：供給腦細胞所需物質
3. **清除代謝廢物**：帶走腦組織的代謝產物
4. **維持顱內壓**：保持顱內壓力平衡

## 12 對顱神經簡表（Cranial Nerves）

| 編號 | 名稱 | 類型 | 主要功能 |
|------|------|------|----------|
| **I** | 嗅神經（Olfactory nerve） | 感覺 | **嗅覺** |
| **II** | 視神經（Optic nerve） | 感覺 | **視覺** |
| **III** | 動眼神經（Oculomotor nerve） | 運動 | 眼外肌（除外直肌、上斜肌）、瞳孔括約肌、睫狀肌 |
| **IV** | 滑車神經（Trochlear nerve） | 運動 | **上斜肌**（Superior oblique） |
| **V** | 三叉神經（Trigeminal nerve） | 混合 | **感覺**：面部、口腔、鼻腔感覺；**運動**：咀嚼肌 |
| **VI** | 外展神經（Abducens nerve） | 運動 | **外直肌**（Lateral rectus） |
| **VII** | 面神經（Facial nerve） | 混合 | **運動**：面部表情肌；**感覺**：味覺（前 2/3 舌頭）；**副交感**：淚腺、唾液腺 |
| **VIII** | 前庭蝸神經（Vestibulocochlear nerve） | 感覺 | **聽覺**、**平衡** |
| **IX** | 舌咽神經（Glossopharyngeal nerve） | 混合 | 舌頭後 1/3 **味覺**、**感覺**、**副交感**：腮腺分泌 |
| **X** | 迷走神經（Vagus nerve） | 混合 | **內臟運動**（副交感）、**內臟感覺**、咽喉感覺與運動 |
| **XI** | 副神經（Accessory nerve） | 運動 | **胸鎖乳突肌**、**斜方肌** |
| **XII** | 舌下神經（Hypoglossal nerve） | 運動 | **舌頭運動**（外在肌、內在肌） |

### 三叉神經（V）分支詳解

| 分支 | 名稱 | 感覺分布 |
|------|------|----------|
| **V1** | 眼神經（Ophthalmic nerve） | 額部、眼瞼、鼻樑、角膜 |
| **V2** | 上頜神經（Maxillary nerve） | 顏面中部、上頜牙齒、上唇 |
| **V3** | 下頜神經（Mandibular nerve） | 顏面下部、下頜牙齒、咀嚼肌（運動）、部分耳廓與外耳道 |

::: {.callout-note appearance="default"}
### 臨床應用：三叉神經痛

三叉神經痛（Trigeminal neuralgia）是常見的顏面部疼痛疾病，表現為短暫、劇烈的電擊樣疼痛，常因觸碰特定「觸發點」而誘發。好發於 V2 或 V3 分佈區域，常見於中老年人。
:::

### 顱神經與眼眶的關係

| 神經 | 眼外肌支配 | 眼眶進出口 |
|------|------------|------------|
| III 動眼神經 | 上瞼提肌、上直肌、下直肌、內直肌、下斜肌 | 眶上裂 |
| IV 滑車神經 | 上斜肌 | 眶上裂 |
| VI 外展神經 | 外直肌 | 眶上裂 |
| V1 眼神經 | — | 眶上裂 |
| V2 上頜神經 | — | 眶下裂 |
