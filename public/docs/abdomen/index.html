Appendix

腹部#

Abdomen | Chapter 4#

本章重點#

腹部包含消化系統的核心器官，也是臨床中最常需要進行理學檢查的區域：

  • 腹壁結構：肌肉層次、筋膜、腹股溝管
  • 腹膜與腹膜腔：脏器如何被覆蓋
  • 消化道：胃、小腸、大腸、肝膽、胰臟
  • 後腹膜器官：腎臟、腎上腺、主動脈
  • 臨床重點：急性腹痛評估、腹膜炎症狀

學習目標#

  • 能夠描述腹壁各層肌肉的名稱、位置和功能
  • 能夠解釋腹膜如何形成大網膜、小網膜、腸系膜
  • 能夠說出肝臟、膽囊、胃、胰臟的解剖位置及其血管供應
  • 能夠區分腹膜內器官和後腹膜器官
  • 能夠描述腹股溝管的結構及其與腹股溝疝氣的關係

腹壁結構#

肌肉層次（前外側腹壁）#

層次肌肉重要特點
最表層腹外斜肌（External oblique）纖維向下內
第二層腹內斜肌（Internal oblique）纖維向上內
第三層腹橫肌（Transversus abdominis）纖維水平
最深層腹直肌（Rectus abdominis）兩側各有，剣突到恥骨

腹股溝管（Inguinal Canal）#

  • 男性：精索通過
  • 女性：圓韌帶通過
  • 前壁：腹外斜肌筋膜
  • 後壁：腹橫筋膜
  • 上壁：腹內斜肌和腹橫肌下緣
  • 下壁：腹股溝韌帶

腹膜（Peritoneum）#

脏器被覆方式#

  • 臟器被腹膜完全包圍（腹膜內器官）：胃、空腸、迴腸、横結腸
  • 臟器只有一面被腹膜覆蓋（後腹膜器官）：胰臟、腎臟、腎上腺、主動脈

腹膜形成的結構#

結構位置臨床意義
大網膜（Greater omentum）胃大彎到橫結腸，像圍裙覆蓋小腸緊急時可附著到發炎區域限制感染擴散
小網膜（Lesser omentum）胃小彎到肝門膽結石手術重要標誌
腸系膜（Mesentery）空腸和迴腸的附著到後腹壁包含血管和淋巴

肝臟（Hepatobiliary System）#

肝臟分葉#

分葉方式內容
形態學分葉右葉、左葉、尾葉、方葉
Couinaud 功能分葉8個功能段（segment），各有獨立血供

膽道系統#

  • 肝內膽管 → 左/右肝管 → 總肝管
  • 膽囊管 + 總肝管 → 總膽管（Common bile duct）
  • 膽囊：儲存和濃縮膽汁

臨床應用#

急性闌尾炎（Acute Appendicitis）#

最常見的外科急症之一：

  • 典型轉移痛：先是臍周圍不適 → 然後轉移到右下腹（McBurney’s point）
  • 特徵：壓痛、反彈痛、發燒
  • 鑑別診斷：腸胃炎、泌尿道感染、婦科問題

腹股溝疝氣（Inguinal Hernia）#

  • 間接型：先天性，腹股溝管內環突出（年輕男性）
  • 直接型：後壁弱化，腹股溝管後壁突出（老年男性）
  • 處置：網膜修補術（Lichtenstein repair）

表面解剖#

  • 恥骨聯合：兩側恥骨之間的軟骨連接
  • 臍（Umbilicus）：約 L3/L4 高度
  • McBurney’s point：臍到右側髂前上棘連線的外1/3點 = 闌尾炎壓痛點
  • 肝上界：右鎖骨中線第5肋間
  • 膽囊底：右胸直肌外側緣與右肋弓交界處
